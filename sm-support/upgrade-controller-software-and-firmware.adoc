= 在 SANtricity System Manager 中升级控制器软件和固件
:allow-uri-read: 


[role="lead"]
您可以升级存储阵列的软件，也可以升级 IOM 固件和非易失性静态随机存取存储器 (NVSRAM)，以确保您拥有所有最新功能和错误修复。

.开始之前
* 您知道是否要升级 IOM 固件。
+
通常情况下，您应该同时升级所有组件。但是，如果不想在 SANtricity OS 软件升级过程中升级 IOM 固件，或者技术支持指示您降级 IOM 固件（只能使用命令行界面降级固件），则可能决定不升级 IOM 固件。

* 您知道是否要升级控制器 NVSRAM 文件。
+
通常，应同时升级所有组件。但是，如果文件已修补或为自定义版本并且不希望覆盖它，则可能决定不升级控制器 NVSRAM 文件。

* 您知道是立即激活 OS 升级还是稍后激活。
+
稍后激活的原因可能包括：

+
** *时间* -- 激活软件和固件可能需要很长时间，因此您可能需要等待 I/O 负载较轻。控制器在激活期间发生故障转移，因此在升级完成之前，性能可能会低于正常水平。
** *包类型* -- 在升级其他存储阵列上的文件之前，您可能需要在一个存储阵列上测试新软件和固件。


* 您知道是否要从不安全的驱动器或内部安全的驱动器切换到使用外部密钥管理服务器 (KMS) 来确保驱动器安全。
* 您知道是否要在存储阵列中使用基于角色的访问控制。


.关于此任务
您可以选择仅升级 OS 软件文件或仅升级控制器 NVSRAM 文件，或者您可以选择升级这两个文件。

仅在技术支持人员指示时执行此操作。

[CAUTION]
====
*数据丢失或存储阵列损坏的风险* -- 升级过程中请勿对存储阵列进行更改。保持存储阵列的电源。

====
.步骤
. 如果您的存储阵列仅包含一个控制器，或者您没有安装多路径驱动程序，请停止对存储阵列的 I/O 活动，以防止出现应用程序错误。如果您的存储阵列有两个控制器，并且您安装了多路径驱动程序，则无需停止 I/O 活动。
. 选择菜单：Support[Upgrade Center]。
. 从支持站点将新文件下载到管理客户端。
+
.. 单击 *NetApp 支持* 启动支持网站。
.. 在 Support 网站上，单击 *Downloads* 选项卡，然后选择 *Downloads*。
.. 选择 *E-Series SANtricity OS Controller Software*。
.. 按照其余说明进行操作。


+
[NOTE]
====
8.42 及更高版本需要数字签名固件。如果您尝试下载未签名的固件，则会显示错误并中止下载。

====
. 如果此时不想升级 IOM 固件，请单击 *暂停 IOM 自动同步*。
+
如果您的存储阵列只有一个控制器，则 IOM 固件不会升级。

. 在 SANtricity OS 软件升级下，单击 *开始升级* 。
+
此时将显示升级 SANtricity OS 软件对话框。

. 选择一个或多个文件以开始升级过程：
+
.. 通过单击*浏览*并导航到您从支持网站下载的 OS 软件文件，选择 SANtricity OS 软件文件。
.. 通过单击*浏览*并导航到您从支持站点下载的 NVSRAM 文件，选择控制器 NVSRAM 文件。控制器 NVSRAM 文件的文件名类似于 `N2800-830000-000.dlp`。


+
执行以下操作：

+
** 默认情况下，仅显示与当前存储阵列配置兼容的文件。
** 选择要升级的文件时，将显示该文件的名称和大小。


. *可选：* 如果您选择要升级的 SANtricity OS 软件文件，则可以通过选中 *立即传输文件，但不升级（稍后激活升级）* 复选框将文件传输到控制器，而无需激活它们。
. 单击 *Start*，并确认要执行此操作。
+
您可以在升级前运行状况检查期间取消操作，但不能在传输或激活期间取消。

. *可选：* 要查看已升级内容的列表，请单击 *Save Log*。
+
此文件将以此名称保存在浏览器的 Downloads 文件夹中 `drive_upgrade_log-timestamp.txt`。



.完成后
* 确认所有组件都显示在 Hardware 页面上。
* 通过检查软件和固件清单对话框来验证新的软件和固件版本（转到菜单：Support[Upgrade Center]，然后单击 *Software and Firmware Inventory* 的链接）。
* 如果升级了控制器 NVSRAM，则在激活过程中，应用于现有 NVSRAM 的任何自定义设置都将丢失。激活过程完成后，您需要再次将自定义设置应用于 NVSRAM。
