= 清除 SANtricity 软件中的恢复模式
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
恢复存储阵列配置后，使用清除恢复模式操作恢复存储阵列上的 I/O 并将其恢复为正常操作。

.开始之前
* 如果要将存储阵列恢复到以前的配置，则必须在清除恢复模式之前从备份还原配置。
* 您必须执行验证检查或咨询技术支持，以确保恢复成功。确定恢复成功后，可以清除恢复模式。


.关于此任务
存储阵列包含一个配置数据库，其中包含其逻辑配置（池、卷组、卷等）的记录。如果您有意清除存储阵列配置，或者配置数据库已损坏，则存储阵列将进入恢复模式。恢复模式会停止 I/O 并冻结配置数据库，从而让您有时间执行以下操作之一：

* 从控制器闪存设备中存储的自动备份中恢复配置。您必须联系技术支持才能执行此操作。
* 从先前的保存配置数据库操作还原配置。保存配置数据库操作通过命令行界面 (CLI) 执行。
* 从头开始重新配置存储阵列。


在恢复或重新定义存储阵列配置并验证一切正常后，您必须手动清除恢复模式。

[NOTE]
====
清除恢复模式操作启动后无法取消。清除恢复模式可能需要很长时间。仅在技术支持人员指示时执行此操作。

====
.步骤
. 选择菜单：Support[Support Center > Diagnostics] 选项卡。
. 选择 *Clear Recovery Mode*，并确认要执行此操作。
+
仅当存储阵列处于恢复模式时才会显示此选项。
