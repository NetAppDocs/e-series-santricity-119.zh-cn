= 在 SANtricity System Manager 中查看 iSCSI 统计信息包
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以查看有关 iSCSI 连接到存储阵列的数据。

.关于此任务
System Manager 显示这些类型的 iSCSI 统计信息。所有统计信息都是只读的，无法设置。


NOTE: System Manager 中显示的统计数据类型基于您的存储阵列可用的统计数据。

* *以太网 MAC 统计信息* -- 提供媒体访问控制 (MAC) 的统计数据。MAC 还提供了一种称为物理地址或 MAC 地址的寻址机制。MAC 地址是分配给每个网络适配器的唯一地址。MAC 地址有助于将数据包发送到子网内的目的地。
* *以太网 TCP/IP 统计信息* -- 提供 TCP/IP 的统计数据，即 iSCSI 设备的传输控制协议 (TCP) 和互联网协议 (IP)。使用 TCP，网络主机上的应用程序可以相互创建连接，从而可以在数据包中交换数据。IP 是一种面向数据的协议，可在分组交换的互联网络中传输数据。IPv4 统计数据和 IPv6 统计数据分别显示。
* *以太网内核统计* -- 提供 iSCSI 设备的平台内核驱动程序的统计信息。内核统计信息显示的网络数据与 TCP/IP 统计信息选项相似。但是，内核统计数据是从平台内核驱动程序收集的，而不是直接从 iSCSI 硬件收集的。
* *本地目标/启动器（协议）统计信息* -- 显示 iSCSI 目标的统计信息，该目标提供对其存储介质的块级访问，并显示存储阵列在异步镜像操作中用作启动器时的 iSCSI 统计信息。
* *DCBX 运行状态统计* -- 显示各种数据中心桥接交换 (DCBX) 功能的运行状态。
* *LLDP TLV 统计数据* -- 显示链路层发现协议 (LLDP) 类型长度值 (TLV) 统计数据。
* *DCBX TLV 统计信息* -- 显示标识数据中心桥接 (DCB) 环境中存储阵列主机端口的信息。此信息将与网络对等设备共享，用于识别和功能目的。


您可以将这些统计数据中的每一个查看为原始统计数据或基线统计数据。原始统计数据是自控制器启动以来收集的所有统计数据。基线统计数据是自您设置基线时间以来收集的时间点统计数据。

.步骤
. 选择菜单：Support[Support Center > Diagnostics] 选项卡。
. 选择 *View iSCSI Statistics Packages*。
. 单击选项卡可查看不同的统计信息集。
. 要设置基线，请单击 *Set new baseline*。
+
设置基线为统计数据的收集设置了一个新的起点。相同的基线用于所有 iSCSI 统计信息。
