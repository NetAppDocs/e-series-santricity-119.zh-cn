= 了解 SANtricity 软件和固件升级错误
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在控制器软件升级或驱动器固件升级期间可能发生错误。

[cols="25h,~,~"]
|===
| 固件下载错误 | 说明 | 建议操作 


 a| 
分配的驱动器出现故障
 a| 
无法升级存储阵列中分配的驱动器。
 a| 
出现故障的一个原因可能是驱动器没有适当的签名。请确保受影响的驱动器是授权驱动器。有关详细信息，请与技术支持联系。

更换驱动器时，请确保更换驱动器的容量等于或大于您要更换的故障驱动器。

您可以在存储阵列接收 I/O 时更换出现故障的驱动器。



 a| 
集成热备用驱动器
 a| 
如果驱动器被标记为热备盘并且正在用于某个卷组，则固件升级过程将失败。
 a| 
必须先纠正此错误情况，然后才能升级固件。启动 System Manager 并使用 Recovery Guru 解决此问题。



 a| 
不完整的卷组
 a| 
如果任何属于卷组的驱动器被绕过、删除或无响应，则视为不完整的卷组。不完整的卷组会阻止固件升级。
 a| 
如果一个或多个卷组或磁盘池不完整，则必须先更正此错误情况，然后才能升级固件。启动 System Manager 并使用 Recovery Guru 来解决问题。



 a| 
当前在任何卷组上运行的独占操作（后台媒体/奇偶校验扫描除外）
 a| 
如果卷上正在进行任何独占操作，则无法升级固件。
 a| 
如果一个或多个独占操作正在进行中，则必须先完成操作，然后才能升级固件。使用 System Manager 来监控操作进度。



 a| 
缺失卷
 a| 
如果缺少任何卷，则无法升级固件。
 a| 
必须先纠正丢失的卷情况，然后才能升级固件。启动 System Manager 并使用 Recovery Guru 解决此问题。



 a| 
任一控制器处于 Optimal 以外的状态
 a| 
如果任何一个控制器处于非最佳状态，则无法升级固件。
 a| 
其中一个存储阵列控制器需要注意。必须先纠正此情况，然后才能升级固件。启动 System Manager 并使用 Recovery Guru 来解决问题。



 a| 
SPM 验证数据库控制器检查失败
 a| 
无法升级固件，因为存储分区映射数据库已损坏。
 a| 
控制器上发生存储分区映射数据库错误。请联系技术支持以解决此问题。



 a| 
配置数据库验证（如果存储阵列的控制器版本支持）
 a| 
无法升级固件，因为配置数据库已损坏。
 a| 
控制器上发生配置数据库错误。请联系技术支持以解决此问题。



 a| 
MEL 相关检查
 a| 
无法升级固件，因为事件日志包含错误。
 a| 
请联系技术支持以解决此问题。



 a| 
在过去 7 天内报告了超过 10 起 DDE 信息性或危急 MEL 事件
 a| 
无法升级固件，因为在过去七天内报告的 DDE 信息或关键 MEL 事件超过 10 个。
 a| 
请联系技术支持以解决此问题。



 a| 
在过去 7 天内报告了超过 2 个 Page 2C Critical MEL 事件
 a| 
无法升级固件，因为在过去七天内报告了两个以上的页面 2C 关键 MEL 事件。
 a| 
请联系技术支持以解决此问题。



 a| 
在过去 7 天内报告了 2 个以上已降级的驱动器通道关键 MEL 事件
 a| 
无法升级固件，因为在过去七天内报告了两个以上降级的驱动器通道严重 MEL 事件。
 a| 
请联系技术支持以解决此问题。



 a| 
过去 7 天超过 4 个关键 MEL 条目
 a| 
无法升级固件，因为在过去七天中报告了四个以上的关键事件日志条目。
 a| 
请联系技术支持以解决此问题。



 a| 
需要提供有效的管理 IP 地址。
 a| 
要执行此操作，需要提供有效的控制器 IP 地址。
 a| 
请联系技术支持以解决此问题。



 a| 
该命令要求为每个控制器提供一个活动管理 IP 地址。
 a| 
此操作需要与存储阵列关联的每个控制器的控制器 IP 地址。
 a| 
请联系技术支持以解决此问题。



 a| 
返回未处理的下载文件类型。
 a| 
不支持指定的下载文件。
 a| 
请联系技术支持以解决此问题。



 a| 
固件下载上传过程中出错。
 a| 
固件下载失败，因为控制器无法处理此请求。验证存储阵列是否最佳并重试此操作。
 a| 
如果在验证存储阵列处于最佳状态后再次发生此错误，请联系技术支持以解决此问题。



 a| 
固件激活过程中出错。
 a| 
固件激活失败，因为控制器无法处理此请求。验证存储阵列是否最佳并重试此操作。
 a| 
如果在验证存储阵列处于最佳状态后再次发生此错误，请联系技术支持以解决此问题。



 a| 
等待控制器 {0} 重新启动时已达到超时。
 a| 
重新启动后，管理软件无法重新连接到控制器 {0}。验证是否有到存储阵列的操作连接路径，如果未成功完成，则重试此操作。
 a| 
如果在验证存储阵列处于最佳状态后再次发生此错误，请联系技术支持以解决此问题。

|===
您可以使用 System Manager 中的 Recovery Guru 来更正其中一些情况。但是，对于某些情况，您可能需要联系技术支持。有关最新控制器固件下载的信息可从存储阵列获得。此信息有助于技术支持了解阻止固件升级和下载的错误条件。
