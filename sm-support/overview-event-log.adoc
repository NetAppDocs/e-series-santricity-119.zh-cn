= 了解 SANtricity 软件中的事件日志
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
事件日志提供存储阵列上发生的事件的历史记录，有助于技术支持对导致故障的事件进行故障排除。

您可以将事件日志用作 Recovery Guru 的补充诊断工具，以跟踪存储阵列事件。当您尝试从存储阵列中的组件故障中恢复时，请始终首先参考 Recovery Guru。



== 事件类别

事件日志中的事件按不同状态进行分类。需要执行操作的事件具有以下状态：

* 严重
* 警告


以下事件仅供参考，无需立即采取行动：

* 信息




== 严重事件

关键事件表示存储阵列存在问题。如果立即解决关键事件，可能会防止数据访问丢失。

当发生关键事件时，它将记录在事件日志中。所有关键事件都将发送到 SNMP 管理控制台或您配置为接收警报通知的电子邮件收件人。如果事件发生时货架 ID 未知，货架 ID 将列为"货架未知"。

当您收到关键事件时，请参阅 Recovery Guru 程序，了解关键事件的详细说明。完成 Recovery Guru 程序以更正关键事件。要更正某些关键事件，您可能需要联系技术支持。
