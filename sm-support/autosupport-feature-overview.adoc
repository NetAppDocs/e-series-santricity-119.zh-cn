= 了解有关 E 系列 AutoSupport 的信息
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
AutoSupport 功能可监控存储阵列的运行状况，并将自动派单发送给技术支持。

技术支持以被动方式使用 AutoSupport 数据来加快客户问题的诊断和解决，并主动检测和避免潜在问题。

AutoSupport 数据包括有关存储阵列的配置、状态、性能和系统事件的信息。AutoSupport 数据不包含任何用户数据。调度可以立即发送或按计划发送（每日和每周）。



== 主要优势

AutoSupport 功能的一些主要优势包括：

* 加快案例解决时间
* 先进的监控，实现更快的事件管理
* 根据时间表自动报告，并自动报告关键事件
* 所选组件（如驱动器）的自动硬件更换请求
* 非侵入式警报，通知您出现问题并为技术支持提供信息以采取纠正措施
* 监控派遣中已知配置问题的 AutoSupport 分析工具




== 各个 AutoSupport 功能

该 AutoSupport 功能由三个单独的功能组成，您可以分别启用这些功能。

* *基本 AutoSupport* -- 允许您的存储阵列自动收集数据并将其发送给技术支持。
* *AutoSupport OnDemand* -- 允许技术支持在需要解决问题时请求重新传输以前的 AutoSupport 派单。所有传输都是从存储阵列启动的，而不是从 AutoSupport 服务器启动的。存储阵列定期与 AutoSupport 服务器进行检查，以确定是否存在任何挂起的重传请求，并做出相应的响应。
* *远程诊断* -- 允许技术支持在需要解决问题时请求新的最新 AutoSupport 派遣。所有传输都是从存储阵列启动的，而不是从 AutoSupport 服务器启动的。存储阵列定期与 AutoSupport 服务器签入，以确定是否存在任何挂起的新请求，并做出相应的响应。




== AutoSupport 与收集支持数据之间的差异

存储阵列中存在两种收集支持数据的方法：

* *AutoSupport 功能* -- 自动收集数据。
* *收集支持数据选项* -- 必须手动收集和发送数据。


AutoSupport 功能更易于使用，因为数据是自动收集和发送的。可以主动使用 AutoSupport 数据来防止问题发生。AutoSupport 功能可以加快故障排除速度，因为技术支持已经可以访问数据。出于这些原因，AutoSupport 功能是首选的数据收集方法。
