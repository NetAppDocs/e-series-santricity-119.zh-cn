= 在 SANtricity System Manager 中检索运行状况映像
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以查看控制器的运行状况映像。运行状况映像是控制器处理器内存的原始数据转储，技术支持可以使用它来诊断控制器问题。

.关于此任务
固件在检测到某些错误时会自动生成健康图像。生成运行状况映像后，发生错误的控制器将重新启动并在事件日志中记录事件。

如果已开启 AutoSupport，则会自动将运行状况图像发送给技术支持。如果尚未打开 AutoSupport，则需要联系技术支持以获取有关检索运行状况图像并将其发送给他们进行分析的说明。

[NOTE]
====
仅在技术支持人员指示时执行此操作。

====
.步骤
. 选择菜单：Support[Support Center > Diagnostics] 选项卡。
. 选择 *Retrieve Health Image*。
+
您可以在下载文件之前查看详细信息部分以查看运行状况映像的大小。

. 单击 *Collect*。
+
此文件将以此名称保存在浏览器的 Downloads 文件夹中 `health-image.7z`。

. 按照技术支持提供的说明将文件发送给他们。
