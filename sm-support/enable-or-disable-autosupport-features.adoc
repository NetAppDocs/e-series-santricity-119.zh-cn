= 在 SANtricity System Manager 中启用或禁用 AutoSupport 功能
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在初始设置期间启用 AutoSupport 功能和单个 AutoSupport 功能，也可以稍后启用或禁用它们。

.开始之前
如果要启用 AutoSupport OnDemand 或远程诊断，必须将 AutoSupport 传递方法设置为 HTTPS。

.关于此任务
您可以随时禁用 AutoSupport 功能，但强烈建议您保持启用状态。启用 AutoSupport 功能可以大大加快问题确定和解决的速度，如果存储阵列上出现问题。

该 AutoSupport 功能由三个单独的功能组成，您可以分别启用这些功能。

* *基本 AutoSupport* -- 允许您的存储阵列自动收集数据并将其发送给技术支持。
* *AutoSupport OnDemand* -- 允许技术支持在需要解决问题时请求重新传输以前的 AutoSupport 派单。所有传输都是从存储阵列启动的，而不是从 AutoSupport 服务器启动的。存储阵列定期与 AutoSupport 服务器进行检查，以确定是否存在任何挂起的重传请求，并做出相应的响应。
* *远程诊断* -- 允许技术支持在需要解决问题时请求新的最新 AutoSupport 派遣。所有传输都是从存储阵列启动的，而不是从 AutoSupport 服务器启动的。存储阵列定期与 AutoSupport 服务器签入，以确定是否存在任何挂起的新请求，并做出相应的响应。


.步骤
. 选择菜单：Support[Support Center > AutoSupport] 选项卡。
. 选择*启用/禁用 AutoSupport 功能*。
. 选中要启用的 AutoSupport 功能旁边的复选框。
+
这些特征相互依赖，如对话框中项目的缩进所示。例如，您必须先启用 AutoSupport OnDemand，然后才能启用远程诊断。

. 单击 *Save*。
+
如果禁用 AutoSupport，主页上将显示通知。您可以通过点击*忽略*来关闭通知。
