= 在 SANtricity System Manager 中查看存储阵列的配置文件
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
存储阵列配置文件提供了存储阵列的所有组件和属性的描述。

.关于此任务
您可以使用存储阵列配置文件作为恢复过程中的辅助功能，或作为存储阵列当前配置的概述。您可能需要在管理客户端上保存存储阵列配置文件的副本，并在存储阵列中保留存储阵列配置文件的硬拷贝。如果配置发生更改，请创建存储阵列配置文件的新副本。

.步骤
. 选择菜单：Support[Support Center > Support Resources] 选项卡。
. 向下滚动到 *Launch detailed storage array information*，然后选择 *Storage Array Profile*。
+
此报告会显示在您的屏幕上。

+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 板块 | 说明 


 a| 
存储阵列
 a| 
显示您可以配置的所有选项以及存储阵列的系统静态选项。这些选项包括控制器、驱动器盘架、驱动器、磁盘池、卷组、卷和热备盘驱动器的数量；允许的驱动器盘架、驱动器、固态硬盘 (SSD) 和卷的最大数量；快照组、快照映像、快照卷和一致性组的数量；有关功能的信息；有关固件版本的信息；有关机箱序列号的信息；AutoSupport 状态和 AutoSupport 计划信息；自动支持数据收集和计划支持数据收集的设置；存储阵列全球标识符 (WWID)；以及媒体扫描和缓存设置。



 a| 
存储
 a| 
显示存储阵列中所有存储设备的列表。根据您的存储阵列配置，Storage 部分可能会显示这些子部分。

** *磁盘池* -- 显示存储阵列中所有磁盘池的列表。
** *卷组* -- 显示存储阵列中所有卷组的列表。卷和可用容量按创建顺序列出。
** *卷* -- 显示存储阵列中所有卷的列表。列出的信息包括卷名、卷状态、容量、RAID 级别、卷组或磁盘池、驱动器类型和其他详细信息。
** *缺少卷* -- 显示存储阵列中当前具有缺少状态的所有卷的列表。列出的信息包括每个缺失卷的全球标识符 (WWID)。




 a| 
复制服务
 a| 
显示用于存储阵列的所有复制服务的列表。根据您的存储阵列配置，复制服务部分可能会显示以下子部分：

** *Volume Copies* -- 显示存储阵列中所有副本对的列表。列出的信息包括副本数、副本对名称、状态、开始时间戳和其他详细信息。
** *快照组* -- 显示存储阵列中所有快照组的列表。
** *快照映像* -- 显示存储阵列中所有快照的列表。
** *快照卷* -- 显示存储阵列中所有快照卷的列表。
** *一致性组* -- 显示存储阵列中所有一致性组的列表。
** *成员卷* -- 显示存储阵列中所有一致性组成员卷的列表。
** *镜像组* -- 显示所有镜像卷的列表。
** *保留容量* -- 显示存储阵列中所有保留容量卷的列表。




 a| 
主机分配
 a| 
显示存储阵列中主机分配的列表。列出的信息包括卷名、逻辑单元号 (LUN)、控制器 ID、主机名或主机群集名以及卷状态。列出的其他信息包括拓扑定义和主机类型定义。



 a| 
硬件
 a| 
显示存储阵列中所有硬件的列表。根据您的存储阵列配置，Hardware 部分可能会显示这些子部分。

** *Controllers* -- 显示存储阵列中所有控制器的列表，包括控制器位置、状态和配置。此外，它还包括驱动器通道信息、主机通道信息和以太网端口信息。
** *驱动器* -- 显示存储阵列中所有驱动器的列表。驱动器按机架 ID、抽屉 ID、插槽 ID 顺序列出。列出的信息包括每个驱动器的机架 ID、抽屉 ID、插槽 ID、状态、原始容量、介质类型、接口类型、当前数据速率、产品 ID 和固件版本。驱动器部分还包括驱动器通道信息、热备盘覆盖信息和磨损寿命信息（仅适用于 SSD 驱动器）。磨损寿命信息包括已使用的耐久性百分比，即迄今为止写入 SSD 驱动器的数据量除以驱动器的总理论写入限制。
** *驱动器通道* -- 显示存储阵列中所有驱动器通道的信息。列出的信息包括通道状态、链接状态（如适用）、驱动器计数和累计错误计数。
** *机架* -- 显示存储阵列中所有机架的信息。列出的信息包括驱动器类型和机架每个组件的状态信息。机架组件可能包括电池组、小型可插拔 (SFP) 收发器、电源风扇罐或输入/输出模块 (IOM) 罐。如果存储阵列使用安全密钥，"硬件"部分还会显示安全密钥标识符。




 a| 
功能
 a| 
显示已安装功能包的列表以及每个主机或主机群集允许的最大快照组数、快照（旧版）和卷数。功能部分中的信息还包括驱动器安全；即存储阵列是启用安全还是禁用安全。

|===
====
. 要搜索存储阵列配置文件，请在 *Find* 文本框中键入搜索词，然后单击 *Find* 。
+
所有匹配的术语都会突出显示。要一次滚动浏览所有结果，请继续单击 *Find*。

. 要保存存储阵列配置文件，请单击 *Save*。
+
此文件将以此名称保存在浏览器的 Downloads 文件夹中 `storage-array-profile.txt`。
