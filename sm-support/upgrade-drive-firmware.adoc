= 在 SANtricity System Manager 中升级驱动器固件
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以升级驱动器固件，以确保您拥有所有最新功能和错误修复。

.开始之前
* 您已使用磁盘到磁盘备份、卷复制（到不受计划固件升级影响的卷组）或远程镜像备份数据。
* 存储阵列具有最佳状态。
* 所有驱动器都具有最佳状态。
* 存储阵列上未运行任何配置更改。
* 如果驱动器只能进行离线升级，则会停止与驱动器关联的所有卷的 I/O 活动。


.步骤
. 选择菜单：Support[Upgrade Center]。
. 将新文件从支持站点下载到您的管理客户端。
. 在驱动器固件升级下，单击 *开始升级* 。
+
此时将显示一个对话框，其中列出当前正在使用的驱动器固件文件。

. 从支持站点提取（解压缩）您下载的文件。
. 单击 *Browse*，然后选择从 Support 站点下载的新驱动器固件文件。
+
驱动器固件文件的文件名类似于  `D_HUC101212CSS600_30602291_MS01_2800_0002`，扩展名为  `.dlp`。

+
您最多可以选择四个驱动器固件文件，一次一个。如果多个驱动器固件文件与同一驱动器兼容，则会出现文件冲突错误。确定要用于升级的驱动器固件文件并删除另一个。

. 单击 *Next*。
+
此时将显示 *Select Drives* 对话框，其中列出了可使用选定文件升级的驱动器。

+
仅显示兼容的驱动器。

+
为驱动器选择的固件显示在建议的固件信息区域中。如果您必须更改固件，请单击 *Back* 返回上一个对话框。

. 选择要执行的升级类型：
+
** *联机（默认值）* -- 显示可以支持固件下载的驱动器_在存储阵列处理 I/O 时_。选择此升级方法时，您无需停止使用这些驱动器对关联卷的 I/O。在存储阵列处理这些驱动器的 I/O 时，这些驱动器会一次升级一个。
** *离线（并行）* -- 显示仅在使用驱动器的任何卷上的所有 I/O 活动停止时才能支持固件下载的驱动器。选择此升级方法时，必须停止使用要升级的驱动器的任何卷上的所有 I/O 活动。没有冗余的驱动器必须作为离线操作处理。此要求包括与 SSD 缓存、RAID 0 卷组或任何已降级的池或卷组关联的任何驱动器。离线（并行）升级通常比在线（默认）方法更快。


. 在表格的第一列中，选择要升级的驱动器。
. 单击 *Start*，并确认要执行此操作。
+
如果需要停止升级，请单击 *停止*。当前正在进行的所有固件下载已完成。任何未开始的固件下载都将被取消。

+
[CAUTION]
====
停止驱动器固件升级可能会导致数据丢失或驱动器不可用。

====
. *可选：* 要查看已升级内容的列表，请单击 *Save Log*。
+
此文件将以此名称保存在浏览器的 Downloads 文件夹中 `drive_upgrade_log-timestamp.txt`。

. 如果在升级过程中出现以下任一错误，请采取适当的建议措施。


.错误和建议操作
[%collapsible]
====
[cols="40h,~"]
|===
| 如果遇到此固件下载错误... | 然后执行以下操作... 


 a| 
分配的驱动器出现故障
 a| 
出现故障的一个原因可能是驱动器没有适当的签名。请确保受影响的驱动器是授权驱动器。有关详细信息，请与技术支持联系。

更换驱动器时，请确保更换驱动器的容量等于或大于您要更换的故障驱动器。

您可以在存储阵列接收 I/O 时更换出现故障的驱动器。



 a| 
检查存储阵列
 a| 
* 确保已为每个控制器分配 IP 地址。
* 确保连接到控制器的所有电缆均未损坏。
* 确保所有电缆均已紧密连接。




 a| 
集成热备用驱动器
 a| 
必须先纠正此错误情况，然后才能升级固件。启动 System Manager 并使用 Recovery Guru 解决此问题。



 a| 
不完整的卷组
 a| 
如果一个或多个卷组或磁盘池不完整，则必须先更正此错误情况，然后才能升级固件。启动 System Manager 并使用 Recovery Guru 来解决问题。



 a| 
当前在任何卷组上运行的独占操作（后台介质/奇偶校验扫描除外）
 a| 
如果一个或多个独占操作正在进行中，则必须先完成操作，然后才能升级固件。使用 System Manager 来监控操作进度。



 a| 
缺失卷
 a| 
必须先纠正丢失的卷情况，然后才能升级固件。启动 System Manager 并使用 Recovery Guru 解决此问题。



 a| 
任一控制器处于 Optimal 以外的状态
 a| 
其中一个存储阵列控制器需要注意。必须先纠正此情况，然后才能升级固件。启动 System Manager 并使用 Recovery Guru 来解决问题。



 a| 
控制器对象图形之间的存储分区信息不匹配
 a| 
验证控制器上的数据时出错。请联系技术支持以解决此问题。



 a| 
SPM 验证数据库控制器检查失败
 a| 
控制器上发生存储分区映射数据库错误。请联系技术支持以解决此问题。



 a| 
配置数据库验证（如果存储阵列的控制器版本支持）
 a| 
控制器上发生配置数据库错误。请联系技术支持以解决此问题。



 a| 
MEL 相关检查
 a| 
请联系技术支持以解决此问题。



 a| 
在过去 7 天内报告了超过 10 起 DDE 信息性或危急 MEL 事件
 a| 
请联系技术支持以解决此问题。



 a| 
在过去 7 天内报告了超过 2 个 Page 2C Critical MEL 事件
 a| 
请联系技术支持以解决此问题。



 a| 
在过去 7 天内报告了 2 个以上已降级的驱动器通道关键 MEL 事件
 a| 
请联系技术支持以解决此问题。



 a| 
过去 7 天超过 4 个关键 MEL 条目
 a| 
请联系技术支持以解决此问题。

|===
====
.完成后
您的驱动器固件升级已完成。您可以恢复正常操作。
