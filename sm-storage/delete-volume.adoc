= 在 SANtricity System Manager 中删除卷
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
通常，如果卷是使用错误的参数或容量创建的，不再满足存储配置需求，或者是备份或应用程序测试不再需要的快照映像，则会删除卷。

删除卷会增加池或卷组中的可用容量。您可以选择要删除的一个或多个卷。

.开始之前
在计划删除的卷上，确保以下内容：

* 所有数据都已备份。
* 所有输入/输出 (I/O) 均已停止。
* 任何设备和文件系统均已卸载。


.关于此任务
无法删除具有以下条件之一的卷：

* 此卷正在初始化。
* 正在重建此卷。
* 此卷是包含正在执行回写操作的驱动器的卷组的一部分。
* 卷正在进行修改操作，例如更改段大小，除非卷现在处于 Failed 状态。
* 此卷包含任何类型的永久预留。
* 此卷是 Copy Volume 中状态为"待定"、"正在进行"或"失败"的源卷或目标卷。


[CAUTION]
====
删除卷会导致这些卷上的所有数据丢失。

====
[NOTE]
====
当卷超过给定大小（当前为 128 TB）时，正在后台执行删除，释放的空间可能无法立即使用。

====
.步骤
. 选择菜单：Storage[Volumes]。
. 单击 *Delete*。
+
此时将显示"删除卷"对话框。

. 选择要删除的一个或多个卷，并确认要执行此操作。
. 单击 *Delete*。


.结果
System Manager 执行以下操作：

* 删除所有关联的快照映像、计划和快照卷。
* 删除所有镜像关系。
* 增加池或卷组中的可用容量。
