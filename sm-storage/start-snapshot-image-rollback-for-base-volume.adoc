= 在 SANtricity System Manager 中启动基础卷的快照映像回滚
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
可以执行回滚操作，以更改基本卷的内容，使其与 Snapshot 映像中保存的内容相匹配。

回滚操作不会改变与基本卷相关联的 snapshot 映像的内容。

.开始之前
* 有足够的保留容量可用于启动回滚操作。
* 选定的快照映像为最佳，选定的卷为最佳。
* 所选卷没有正在进行的回滚操作。


.关于此任务
回滚启动顺序允许您在基本卷的快照映像上开始回滚，同时提供添加存储容量的选项。一次不能为基本卷启动多个回滚操作。

[NOTE]
====
主机可以立即访问新的回滚基本卷，但在回滚开始后，现有的基本卷不允许主机读写访问。您可以在开始回滚之前创建基本卷的 Snapshot，以保留用于恢复的预回滚基本卷。

====
.步骤
. 选择菜单：Storage[Snapshots]。
. 选择 *Snapshot Images* 选项卡。
. 选择 Snapshot 映像，然后选择菜单：Rollback[Start]。
+
此时将显示"确认开始回滚"对话框。

. *可选：* 如有必要，选择 *Increase Capacity* 选项。
+
此时将显示"增加保留容量"对话框。

+
.. 使用微调框调整容量百分比。
+
如果包含所选存储对象的池或卷组上不存在可用容量，且存储阵列具有未分配容量，则可以添加容量。您可以创建新的池或卷组，然后使用该池或卷组上的新可用容量重试此操作。

.. 单击 *Increase*。


. 确认您要执行此操作，然后单击 *Rollback*。


.结果
System Manager 执行以下操作：

* 使用选定快照映像上保存的内容还原卷。
* 使回滚卷立即可用于主机访问。无需等待回滚操作完成。


.完成后
选择菜单：Home[View Operations in Progress] 以查看回滚操作的进度。

如果回滚操作不成功，则操作暂停。您可以恢复暂停的操作，如果仍然不成功，请按照 Recovery Guru 程序更正问题或联系技术支持。
