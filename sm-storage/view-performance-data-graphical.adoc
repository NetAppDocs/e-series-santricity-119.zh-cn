= 在 SANtricity System Manager 中查看图形性能数据
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以查看逻辑对象、物理对象、应用程序和工作负载的图形性能数据。

.关于此任务
性能图表显示历史数据以及当前正在捕获的实时数据。图表上标有 Live updating 的垂直线将历史数据与实时数据区分开来。

*主页视图*

主页包含一个显示存储阵列级别性能的图表。您可以从此视图中选择有限的指标，也可以单击 *View Performance Details* 以选择所有可用的指标。

*详细视图*

详细性能视图中提供的图表排列在三个选项卡下：

* *Logical View* -- 显示按卷组和池分组的逻辑对象的性能数据。逻辑对象包括卷组、池和卷。
* *物理视图* -- 显示控制器、主机通道、驱动器通道和驱动器的性能数据。
* *Applications & Workloads View* -- 显示按您定义的应用程序类型和工作负载分组的逻辑对象（卷）列表。


.步骤
. 选择 *Home*。
. 要选择阵列级视图，请单击 IOPS、MiB/s 或 CPU 按钮。
. 要查看更多详细信息，请单击 *View Performance Details*。
. 选择 *Logical View* 选项卡、*Physical View* 选项卡或 *Applications & Workloads View* 选项卡。
+
根据对象类型，每个选项卡中都会显示不同的图形。

+
[cols="25h,~"]
|===
| 查看选项卡 | 为每种对象类型显示的性能数据 


 a| 
逻辑视图
 a| 
** *存储阵列*：IOPS、MiB/s
** *池*：延迟、IOPS、MiB/s
** *卷组*：延迟、IOPS、MiB/s
** *卷*：延迟、IOPS、MiB/s




 a| 
物理视图
 a| 
** *控制器*：IOPS、MiB/s、CPU、Headroom
** *主机通道*：延迟、IOPS、MiB/s、净空
** *驱动器通道*：延迟、IOPS、MiB/s
** *驱动器*：延迟、IOPS、MiB/s




 a| 
应用程序和工作负载视图
 a| 
** *存储阵列*：IOPS、MiB/s
** *Applications*：延迟、IOPS、MiB/s
** *工作负载*：延迟、IOPS、MiB/s
** *卷*：延迟、IOPS、MiB/s


|===
. 使用选项可查看所需的对象和信息。
+
.选项
[%collapsible]
====
[cols="25h,~"]
|===
| 查看对象的选项 | 说明 


 a| 
展开抽屉可查看对象列表。
 a| 
_Navigation drawers_ 包含存储对象，例如池、卷组和驱动器。

单击抽屉可查看抽屉中的对象列表。



 a| 
选择要查看的对象。
 a| 
选中每个对象左侧的复选框，以选择要查看的性能数据。



 a| 
使用 Filter 查找对象名称或部分名称。
 a| 
在"筛选器"框中，输入对象的名称或部分名称，以仅列出抽屉中的对象。



 a| 
选择对象后，单击 *刷新图形*。
 a| 
从抽屉中选择对象后，选择 *刷新图形* 以查看选定项目的图形数据。



 a| 
隐藏或显示图形
 a| 
选择图形标题以隐藏或显示图形。

|===
====
. 根据需要，使用其他选项查看性能数据。
+
.其他选项
[%collapsible]
====
[cols="25h,~"]
|===
| 选项 | 说明 


 a| 
时间范围
 a| 
选择要查看的时间长度（5 分钟、1 小时、8 小时、1 天、7 天或 30 天）。默认值为 1 小时。


NOTE: 加载 30 天时间范围内的性能数据可能需要几分钟的时间。加载数据时，请勿离开网页、刷新网页或关闭浏览器。



 a| 
数据点详细信息
 a| 
将光标悬停在图形上可查看特定数据点的指标。



 a| 
滚动条
 a| 
使用图形下方的滚动条可查看较早或较晚的时间跨度。



 a| 
缩放栏
 a| 
在图形下方，拖动缩放条手柄以缩小时间范围。缩放条越宽，图形细节的粒度越小。

要重置图形，请选择一个时间范围选项。



 a| 
拖放
 a| 
在图形上，将光标从一个时间点拖动到另一个时间点以放大时间范围。

要重置图形，请选择一个时间范围选项。

|===
