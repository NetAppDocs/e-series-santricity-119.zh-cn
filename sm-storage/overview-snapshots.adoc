通过 Snapshot 功能，您可以创建用于备份或测试的存储阵列卷的时间点映像。



== 什么是快照映像？

_快照映像_是在特定时间点捕获的卷数据的逻辑副本。像还原点一样，快照映像允许您回滚到已知良好的数据集。虽然主机可以访问快照映像，但不能直接读写。

* link:snapshot-terminology.html["Snapshot 术语"]

* link:snapshot-schedules-and-snapshot-consistency-groups.html["快照计划和一致性组"]
* link:snapshot-volumes.html["Snapshot 卷"]




== 如何创建快照？

您可以从基本卷或快照一致性组手动创建快照映像。此过程可从菜单：Storage[Snapshots] 中获得。

== 如何从快照回滚数据？

_rollback_ 是将基本卷中的数据返回到上一个时间点的过程。您可以从菜单：Storage[Snapshots] 中回滚快照数据。
