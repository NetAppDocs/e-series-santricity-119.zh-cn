= 在 SANtricity System Manager 中创建主机集群
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当两个或多个主机需要对同一卷进行 I/O 访问时，可以创建主机群集。

.关于此任务
创建主机集群时，请记住以下准则：

* 除非有两个或多个主机可用于创建集群，否则此操作不会启动。
* 主机群集中的主机可以使用不同的操作系统（异构）。
* 主机集群中的 NVMe 主机无法与非 NVMe 主机混合。
* 要创建启用 Data Assurance (DA) 的卷，您计划使用的主机连接必须支持 DA。
+
如果存储阵列中控制器上的任何主机连接不支持 DA，则关联的主机无法访问启用 DA 的卷上的数据。

* 如果您选择的名称已在使用中，此操作将不会成功。
* 名称长度不能超过 30 个字符。


.步骤
. 选择菜单：Storage[Hosts]。
. 选择菜单：Create[Host Cluster]。
+
此时将显示"创建主机群集"对话框。

. 根据需要选择主机集群的设置。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
名称
 a| 
键入新主机集群的名称。



 a| 
选择要共享卷访问权限的主机
 a| 
从下拉列表中选择两个或多个主机。只有那些尚未成为主机集群一部分的主机才会显示在列表中。

|===
====
. 单击 *Create*。
+
如果所选主机连接到具有不同 Data Assurance (DA) 功能的接口类型，则会出现一个对话框，其中显示 DA 在主机群集上不可用。此不可用性可防止将启用了 DA 的卷添加到主机群集中。选择 *Yes* 继续，或选择 *No* 取消。

+
DA 提高了整个存储系统的数据完整性。DA 使存储阵列能够检查在主机和驱动器之间移动数据时可能发生的错误。对新卷使用 DA 可确保检测到任何错误。



.结果
新主机群集显示在表中，分配的主机位于下方的行中。
