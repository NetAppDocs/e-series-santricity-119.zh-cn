= 了解 SANtricity 软件中的主机术语
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
了解主机术语如何适用于您的存储阵列。

[cols="25h,~"]
|===
| 组件 | 定义 


 a| 
主机
 a| 
主机是向存储阵列上的卷发送 I/O 的服务器。



 a| 
主机名
 a| 
主机名应等同于主机的系统名称。



 a| 
主机集群
 a| 
主机集群是一组主机。您可以创建主机集群，以便轻松地将相同的卷分配给多个主机。



 a| 
主机接口协议
 a| 
主机接口协议是控制器与主机之间的连接（例如光纤通道、iSCSI 等）。



 a| 
HBA 或网络接口卡 (NIC)
 a| 
主机总线适配器 (HBA) 是驻留在主机中的主板，包含一个或多个主机端口。



 a| 
主机端口
 a| 
主机端口是主机总线适配器 (HBA) 上的端口，它提供与控制器的物理连接，并用于 I/O 操作。



 a| 
主机端口标识符
 a| 
主机端口标识符是与主机总线适配器 (HBA) 上的每个主机端口相关联的唯一全球名称。

* Internet Small Computer System Interface (iSCSI) 主机端口标识符必须介于 1 到 233 个字符之间。iSCSI 主机端口标识符以标准 IQN 格式显示（例如， `iqn.xxx.com.xxx:8b3ad`）。
* 非 iSCSI 主机端口标识符（如光纤通道和串行连接 SCSI (SAS)）在每两个字符后显示为冒号分隔（例如， `xx:yy:zz`）。光纤通道主机端口标识符必须有 16 个字符。




 a| 
主机操作系统类型
 a| 
主机操作系统类型是一种配置设置，用于定义存储阵列中的控制器对 I/O 的反应方式，具体取决于主机的操作系统（或变体）。这有时也简称为 _host type_。



 a| 
控制器主机端口
 a| 
控制器主机端口是控制器上的一个端口，用于提供与主机的物理连接，并用于 I/O 操作。



 a| 
LUN
 a| 
逻辑单元号 (LUN) 是分配给主机用于访问卷的地址空间的编号。此卷以 LUN 的形式作为容量呈现给主机。

每个主机都有自己的 LUN 地址空间。因此，不同的主机可以使用相同的 LUN 来访问不同的卷。

|===
