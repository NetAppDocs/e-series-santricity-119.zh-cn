= 更改 SANtricity System Manager 中卷的缓存设置
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以更改读缓存和写缓存设置，以影响卷的整体 I/O 性能。

.关于此任务
更改卷的缓存设置时，请记住以下准则：

* 打开"更改缓存设置"对话框后，您可能会看到选定缓存属性旁边显示的图标。此图标指示控制器已暂时暂停缓存操作。
+
当新电池正在充电、控制器已被移除或控制器检测到缓存大小不匹配时，可能会发生此操作。条件清除后，对话框中选择的缓存属性将变为活动状态。如果所选缓存属性未处于活动状态，请联系技术支持。

* 您可以更改存储阵列上单个卷或多个卷的缓存设置。您可以同时更改所有标准卷或所有精简卷的缓存设置。


.步骤
. 选择菜单：Storage[Volumes]。
. 选择任何卷，然后选择菜单：更多[更改缓存设置]。
+
此时将显示"更改缓存设置"对话框。此对话框中将显示存储阵列上的所有卷。

. 选择 *Basic* 选项卡以更改读缓存和写缓存的设置。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 缓存设置 | 说明 


 a| 
读取缓存
 a| 
读缓存是存储已从驱动器读取的数据的缓冲区。读取操作的数据可能已经存在于先前操作的缓存中，因此无需访问驱动器。数据保留在读缓存中，直到刷新为止。



 a| 
写缓存
 a| 
写缓存是存储来自主机尚未写入驱动器的数据的缓冲区。数据将保留在写缓存中，直到写入驱动器。写缓存可以提高 I/O 性能。


NOTE: 禁用卷的 *Write caching* 后，缓存会自动刷新。

|===
====
. 选择 *Advanced* 选项卡以更改厚卷的高级设置。高级缓存设置仅适用于厚卷。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 缓存设置 | 说明 


 a| 
动态读缓存预取
 a| 
动态缓存读取预取允许控制器在将数据块从驱动器读取到缓存时将额外的顺序数据块复制到缓存中。这种缓存增加了将来从缓存中填充数据请求的可能性。动态缓存读取预取对于使用顺序 I/O 的多媒体应用程序非常重要。预取到缓存的数据速率和数量是根据主机读取的速率和请求大小自行调整的。随机访问不会导致数据被预取到缓存中。禁用读缓存时，此功能不适用。

对于精简卷，动态缓存读取预取始终被禁用且无法更改。



 a| 
不使用电池的写缓存
 a| 
没有电池的写缓存设置允许写缓存继续，即使电池丢失、故障、完全放电或未完全充电。通常不建议选择没有电池的写缓存，因为如果断电，数据可能会丢失。通常，控制器会暂时关闭写缓存，直到电池充电或更换故障电池。


CAUTION: *可能丢失数据* -- 如果选择此选项并且没有通用电源进行保护，则可能会丢失数据。此外，如果您没有控制器电池并启用 *Write caching without batteries* 选项，则可能会丢失数据。

此设置仅在启用写缓存时可用。此设置不适用于精简卷。



 a| 
使用镜像写入缓存
 a| 
当写入一个控制器的缓存内存的数据也写入另一个控制器的缓存内存时，将发生镜像写入缓存。因此，如果一个控制器发生故障，另一个控制器可以完成所有未完成的写入操作。仅当写缓存已启用且存在两个控制器时，写缓存镜像才可用。使用镜像进行写缓存是创建卷时的默认设置。

此设置仅在启用写缓存时可用。此设置不适用于精简卷。

|===
====
. 单击 *Save* 以更改缓存设置。
