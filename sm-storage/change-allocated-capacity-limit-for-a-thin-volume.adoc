= 更改 SANtricity System Manager 中精简卷的已分配容量限制
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
对于能够按需分配空间的精简卷，您可以更改限制分配容量的限制，精简卷可以自动扩展到该容量。

当精简卷接近分配的容量限制时，您还可以更改将警报（超过警告阈值）发送到 Home 页面上 Notifications 区域的百分比点。您可以选择启用或禁用此警报通知。

[NOTE]
====
此功能在 EF600/EF600C 或 EF300/EF300C 存储系统中不可用。

====
系统会根据分配的容量限制自动扩展分配的容量。分配的容量限制允许您将精简卷的自动增长限制在报告的容量以下。当写入数据量接近分配容量时，可以更改分配容量限制。

更改精简卷的分配容量限制和警告阈值时，必须考虑卷的用户数据和复制服务数据要消耗的空间。

.步骤
. 选择菜单：Storage[Volumes]。
. 选择 *Thin Volume Monitoring* 选项卡。
+
此时将显示精简卷监控视图。

. 选择要更改的精简卷，然后选择 *Change Limit*。
+
此时将显示"更改限制"对话框。此对话框中将显示所选精简卷的已分配容量限制和警告阈值设置。

. 根据需要更改分配的容量限制和警告阈值。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
将分配的容量限制更改为...
 a| 
写入失败的阈值，防止精简卷消耗额外资源。此阈值是卷的报告容量大小的百分比。



 a| 
在...时提醒我（警告阈值）
 a| 
如果希望系统在精简卷接近分配容量限制时生成警报，请选中此复选框。警报将发送到主页上的"通知"区域。此阈值是卷的报告容量大小的百分比。

清除复选框以禁用警告阈值警报通知。

|===
====
. 单击 *Save*。
