= 了解 SANtricity System Manager 中的性能图表和准则
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
性能页面提供数据图形和表格，可用于评估存储阵列在几个关键领域的性能。

性能函数允许您完成以下任务：

* 近乎实时地查看性能数据，以帮助您确定存储阵列是否遇到问题。
* 导出性能数据以构建存储阵列的历史视图，并确定问题何时开始或导致问题的原因。
* 选择要查看的对象、性能指标和时间范围。
* 比较指标。


您可以以三种格式查看性能数据：

* *实时图形* -- 近乎实时地在图形上绘制性能数据。
* *近实时表格* -- 在表中近实时列出性能数据。
* *导出的 CSV 文件* -- 允许您将表格性能数据保存在逗号分隔值的文件中，以便进一步查看和分析。

[[guidelines-for-viewing-performance-data]]
== 查看性能数据的指南

* 性能数据收集始终处于开启状态。没有关闭的选项。
* 每次采样间隔过后，都会查询存储数组并更新数据。
* 对于图形数据，5 分钟时间范围支持 10 秒更新，平均时间为 5 分钟。所有其他时间范围每 5 分钟更新一次，在所选时间范围内平均。
* 图形视图中的性能数据会实时更新。表视图中的性能数据近乎实时更新。
* 如果被监控对象在收集数据期间发生变化，则该对象可能没有跨越所选时间范围的完整数据点集。例如，卷集可以在创建、删除、分配或取消分配卷时更改；或者可以添加、删除驱动器或驱动器发生故障。
