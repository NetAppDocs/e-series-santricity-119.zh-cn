= 在 SANtricity System Manager 中删除远程存储对象
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
导入完成后，如果您不再希望在本地和远程设备之间复制数据，则可以删除远程存储对象。

.开始之前
确保没有导入与您计划删除的远程存储对象关联。

.关于此任务
删除远程存储对象时，将删除本地和远程设备之间的连接。

.步骤
. 选择菜单：Storage[Remote storage]。
. 从列表中选择要删除的远程存储对象。
. 单击 *Remove*。
+
此时将显示确认删除远程存储连接对话框。

. 键入 `remove`确认操作，然后单击*删除*。
+
已删除所选远程存储对象。
