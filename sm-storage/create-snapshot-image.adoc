= 在 SANtricity System Manager 中创建快照映像
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以从基本卷或快照一致性组手动创建快照映像。这也称为 _即时快照_ 或 _即时映像_。

.开始之前
* 基础卷必须是最佳的。
* 驱动器必须处于最佳状态。
* 无法将快照组指定为"`reserved.`"
* 保留容量卷必须具有与快照组的关联基本卷相同的 Data Assurance (DA) 设置。


.步骤
. 请执行以下操作之一以创建快照映像：
+
** 选择菜单：Storage[Volumes]。选择对象（基本卷或快照一致性组），然后选择菜单：Copy Services[Create instant snapshot]。
** 选择菜单：Storage[Snapshots]。选择 *Snapshot Images* 选项卡，然后选择菜单：Create[Instant snapshot]。
+
此时将显示创建快照图像对话框。选择对象（基本卷或快照一致性组），然后单击 *下一步*。如果为卷或快照一致性组创建了以前的快照图像，则系统会立即创建即时快照。否则，如果这是第一次为卷或快照一致性组创建快照图像，则将显示确认创建快照图像对话框。



. 单击 *Create* 以接受需要保留容量的通知，并继续执行 Reserve Capacity 步骤。
+
此时将显示"保留容量"对话框。

. 使用微调框调整容量百分比，然后单击 *Next* 以接受表中突出显示的候选卷。
+
此时将显示"编辑设置"对话框。

. 根据需要选择快照映像的设置，并确认要执行此操作。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
*Snapshot 图像设置*



 a| 
Snapshot 图像限制
 a| 
如果要在指定限制后自动删除快照图像，请选中此复选框；使用旋转框更改限制。如果清除此复选框，快照图像创建将在 32 个图像后停止。



 a| 
*保留容量设置*



 a| 
在...时提醒我
 a| 
使用微调框可调整系统在快照组的保留容量接近满时发送警报通知的百分比点。

当快照组的保留容量超过指定阈值时，请使用提前通知来增加保留容量或在剩余空间用完之前删除不必要的对象。



 a| 
完全保留容量的政策
 a| 
从下列策略中选择一项：

** *清除最旧的快照映像* -- 系统会自动清除快照组中最旧的快照映像，从而释放快照映像保留容量，以便在组内重复使用。
** *拒绝对基本卷的写入* -- 当保留容量达到其最大定义百分比时，系统会拒绝对触发保留容量访问的基本卷的任何 I/O 写入请求。


|===
====


.结果
* System Manager 在"快照图像"表中显示新的快照图像。该表按时间戳和关联的基本卷或快照一致性组列出了新映像。
* 由于以下条件，快照创建可能保持"挂起"状态：
+
** 包含此快照映像的基本卷是异步镜像组的成员。
** 基本卷当前处于同步操作中。快照映像创建在同步操作完成后立即完成。
