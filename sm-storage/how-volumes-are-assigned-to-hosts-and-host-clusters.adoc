= 如何在 SANtricity 软件中将卷分配给主机和主机群集
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要使主机或主机群集向卷发送 I/O，必须将该卷分配给主机或主机群集。

您可以在创建卷时选择主机或主机群集，也可以稍后将卷分配给主机或主机群集。主机群集是一组主机。您可以创建主机群集，以便轻松地将相同的卷分配给多个主机。

您可以灵活地为主机分配卷，从而满足特定的存储需求。

* *独立主机，不属于主机群集* -- 您可以将卷分配给单个主机。该卷只能由一台主机访问。
* *主机集群* -- 您可以将卷分配给主机集群。主机集群中的所有主机都可以访问该卷。
* *主机群集中的主机* -- 您可以将卷分配给作为主机群集一部分的单个主机。即使主机是主机群集的一部分，卷只能由单个主机访问，而不能由主机群集中的任何其他主机访问。


创建卷时，将自动分配逻辑单元号 (LUN)。在 I/O 操作期间，LUN 充当主机和控制器之间的"地址"。可以在创建卷后更改 LUN。
