= 在 SANtricity System Manager 中创建卷组
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用卷组创建一个或多个可供主机访问的卷。卷组是具有 RAID 级别和容量等共享特性的卷的容器。

凭借更大容量的驱动器和跨控制器分配卷的能力，为每个卷组创建多个卷是利用存储容量和保护数据的好方法。

.开始之前
在创建卷组之前，请查看以下指导原则：

* 您至少需要一个未分配的驱动器。
* 单个卷组中可以拥有的驱动器数量存在限制。这些限制会根据 RAID 级别而有所不同。
* 要启用货架/抽屉丢失保护，您必须创建一个使用至少位于三个货架或抽屉中的驱动器的卷组，除非您使用 RAID 1，其中两个货架/抽屉是最低要求。
* 如果您有 EF600 或 EF300 存储阵列，并且您计划手动创建卷组，请确保每个控制器可以访问前 12 个插槽中的相同数量的驱动器以及最后 12 个插槽中的相同数量的驱动器。此配置可帮助控制器更有效地使用驱动器端 PCIe 总线。当前 System Manager 允许在创建卷组时在高级功能下选择驱动器。
* 查看您选择的 RAID 级别如何影响卷组的生成容量：
+
** 如果选择 RAID 1，则必须一次添加两个驱动器，以确保选择了镜像对。镜像和条带化（称为 RAID 10 或 RAID 1+0）是在选择四个或更多驱动器时实现的。
** 如果选择 RAID 5，则必须添加至少三个驱动器才能创建卷组。
** 如果选择 RAID 6，则必须添加至少五个驱动器才能创建卷组。




.步骤
. 选择菜单：Storage[Pools & Volume Groups]。
. 单击菜单：Create[Volume group]。
+
此时将显示创建卷组对话框。

. 键入此卷组的名称。
. 选择最能满足数据存储和保护要求的 RAID 级别。
+
此时将显示卷组候选项表，并仅显示支持选定 RAID 级别的候选项。

. *可选：*如果您的存储阵列中有多个类型的驱动器，请选择要使用的驱动器类型。
+
此时将显示卷组候选项表，并仅显示支持选定驱动器类型和 RAID 级别的候选项。

. *可选：*您可以选择自动方法或手动方法来定义要在卷组中使用的驱动器。自动方法是默认选择。
+
要手动选择驱动器，请单击*手动选择驱动器（高级）*链接。单击后，它会变为*自动选择驱动器（高级）*。

+
Manual 方法允许您选择哪些特定驱动器构成卷组。您可以选择特定的未分配驱动器来获得所需的容量。如果存储阵列包含具有不同介质类型或不同接口类型的驱动器，则只能为单个驱动器类型选择未配置的容量来创建新的卷组。

+
[NOTE]
====
只有了解驱动器冗余和最佳驱动器配置的专家才能使用 Manual 方法。

====
. 根据显示的驱动器特性，选择要在卷组中使用的驱动器，然后单击 *创建*。
+
显示的驱动器特性取决于您选择的是自动方法还是手动方法。

+
.自动方法驱动特性
[%collapsible]
====
[cols="25h,~"]
|===
| 特征 | 用途 


 a| 
空闲容量
 a| 
以 GiB 为单位显示可用容量。选择具有满足应用程序存储需求的容量的卷组候选项。



 a| 
驱动器总数
 a| 
显示此卷组可用的驱动器数量。请选择具有所需驱动器数量的卷组候选项。



 a| 
驱动器块尺寸（仅限 EF300 和 EF600）
 a| 
显示组中的驱动器可写入的块大小（扇区大小）。值可能包括：

** 512 -- 512 字节扇区大小。
** 4K -- 4,096 字节扇区大小。




 a| 
支持安全功能
 a| 
指示此卷组候选项是否完全由支持安全的驱动器组成，这些驱动器可以是全磁盘加密 (FDE) 驱动器或联邦信息处理标准 (FIPS) 驱动器。

** 您可以使用 Drive Security 保护卷组，但所有驱动器必须具有安全功能才能使用此功能。
** 如果要创建仅限 FDE 的卷组，请在"支持安全"列中查找 *Yes - FDE*。如果要创建仅限 FIPS 的卷组，请查找 *Yes - FIPS* 或 *Yes - FIPS (Mixed)*。"Mixed" 表示 140-2 和 140-3 级别驱动器的混合。如果使用这些级别的混合，请注意，卷组将在较低的安全级别 (140-2) 下运行。
** 您可以创建一个由驱动器组成的卷组，这些驱动器可能具有安全功能，也可能不具有安全功能，或者是安全级别的混合。如果卷组中的驱动器包括不支持安全功能的驱动器，则无法使卷组安全。




 a| 
启用安全？
 a| 
提供使用具有安全功能的驱动器启用 Drive Security 功能的选项。如果卷组具有安全功能，并且您已设置安全密钥，则可以通过选中复选框来启用 Drive Security。


NOTE: 启用 Drive Security 后，将其删除的唯一方法是删除卷组并擦除驱动器。



 a| 
支持 DA
 a| 
指示此组是否可用 Data Assurance (DA)。Data Assurance (DA) 检查并更正数据通过控制器传输到驱动器时可能发生的错误。

如果要使用 DA，请选择支持 DA 的卷组。（对于支持 DA 的驱动器，会在池中创建的卷上自动启用 DA。）

卷组可以包含支持 DA 或不支持 DA 的驱动器，但所有驱动器都必须支持 DA 才能使用此功能。



 a| 
支持资源调配（仅限 EF300 和 EF600）
 a| 
显示资源调配是否可用于此组。资源调配是 EF300 和 EF600 存储阵列中提供的一项功能，它允许卷立即投入使用，而无需后台初始化过程。



 a| 
磁盘架丢失保护
 a| 
显示盘架丢失保护是否可用。盘架丢失保护可保证在发生与盘架的完全通信丢失时可访问卷组中的卷上的数据。



 a| 
抽屉丢失保护
 a| 
显示抽屉丢失保护是否可用，仅当您使用包含抽屉的驱动器架时提供。抽屉丢失保护可保证在与驱动器架中的单个抽屉完全失去通信时对卷组中卷上的数据的可访问性。



 a| 
支持的卷块大小（仅限 EF300 和 EF600）
 a| 
显示可以为组中的卷创建的块大小：

** 512n -- 原生 512 字节。
** 512e -- 模拟 512 字节。
** 4K -- 4,096 字节。
