= 了解如何在 SANtricity System Manager 中手动创建主机
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
创建主机是让存储阵列知道哪些主机连接到它并允许对卷进行 I/O 访问所需的步骤之一。您只能手动创建主机。



== 手动创建

手动创建主机允许您确保存储阵列控制器检测到的主机端口标识符与主机正确关联。

在手动创建主机期间，您可以通过从列表中选择或手动输入主机端口标识符来关联主机端口标识符。创建主机后，如果计划共享对卷的访问权限，则可以为其分配卷或将其添加到主机群集中。
