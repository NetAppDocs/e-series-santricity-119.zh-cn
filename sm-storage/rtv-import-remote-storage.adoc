= 在 SANtricity System Manager 中导入远程存储
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要启动从远程系统到本地 E 系列存储系统的存储导入，请使用导入远程存储向导。

.开始之前
* 必须将 E 系列存储系统配置为与远程存储系统通信。
+
[NOTE]
====
硬件配置在远程存储功能的用户指南中进行了描述，该指南可从 E 系列和 SANtricity 文档中心获取，网址为 https://docs.netapp.com/us-en/e-series/remote-storage-volumes/setup-remote-volumes-concept.html["配置硬件"^]，以及在 https://www.netapp.com/pdf.html?item=/media/28697-tr-4893-deploy.pdf["远程存储技术报告"^]中。

====
* 对于远程存储系统，收集以下信息：
+
** iSCSI IQN
** iSCSI IP 地址
** 远程存储设备的 LUN 编号（源卷）


* 对于本地 E 系列存储系统，请创建或选择要用于数据导入的卷。请参阅 link:create-volumes.html["创建卷"]。目标卷必须满足以下要求：
+
** 匹配远程存储设备的块大小（源卷）。
** 容量等于或大于远程存储设备。
** 状态为 Optimal 且可用。




有关要求的完整列表，请参见 link:rtv-remote-storage-volume-requirements.html["远程存储卷要求"]。

* *建议：*在开始导入过程之前，请备份远程存储系统上的卷。


.关于此任务
在此任务中，您将在远程存储设备和本地 E 系列存储系统上的卷之间创建映射。完成配置后，导入开始。

[NOTE]
====
由于许多变量会影响导入操作及其完成时间，因此我们建议您首先执行较小的 "`test`" 导入。使用这些测试可确保所有连接按预期工作，并确保导入操作在适当的时间内完成。

====
.步骤
. 选择菜单：Storage[Remote storage]。
. 单击 *Import Remote Storage* 。
+
此时将显示用于导入远程存储的向导。

. 在"配置源"面板的 *步骤 1a* 中，输入连接信息。如果要添加其他 iSCSI 连接，请单击 *添加其他 IP 地址* 以包括远程存储的其他 IP 地址。完成后，单击 *下一步*。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
名称
 a| 
输入远程存储设备的名称，以便在 System Manager 界面中对其进行标识。

一个名称最多可包含 30 个字符，并且只能包含字母、数字和以下特殊字符：下划线 (_)、短划线 (-) 和哈希符号 (#)。名称不能包含空格。



 a| 
iSCSI 连接属性
 a| 
输入远程存储设备的连接属性：

** *iSCSI 限定名称 (IQN)*：输入 iSCSI IQN。
** *IP 地址*：输入 IPv4 地址。
** *Port*：输入要用于源和目标设备之间通信的端口号。默认情况下，端口号为 3260。


|===
====
+
单击 *Next*（下一步）后，将显示 Configure Source（配置源）面板的 *Step 1b*（步骤 1b）。

. 在 *LUN* 字段中，选择要用作源的远程存储设备的 LUN 编号，然后单击 *Next*。
+
Configure Target（配置目标）面板打开并显示要作为导入目标的卷候选项。由于块大小、容量或卷可用性，某些卷不会显示在候选项列表中。

. 从表中选择 E 系列存储系统上的目标卷。如果需要，使用滑块更改导入优先级。单击*下一步*。通过键入 `continue`在下一个对话框中确认操作，然后单击*继续*。
+
如果目标卷的容量大于源卷，则不会将该附加容量报告给连接到 E 系列系统的主机。要使用新容量，必须在导入操作完成并断开连接后在主机上执行文件系统扩展操作。

+
在对话框中确认配置后，将显示 Review 面板。

. 在 Review 面板中，验证设置是否准确，然后单击 *Finish* 以启动导入。
+
将打开另一个对话框，询问您是否要启动另一个导入。

. 如果需要，请单击*是*以创建另一个远程存储导入。单击*是*返回到配置源面板的*步骤 1a*，您可以在其中选择现有配置或添加新配置。如果不想创建另一个导入，请单击*否*退出对话框。
+
导入过程开始后，整个目标卷将被复制的数据覆盖。如果主机在此过程中将任何新数据写入目标卷，则该新数据将传播回远程设备（源卷）。

. 在 Remote Storage 面板下的 View Operations 对话框中查看操作进度。


.结果
完成导入操作所需的时间取决于远程存储系统的大小、导入的优先级设置以及两个存储系统及其关联卷上的 I/O 负载量。

导入完成后，本地卷将成为远程存储设备的副本。

.完成后
当您准备好中断两个卷之间的关系时，从"正在进行的操作"视图中选择导入对象上的*断开连接*。关系断开后，本地卷的性能将恢复正常，并且不再受远程连接的影响。
