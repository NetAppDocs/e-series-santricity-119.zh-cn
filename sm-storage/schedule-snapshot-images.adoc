= 在 SANtricity System Manager 中计划快照映像
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以创建快照计划，以便在基本卷出现问题时启用恢复并执行计划备份。基本卷或快照一致性组的快照可以在一天中的任何时间按每日、每周或每月计划创建。

.开始之前
基本卷必须为 Optimal。

.关于此任务
此任务描述如何为现有 Snapshot 一致性组或基本卷创建 Snapshot 计划。

[NOTE]
====
您还可以在创建基本卷或 Snapshot 一致性组的 Snapshot 映像的同时创建 Snapshot 计划。

====
.步骤
. 请执行以下操作之一来创建 Snapshot 计划：
+
** 选择菜单：Storage[Volumes]。
+
为此 Snapshot 计划选择对象（卷或 Snapshot 一致性组），然后选择菜单：复制服务[创建 Snapshot 计划]。

** 选择菜单：Storage[Snapshots]。
+
选择 *Schedules* 选项卡，然后单击 *Create*。



. 选择此 Snapshot 计划的对象（卷或 Snapshot 一致性组），然后单击 *Next*。
+
此时将显示"创建 Snapshot 计划"对话框。

. 请执行以下操作之一：
+
** *使用另一个 Snapshot 对象中先前定义的计划*。
+
确保显示高级选项。单击*显示更多选项*。单击*Import Schedule*，选择要导入的带有计划的对象，然后单击*Import*。

** *修改基本或高级选项*。
+
在对话框右上角，单击 *Show more options* 以显示所有选项，然后参阅下表。



+
.字段详细信息

 a|

 a|

 a| 
开始时间
 a| 
从下拉列表中，为每日 Snapshot 选择新的开始时间（以半小时为间隔提供选择）。默认情况下，开始时间比当前时间提前半小时。



 a|

 a|

 a|

 a| 
从下列选项中选择一项：

** *每日/每周* -- 为同步快照选择单个日期。如果您想要每日计划，也可以选择右上角的 *选择所有日期* 复选框。
** *每月/每年* -- 选择用于同步快照的个别月份。在 *On day(s)* 字段中，输入每月进行同步的日期。有效输入为 *1* 至 *31* 和 *Last*。您可以使用逗号或分号分隔多天。对于包含的日期，请使用连字符。例如：1,3,4,10-15,Last。如果您需要每月计划，也可以选择右上角的 *Select all months* 复选框。




 a| 
开始时间
 a| 
从下拉列表中，为每日 Snapshot 选择新的开始时间（以半小时为间隔提供选择）。默认情况下，开始时间比当前时间提前半小时。



 a| 
Time zone
 a| 
从下拉列表中，选择阵列的时区。



 a| 
每天 Snapshot 数 / Snapshot 之间的时间
 a| 
选择每天要创建的 snapshot 映像数。如果选择多个，请同时选择 snapshot 映像之间的时间间隔。对于多个 snapshot 映像，请确保您有足够的保留容量。



 a| 
是否立即创建快照映像？
 a| 
选中此复选框可以创建即时映像，这是在您正在计划的自动映像之外额外创建的。



 a| 
开始/结束日期或无结束日期
 a| 
输入开始同步的开始日期。此外，请输入结束日期或选择 *无结束日期*。

|===
====
. 请执行以下操作之一：
+
** 如果对象是 Snapshot 一致性组，请单击*创建*以接受设置并创建 Snapshot 计划。
** 如果对象是卷，请单击 *下一步* 为 Snapshot 映像分配预留容量。
+
卷候选表仅显示支持指定保留容量的候选。保留容量是用于任何复制服务操作和存储对象的物理分配容量。主机无法直接读取。



. 使用微调框为 snapshot 图像分配预留容量。执行以下操作之一：
+
** *接受默认设置。*
+
使用此推荐选项为具有默认设置的 snapshot 图像分配保留容量。

** *分配您自己的预留容量设置，以满足您的数据存储需求。*
+
如果更改默认保留容量设置，请单击 *Refresh Candidates* 以刷新您指定的保留容量的候选列表。

+
使用以下指南分配预留容量：

+
*** 保留容量的默认设置为基本卷容量的 40%。通常这个容量就足够了。
*** 所需的容量因 I/O 写入卷的频率和大小以及快照映像收集的数量和持续时间而异。




. 单击 *Next*。
+
此时将显示"编辑设置"对话框。

. 根据需要编辑 Snapshot 计划的设置，然后单击 *完成* 。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
*Snapshot 映像限制*



 a| 
启用自动删除快照映像时...
 a| 
如果要在指定限制后自动删除快照图像，请选中此复选框；使用旋转框更改限制。如果清除此复选框，快照图像创建将在 32 个图像后停止。



 a| 
*保留容量设置*



 a| 
在...时提醒我
 a| 
使用微调框调整当 Snapshot 计划的预留容量接近满时系统发送警报通知的百分比点。

当计划的保留容量超过指定阈值时，请使用提前通知来增加保留容量或在剩余空间用完之前删除不必要的对象。



 a| 
完全保留容量的政策
 a| 
从下列策略中选择一项：

** *清除最旧的 snapshot 映像* -- 系统会自动清除最旧的 snapshot 映像，从而释放 snapshot 映像保留容量，以便在 snapshot 组内重复使用。
** *拒绝对基本卷的写入* -- 当保留容量达到其最大定义百分比时，系统会拒绝对触发保留容量访问的基本卷的任何 I/O 写入请求。
