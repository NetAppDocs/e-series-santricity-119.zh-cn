= 在 SANtricity System Manager 中更改快照计划的设置
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
对于快照计划，您可以更改自动收集时间或收集频率。

.关于此任务
您可以从现有快照计划导入设置，也可以根据需要修改设置。

由于快照计划与快照组或快照一致性组相关联，因此预留容量可能会受到计划设置更改的影响。

.步骤
. 选择菜单：Storage[Snapshots]。
. 单击 *Schedules* 选项卡。
. 选择要更改的快照计划，然后单击 *Edit*。
+
此时将显示"编辑快照计划"对话框。

. 执行以下操作之一：
+
** *使用另一个快照对象中先前定义的计划* -- 单击 *导入计划*，选择要导入的带有计划的对象，然后单击 *导入*。
** *编辑计划设置* -- 请参阅下面的字段详细信息。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
日 / 月
 a| 
从下列选项中选择一项：

*** *每日/每周* -- 为同步快照选择单个日期。如果您想要每日计划，也可以选择右上角的 *选择所有日期* 复选框。
*** *每月/每年* -- 选择用于同步快照的个别月份。在 *On day(s)* 字段中，输入每月进行同步的日期。有效输入为 *1* 至 *31* 和 *Last*。您可以使用逗号或分号分隔多天。对于包含的日期，请使用连字符。例如：1,3,4,10-15,Last。如果您需要每月计划，也可以选择右上角的 *Select all months* 复选框。




 a| 
开始时间
 a| 
从下拉列表中，为每日快照选择新的开始时间。选择以半小时为增量提供。默认情况下，开始时间比当前时间提前半小时。



 a| 
Time zone
 a| 
从下拉列表中，选择存储阵列的时区。



 a| 
每天快照数

快照之间的时间间隔
 a| 
选择每天要创建的快照映像数。

如果选择多个，请同时选择还原点之间的时间。对于多个还原点，请确保您有足够的保留容量。



 a| 
开始日期

结束日期

无结束日期
 a| 
输入开始同步的开始日期。此外，请输入结束日期或选择 *无结束日期*。

|===
====


. 单击 *Save*。
