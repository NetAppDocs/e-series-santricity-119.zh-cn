= 在 SANtricity System Manager 中激活和暂停快照计划
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当需要节省存储空间时，可以暂时暂停快照图像的计划收集。此方法比删除和稍后重新创建快照计划更有效。

.关于此任务
快照计划的状态保持暂停状态，直到您使用 *Activate* 选项恢复计划的快照活动。

.步骤
. 选择菜单：Storage[Snapshots]。
. 如果尚未显示，请单击 *Schedules* 选项卡。
+
时间表列在页面上。

. 选择要挂起的活动快照计划，然后单击 *Activate / Suspend*。
+
状态列状态变为 *挂起*，快照计划停止收集所有快照图像。

. 要恢复收集快照映像，请选择要恢复的挂起快照计划，然后单击 *激活/挂起*。
+
状态列状态更改为 *Active*。
