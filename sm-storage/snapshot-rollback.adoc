= 了解 SANtricity 软件中的快照回滚
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
回滚操作将基本卷返回到选定 Snapshot 确定的先前状态。

对于回滚，您可以从以下任意源中选择 Snapshot 映像：

* *Snapshot 映像回滚*，用于基本卷的完全恢复。
* *Snapshot 一致性组回滚*，可用于回滚一个或多个卷。


在回滚过程中，Snapshots 功能将保留组中的所有快照图像。如果 I/O 操作需要，它还允许主机在此过程中访问基本卷。

启动回滚时，后台进程扫描基本卷的逻辑块地址 (LBA)，然后在要还原的回滚快照映像中查找写入时复制数据。由于基本卷可供主机访问以进行读取和写入，并且所有以前写入的数据都可以立即使用，因此保留的容量卷必须足够大，以便在处理回滚时包含所有更改。数据传输继续作为后台操作，直到回滚完成。

^1^ 基本卷；^2^ 组中的 Snapshot 对象；^3^ Snapshot 组保留容量
