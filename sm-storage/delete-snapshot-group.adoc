= 在 SANtricity System Manager 中删除快照组
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当要永久删除快照组的数据并将其从系统中删除时，可以删除该快照组。删除快照组将回收池或卷组中可重用的保留容量。

.关于此任务
如果删除某个快照组，则此组中的所有快照映像也将被删除。

.步骤
. 选择菜单：Storage[Pools & Volume Groups]。
. 单击 *Reserved Capacity* 选项卡。
. 选择要删除的快照组，然后单击 menu:Uncommon Tasks[Delete snapshot group]。
+
此时将显示确认删除快照组对话框。

. 键入  `delete` 以确认。


.结果
System Manager 执行以下操作：

* 删除与快照组关联的所有快照映像。
* 禁用与快照组映像关联的任何快照卷。
* 删除快照组的保留容量。
