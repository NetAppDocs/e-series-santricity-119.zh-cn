= 在 SANtricity System Manager 中更改卷的介质扫描设置
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
介质扫描是一种后台操作，用于扫描卷中的所有数据和冗余信息。使用此选项可启用或禁用一个或多个卷的介质扫描设置，或更改扫描持续时间。

.开始之前
了解以下内容：

* 介质扫描根据要扫描的容量和扫描持续时间以恒定速率连续运行。后台扫描可能会被更高优先级的后台任务（例如重建）暂时挂起，但将以相同的恒定速率恢复。
* 仅当为存储阵列和该卷启用了媒体扫描选项时，才会扫描卷。如果该卷也启用了冗余检查，则将检查卷中的冗余信息是否与数据一致，前提是该卷具有冗余。创建每个卷时，默认情况下会启用带冗余检查的媒体扫描。
* 如果在扫描过程中遇到不可恢复的介质错误，将使用冗余信息（如果可用）修复数据。
+
例如，冗余信息在最佳 RAID 5 卷中可用，或者在最佳 RAID 6 卷中可用，或者仅有一个驱动器发生故障。如果无法使用冗余信息修复不可恢复的错误，数据块将被添加到不可读扇区日志中。可更正和不可更正的介质错误都会报告到事件日志中。

+
如果冗余检查发现数据与冗余信息不一致，则将其报告给事件日志。




NOTE: 默认介质扫描周期设置为 120 天。

.关于此任务
介质扫描会检测并修复应用程序不经常读取的磁盘块上的介质错误。这可以在发生驱动器故障时防止数据丢失，因为故障驱动器的数据是使用冗余信息和卷组或池中其他驱动器的数据重建的。

您可以执行以下操作：

* 启用或禁用整个存储阵列的后台媒体扫描
* 更改整个存储阵列的扫描持续时间
* 启用或禁用一个或多个卷的媒体扫描
* 启用或禁用一个或多个卷的冗余检查


.步骤
. 选择菜单：Storage[Volumes]。
. 选择任何卷，然后选择菜单：更多[更改介质扫描设置]。
+
此时将显示更改驱动器介质扫描设置对话框。此对话框中将显示存储阵列上的所有卷。

. 要启用介质扫描，请选中 *Scan media over the course of...* 复选框。
+
禁用介质扫描复选框将暂停所有介质扫描设置。

. 指定希望运行媒体扫描的天数。
. 选中要执行介质扫描的每个卷的 *Media Scan* 复选框。
+
System Manager 为您选择运行媒体扫描的每个卷启用冗余检查选项。如果存在不希望执行冗余检查的单个卷，请取消选中 *Redundancy Check* 复选框。

. 单击 *Save*。
+
System Manager 根据您的选择将更改应用于后台媒体扫描。
