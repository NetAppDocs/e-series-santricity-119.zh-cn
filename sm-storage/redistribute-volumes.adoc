= 在 SANtricity System Manager 中重新分布卷
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
重新分配卷以将卷移回其首选控制器所有者。通常，当主机和存储阵列之间的数据路径出现问题时，多路径驱动程序会从其首选控制器所有者处移动卷。

.开始之前
* 要重新分发的卷未使用，否则将发生 I/O 错误。
* 在使用要重新分发的卷的所有主机上安装多路径驱动程序，否则将发生 I/O 错误。
+
如果要在主机上没有多路径驱动程序的情况下重新分配卷，则必须停止_重新分配操作进行期间_对卷的所有 I/O 活动，以防止应用程序错误。



.关于此任务
大多数主机多路径驱动程序会尝试访问其首选控制器所有者路径上的每个卷。但是，如果此首选路径不可用，主机上的多路径驱动程序会故障转移到备用路径。此故障转移可能会导致卷所有权更改为备用控制器。解决导致故障转移的条件后，某些主机可能会自动将卷所有权移回首选控制器所有者，但在某些情况下，可能需要手动重新分配卷。

.步骤
. 选择菜单：Storage[Volumes]。
. 选择菜单：More[重新分配卷]。
+
此时将显示"重新分配卷"对话框。此对话框中将显示存储阵列上首选控制器所有者与其当前所有者不匹配的所有卷。

. 选择要重新分发的一个或多个卷，并确认要执行此操作。


.结果
System Manager 将选定卷移动到其首选控制器所有者，或者您可能会看到"重新分配卷不必要"对话框。
