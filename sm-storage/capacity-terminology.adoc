= 了解 SANtricity 软件中的容量术语
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
了解容量术语如何适用于您的存储阵列。



[[storage-objects]]
== 存储对象

以下术语描述了可以与存储阵列交互的不同类型的存储对象。

[cols="25h,~"]
|===
| 存储对象 | 说明 


 a| 
主机
 a| 
主机是向存储阵列上的卷发送 I/O 的服务器。



 a| 
LUN
 a| 
逻辑单元号 (LUN) 是分配给主机用于访问卷的地址空间的编号。此卷以 LUN 的形式作为容量呈现给主机。

每个主机都有自己的 LUN 地址空间。因此，不同的主机可以使用相同的 LUN 来访问不同的卷。



 a| 
镜像一致性组
 a| 
镜像一致性组是一个或多个镜像对的容器。对于异步镜像操作，必须创建镜像一致性组。



 a| 
镜像卷对
 a| 
镜像对由两个卷组成，一个主卷和一个辅助卷。



 a| 
池
 a| 
池是逻辑上分组的一组驱动器。您可以使用池创建一个或多个可供主机访问的卷。（您可以从池或卷组创建卷。）



 a| 
快照一致性组
 a| 
快照一致性组是创建快照映像时被视为单个实体的卷集合。每个卷都有自己的快照映像，但所有映像都是在相同的时间点创建的。



 a| 
Snapshot 组
 a| 
快照组是来自单个基本卷的快照图像的集合。



 a| 
Snapshot 卷
 a| 
快照卷允许主机访问快照映像中的数据。快照卷包含其自己的保留容量，该容量可保存对基本卷的任何修改，而不会影响原始快照映像。



 a| 
卷
 a| 
卷是应用程序、数据库和文件系统存储数据的容器。它是为主机创建的逻辑组件，用于访问存储阵列上的存储。



 a| 
卷组
 a| 
卷组是具有共享特征的卷的容器。卷组具有定义的容量和 RAID 级别。您可以使用卷组创建一个或多个可供主机访问的卷。（您可以从卷组或池创建卷。）

|===


[[storage-capacity]]
== 存储容量

以下术语描述了您的存储阵列上使用的不同类型的容量。

[cols="25h,~"]
|===
| 容量类型 | 说明 


 a| 
已分配容量
 a| 
分配的容量是从池或卷组中的驱动器分配的物理容量。

您可以使用分配的容量来创建卷和进行复制服务操作。



 a| 
可用容量
 a| 
可用容量是池或卷组中尚未分配给卷创建或复制服务操作和存储对象的可用容量。



 a| 
池或卷组容量
 a| 
池、卷或卷组容量是指已分配给池或卷组的存储阵列中的容量。此容量用于创建卷并为复制服务操作和存储对象的各种容量需求提供服务。



 a| 
池不可用容量
 a| 
池不可用容量是指由于驱动器大小不匹配而无法使用的池中空间。



 a| 
保存容量
 a| 
保留容量是在池中保留的容量（驱动器数量），用于支持潜在的驱动器故障。



 a| 
已报告容量
 a| 
报告容量是报告给主机并可由主机访问的容量。



 a| 
预留容量
 a| 
保留容量是用于任何复制服务操作和存储对象的物理分配容量。主机无法直接读取。



 a| 
SSD 缓存
 a| 
SSD Cache 是一组固态硬盘 (SSD) 驱动器，您可以在存储阵列中将它们逻辑地组合在一起。SSD Cache 功能将最常访问的数据（"热"数据）缓存到延迟较低的 SSD 驱动器上，以动态加速应用程序工作负载。



 a| 
未分配容量
 a| 
未分配容量是存储阵列中 *未* 分配给池或卷组的空间。



 a| 
写入容量
 a| 
写入容量是从为精简卷分配的预留容量中已写入的容量大小。

|===
