= 了解 SANtricity 软件中的主机和主机集群
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以配置主机和主机群集，它们定义了存储阵列和数据服务器之间的连接。



== 什么是主机和主机集群？

_host_ 是向存储阵列上的卷发送 I/O 的服务器。_host cluster_ 是一组主机，您可以创建这些主机来将相同的卷分配给多个主机。

了解详情：

* link:host-terminology.html["主机术语"]
* link:access-volumes.html["访问卷"]
* link:maximum-number-of-luns.html["LUN 的最大数量"]




== 如何配置主机和主机群集？

要定义主机连接，您可以转到菜单：Storage[Hosts] 手动配置主机。如果您希望两个或多个主机共享对同一卷集的访问权限，则可以定义一个群集并将该卷分配给该群集。
