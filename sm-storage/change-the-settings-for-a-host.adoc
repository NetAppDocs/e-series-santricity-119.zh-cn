= 在 SANtricity System Manager 中更改主机设置
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以更改主机的名称、主机操作系统类型以及关联的主机群集。

.步骤
. 选择菜单：Storage[Hosts]。
. 选择要编辑的主机，然后单击 *View/Edit Settings*。
+
此时将显示一个对话框，显示当前主机设置。

. 如果尚未选择，请单击 *Properties* 选项卡。
. 根据需要更改设置。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
名称
 a| 
您可以更改用户提供的主机名称。必须指定主机的名称。



 a| 
关联的主机集群
 a| 
您可以从以下选项中进行选择：

** *无* -- 主机仍然是独立主机。如果主机与主机集群相关联，则系统会从集群中删除主机。
** *<Host Cluster>* -- 系统将主机与选定集群关联。




 a| 
主机操作系统类型
 a| 
您可以更改在您定义的主机上运行的操作系统类型。

|===
====
. 单击 *Save*。
