= 了解 SANtricity System Manager 中的自动与手动池创建
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以自动或手动创建池以允许对物理存储进行分组，然后根据需要进行动态分配。创建池后，您可以添加物理驱动器。



== 自动创建

当 System Manager 检测到存储阵列中的未分配容量时，将启动自动池创建。检测到未分配容量时，System Manager 会自动提示您创建一个或多个池，或将未分配容量添加到现有池，或两者兼而有之。

当以下条件之一为真时，将自动创建池：

* 池不存在于存储阵列中，并且有足够的类似驱动器来创建新池。
* 新驱动器被添加到至少有一个池的存储阵列。


池中的每个驱动器必须具有相同的驱动器类型（HDD 或 SSD）并具有相似的容量。System Manager 将提示您完成以下任务：

* 如果这些类型的驱动器数量足够，则创建单个池。
* 如果未分配的容量由不同的驱动器类型组成，则创建多个池。
* 如果已在存储阵列中定义了池，则将驱动器添加到现有池中，并将相同驱动器类型的新驱动器添加到池中。
* 将相同驱动器类型的驱动器添加到现有池中，如果新驱动器的驱动器类型不同，则使用其他驱动器类型创建不同的池。




== 手动创建

当自动创建无法确定最佳配置时，您可能需要手动创建池。出现这种情况的原因可能如下：

* 新驱动器可能会添加到多个池中。
* 一个或多个新的候选池可以使用磁盘架丢失保护或抽屉丢失保护。
* 一个或多个当前池候选者无法保持其货架丢失保护或抽屉丢失保护状态。


如果您的存储阵列上有多个应用程序，并且不希望它们竞争相同的驱动器资源，则可能还需要手动创建池。在这种情况下，您可以考虑手动为一个或多个应用程序创建一个较小的池。您可以只分配一个或两个卷，而不是将工作负载分配给具有多个卷的大型池来分配数据。手动创建一个专用于特定应用程序工作负载的单独池，可以使存储阵列操作更快地执行，争用更少。
