= 了解 SANtricity System Manager 中的池和卷组
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以从存储阵列中未分配驱动器的子集创建逻辑存储容量。此逻辑容量可以采用池或卷组的形式，具体取决于您的环境需要。



[[what-are-pools-and-volume-groups]]
== 什么是池和卷组？

_pool_ 是一组逻辑分组的驱动器。_volume group_ 是具有共享特征的卷的容器。您可以使用池或卷组来创建主机可访问的卷。

了解详情：

* link:how-pools-and-volume-groups-work.html["池和卷组的工作原理"]
* link:capacity-terminology.html["容量术语"]
* link:decide-to-use-a-pool-or-volume-group.html["决定是使用池还是卷组"]




[[how-do-you-create-pools]]
== 如何创建池？

您可以允许 System Manager 在检测到存储阵列中的未分配容量时自动创建池。或者，当自动创建无法确定最佳配置时，您可以从菜单手动创建池：Storage[Pools & Volume Groups]。

了解详情：

* link:automatic-versus-manual-pool-creation.html["自动与手动池创建"]
* link:create-pool-automatically.html["自动创建池"]
* link:create-pool-manually.html["手动创建池"]
* link:add-capacity-to-a-pool-or-volume-group.html["向池或卷组添加容量"]




[[how-do-you-create-volume-groups]]
== 如何创建卷组？

您可以从菜单：Storage[Pools & Volume Groups] 创建卷组。

了解详情：

* link:create-volume-group.html["创建卷组"]
* link:add-capacity-to-a-pool-or-volume-group.html["向池或卷组添加容量"]
