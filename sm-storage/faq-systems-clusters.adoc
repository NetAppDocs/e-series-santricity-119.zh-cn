[[what-are-hosts-and-host-clusters]]
== 什么是主机和主机集群？

主机是向存储阵列上的卷发送 I/O 的服务器。主机群集是一组主机。您可以创建主机群集，以便轻松地将相同的卷分配给多个主机。

您可以单独定义主机。它可以是独立实体，也可以添加到主机群集中。可以将卷分配给单个主机，或者主机可以是与主机群集中的其他主机共享一个或多个卷的访问权限的主机群集的一部分。

主机群集是在 SANtricity System Manager 中创建的逻辑实体。必须先将主机添加到主机群集中，然后才能分配卷。



[[why-would-i-need-to-create-a-host-cluster]]
== 为什么需要创建主机集群？

如果要让两个或多个主机共享对同一卷集的访问权限，则需要创建主机群集。通常，单个主机上安装了群集软件来协调卷访问。



[[how-do-i-know-which-host-operating-system-type-is-correct]]
== 如何知道哪种主机操作系统类型是正确的？

"主机操作系统类型"字段包含主机的操作系统。您可以从下拉列表中选择推荐的主机类型。

下拉列表中显示的主机类型取决于存储阵列型号和固件版本。最新版本首先显示最常见的选项，这些选项最有可能是合适的。此列表中的外观并不意味着完全支持该选项。

[[what-are-hbas-and-adapter-ports]]
== 什么是 HBA 和适配器端口？

主机总线适配器 (HBA) 是驻留在主机中的主板，包含一个或多个主机端口。主机端口是主机总线适配器 (HBA) 上的端口，用于提供与控制器的物理连接，并用于 I/O 操作。

HBA 上的适配器端口称为主机端口。大多数 HBA 都有一个或两个主机端口。HBA 有一个唯一的全球标识符 (WWID)，每个 HBA 主机端口都有一个唯一的 WWID。当您通过 SANtricity System Manager 手动创建主机时，主机端口标识符用于将相应的 HBA 与物理主机关联。



[[how-do-i-match-the-host-ports-to-a-host]]
== 如何将主机端口与主机匹配？

如果要手动创建主机，首先必须使用主机上可用的相应主机总线适配器 (HBA) 实用程序来确定与主机中安装的每个 HBA 关联的主机端口标识符。

获得此信息后，从"创建主机"对话框中提供的列表中选择已登录到存储阵列的主机端口标识符。

[NOTE]
====
确保为要创建的主机选择适当的主机端口标识符。如果您关联了错误的主机端口标识符，则可能会导致其他主机意外访问此数据。

====


[[how-do-i-create-chap-secrets]]
== 如何创建 CHAP 密码？

如果在连接到存储阵列的任何 iSCSI 主机上设置 Challenge Handshake Authentication Protocol (CHAP) 身份验证，则必须为每个 iSCSI 主机重新输入该启动器 CHAP 密码。

为此，您可以将 System Manager 用作 Create Host（创建主机）操作的一部分或通过 View/Edit Settings（查看/编辑设置）选项使用。

如果您使用 CHAP 相互身份验证，还必须在 Settings 页中定义存储阵列的目标 CHAP 密码，然后在每个 iSCSI 主机上重新输入该目标 CHAP 密码。



[[what-is-the-default-cluster]]
== 什么是默认集群？

默认集群是一个系统定义的实体，它允许已登录到存储阵列的任何未关联的主机端口标识符访问分配给默认集群的卷。未关联的主机端口标识符是一个主机端口，它在逻辑上不与特定主机关联，而是物理安装在主机中并登录到存储阵列。

[NOTE]
====
如果您希望主机对存储阵列中的某些卷具有特定访问权限，则必须_不_使用默认群集。相反，您必须将主机端口标识符与其对应的主机相关联。此任务可以在 Create Host 操作期间手动完成。然后，您将卷分配给单个主机或主机群集。

====
您应该_仅_在外部存储环境有利于允许所有主机和连接到存储阵列的所有登录主机端口标识符访问所有卷（全访问模式）而无需特别使存储阵列或用户界面了解主机的特殊情况下使用默认集群。

最初，只能通过命令行界面 (CLI) 将卷分配给默认群集。但是，将至少一个卷分配给默认群集后，此实体（称为 Default Cluster）将显示在用户界面中，然后您可以在其中管理此实体。



[[what-is-host-connectivity-reporting]]
== 什么是主机连接报告？

启用主机连接报告后，存储阵列会持续监控控制器与已配置主机之间的连接，然后在连接中断时向您发出警报。

如果电缆松动、损坏或丢失，或者主机出现其他问题，可能会导致连接中断。在这些情况下，系统可能会打开 Recovery Guru 消息：

* *主机冗余丢失* -- 如果任何一个控制器无法与主机通信，则打开。
* *主机类型不正确* -- 如果主机类型在存储阵列上指定不正确，则打开，这可能导致故障转移问题。


在重新启动控制器可能需要比连接超时更长的时间的情况下，您可能需要禁用主机连接报告。禁用此功能将抑制 Recovery Gurus 消息。

[NOTE]
====
禁用主机连接报告还会禁用自动负载平衡，该功能用于监控和平衡控制器资源使用情况。但是，如果重新启用主机连接报告，则不会自动重新启用自动负载平衡功能。

====
