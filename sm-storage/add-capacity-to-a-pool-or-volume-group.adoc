= 在 SANtricity System Manager 中向池或卷组添加容量
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以添加驱动器以扩展现有池或卷组中的可用容量。

此扩展将导致池或卷组中包括额外的可用容量。您可以使用此可用容量创建额外的卷。在此操作期间，卷中的数据仍可访问。

.开始之前
* 驱动器必须处于最佳状态。
* 驱动器必须具有相同的驱动器类型（HDD 或 SSD）。
* 池或卷组必须处于 Optimal 状态。
* 卷组中允许的最大卷数为 256 个。
* 池中允许的最大卷数取决于存储系统型号：
+
** 2,048 卷（EF600 和 E5700 系列）
** 1,024 卷 (EF300)
** 512 卷（E4000 和 E2800 系列）


* 如果池或卷组包含所有支持安全的驱动器，则仅添加支持安全的驱动器，以继续使用支持安全的驱动器的加密功能。
+
支持安全的驱动器可以是全磁盘加密 (FDE) 驱动器或联邦信息处理标准 (FIPS) 驱动器。



.关于此任务
对于池，一次最多可以添加 60 个驱动器。对于卷组，一次最多可以添加两个驱动器。如果需要添加超过最大数量的驱动器，请重复此过程。（池包含的驱动器数不能超过存储系统的最大限制。）

[NOTE]
====
添加驱动器后，可能需要增加您的保存容量。您应该考虑在扩展操作后增加您的预留容量。

====
[NOTE]
====
避免使用具有数据保障 (DA) 功能的驱动器向不支持 DA 的池或卷组添加容量。池或卷组无法利用支持 DA 的驱动器的功能。在这种情况下，请考虑使用不支持 DA 的驱动器。

====
.步骤
. 选择菜单：Storage[Pools & Volume Groups]。
. 选择要将驱动器添加到的池或卷组，然后单击 *Add Capacity*。
+
此时将显示"添加容量"对话框。仅显示与池或卷组兼容的未分配驱动器。

. 在 *Select drives to add capacity...* 下，选择要添加到现有池或卷组的一个或多个驱动器。
+
控制器固件使用顶部列出的最佳选项来排列未分配的驱动器。添加到池或卷组的总可用容量显示在*选定总容量*的列表下方。

+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 字段 | 说明 


 a| 
磁盘架
 a| 
指示驱动器的盘架位置。



 a| 
托架
 a| 
指示驱动器的托架位置。



 a| 
容量 (GiB)
 a| 
表示驱动器容量。

** 尽可能选择容量等于池或卷组中当前驱动器容量的驱动器。
** 如果您必须添加容量较小的未分配驱动器，请注意，池或卷组中当前每个驱动器的可用容量都会降低。因此，整个池或卷组的驱动器容量相同。
** 如果您必须添加容量较大的未分配驱动器，请注意，您添加的未分配驱动器的可用容量会减少，以便它们与池或卷组中驱动器的当前容量相匹配。




 a| 
支持安全功能
 a| 
指示驱动器是否具有安全功能。

** 要使用 Drive Security 功能保护您的池或卷组，所有驱动器必须具有安全功能。
** 可以使用支持安全的驱动器和不支持安全的驱动器混合创建池或卷组，但无法启用 Drive Security 功能。
** 即使未使用加密功能，具有所有支持安全的驱动器的池或卷组也不能接受不支持安全的驱动器进行备用或扩展。
** 报告为具有安全功能的驱动器可以是全磁盘加密 (FDE) 驱动器或联邦信息处理标准 (FIPS) 驱动器。
** FIPS 驱动器可以是 140-2 级或 140-3 级，140-3 级为更高级别的安全级别。如果选择 140-2 和 140-3 级别驱动器的混合，则池或卷组将在较低的安全级别（140-2）运行。




 a| 
支持 DA
 a| 
指示驱动器是否支持 Data Assurance (DA)。

** 不建议使用不支持数据保障 (DA) 的驱动器向支持 DA 的池或卷组添加容量。池或卷组将不再具有 DA 功能，并且您不再可以选择在池或卷组内新创建的卷上启用 DA。
** 不建议使用支持数据保障 (DA) 的驱动器向不支持 DA 的池或卷组添加容量，因为该池或卷组无法利用支持 DA 的驱动器的功能（驱动器属性不匹配）。在这种情况下，请考虑使用不支持 DA 的驱动器。




 a| 
DULBE 功能
 a| 
指示驱动器是否具有取消分配或未写入逻辑块错误 (DULBE) 的选项。DULBE 是 NVMe 驱动器上的一个选项，允许 EF300 或 EF600 存储阵列支持资源调配的卷。

|===
====
. 单击 *Add*。
+
如果要将驱动器添加到池或卷组，如果选择的驱动器导致池或卷组不再具有以下一个或多个属性，则会显示确认对话框：

+
** 货架损失保护 ^*^
** 抽屉丢失保护 ^*^
** 全磁盘加密功能
** 数据保证能力
** DULBE 功能





NOTE: ^*^ 目前，将驱动器添加到具有货架丢失保护或抽屉丢失保护的池时，不会显示确认对话框。

. 要继续，请单击 *Yes*；否则，请单击 *Cancel*。


.结果
将未分配的驱动器添加到池或卷组后，将重新分配池或卷组中每个卷中的数据，以包括其他驱动器。
