= 在 SANtricity System Manager 中更改镜像对卷的预留容量设置
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以更改镜像对卷的设置，以调整 SANtricity System Manager 发送警报通知的百分比点，即当镜像对卷的预留容量接近满时。

.步骤
. 选择菜单：Storage[Pools & Volume Groups]。
. 选择 *Reserved Capacity* 选项卡。
. 选择要编辑的镜像对卷，然后单击 *View/Edit Settings*。
+
此时将显示镜像配对卷保留容量设置对话框。

. 根据需要更改镜像对卷的预留容量设置。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
在...时提醒我
 a| 
使用微调框可调整在镜像对的保留容量接近满时 System Manager 发送警报通知的百分比点。

当镜像对的保留容量超过指定阈值时，System Manager 会发送警报，让您有时间增加保留容量。


NOTE: 更改一个镜像对的 Alert 设置会更改属于同一镜像一致性组的所有镜像对的 Alert 设置。

|===
====
. 单击 *Save* 以应用更改。
