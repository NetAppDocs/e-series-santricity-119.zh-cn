= 在 SANtricity System Manager 中创建卷
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
创建卷是为了向特定于应用程序的工作负载添加存储容量，并使创建的卷对特定主机或主机群集可见。此外，卷创建顺序还提供了为要创建的每个卷分配特定容量的选项。

.关于此任务
大多数应用程序类型默认为用户定义的卷配置。某些应用程序类型在创建卷时应用了智能配置。例如，如果要为 Microsoft Exchange 应用程序创建卷，系统会询问您需要多少个邮箱、平均邮箱容量要求以及所需的数据库副本数。System Manager 使用此信息为您创建最佳卷配置，可以根据需要对其进行编辑。

创建卷的过程是一个多步骤过程。



== 步骤 1：选择卷的主机

创建卷是为了向特定于应用程序的工作负载添加存储容量，并使创建的卷对特定主机或主机群集可见。此外，卷创建顺序还提供了为要创建的每个卷分配特定容量的选项。

.开始之前
* Hosts 图块下方存在有效的主机或主机集群。
* 已为主机定义主机端口标识符。
* 在创建启用 DA 的卷之前，您计划使用的主机连接必须支持 DA。如果存储阵列中控制器上的任何主机连接不支持 DA，则关联的主机无法访问启用了 DA 的卷上的数据。


.关于此任务
分配卷时，请记住以下准则：

* 主机的操作系统可以对主机可以访问的卷数量进行特定限制。在创建供特定主机使用的卷时，请记住此限制。
* 您可以为存储阵列中的每个卷定义一个分配。
* 分配的卷在存储阵列中的控制器之间共享。
* 主机或主机群集不能使用相同的逻辑单元号 (LUN) 两次访问卷。您必须使用唯一的 LUN。
* 如果要加快创建卷的过程，可以跳过主机分配步骤，以便离线初始化新创建的卷。


[NOTE]
====
如果尝试将卷分配给与主机群集中已建立的主机分配冲突的主机群集，则将卷分配给主机将失败。

====
.步骤
. 选择菜单：Storage[Volumes]。
. 选择菜单：Create[Volume]。
+
此时将显示"创建卷"对话框。

. 从下拉列表中，选择要向其分配卷的特定主机或主机群集，或选择稍后分配主机或主机群集。
. 若要继续选定主机或主机群集的卷创建顺序，请单击 *Next*，然后转到 <<步骤 2：为卷选择工作负载>>。
+
此时将显示"选择工作负载"对话框。





== 步骤 2：为卷选择工作负载

选择工作负载以自定义特定应用程序（如 Microsoft SQL Server、Microsoft Exchange、视频监控应用程序或 VMware）的存储阵列配置。如果未列出要在此存储阵列上使用的应用程序，则可以选择"其他应用程序"。

.关于此任务
此任务描述如何为现有工作负载创建卷。

* _当您使用特定于应用程序的工作负载创建卷时_，系统可能会推荐优化的卷配置，以最大限度地减少应用程序工作负载 I/O 与来自应用程序实例的其他流量之间的竞争。您可以使用"添加/编辑卷"对话框查看推荐的卷配置，并编辑、添加或删除系统推荐的卷和特性。
* _使用"其他"应用程序（或没有特定卷创建支持的应用程序）创建卷时_，请使用"添加/编辑卷"对话框手动指定卷配置。


.步骤
. 执行以下操作之一：
+
** 选择 *Create volumes for an existing workload* 选项，为现有工作负载创建卷。
** 选择 *Create a new workload* 选项，为受支持的应用程序或"其他"应用程序定义新工作负载。
+
*** 从下拉列表中，选择要为其创建新工作负载的应用程序的名称。
+
如果未列出要在此存储阵列上使用的应用程序，请从"其他"条目中选择一项。

*** 输入要创建的工作负载的名称。




. 单击 *Next*。
. 如果您的工作负载与受支持的应用程序类型相关联，请输入所请求的信息；否则，请转到 <<步骤 3：添加或编辑卷>>。




== 步骤 3：添加或编辑卷

System Manager 可能会根据您选择的应用程序或工作负载建议卷配置。此卷配置根据工作负载支持的应用程序类型进行优化。您可以接受推荐的卷配置，也可以根据需要进行编辑。如果选择了其中一个"其他"应用程序，则必须手动指定要创建的卷和特征。

.开始之前
* 池或卷组必须具有足够的可用容量。
* 卷组中允许的最大卷数为 256 个。
* 池中允许的最大卷数取决于存储系统型号：
+
** 2,048 卷（EF600、EF600C 和 E5700 系列）
** 1,024 卷（EF300 和 EF300C）
** 512 卷（E4000 和 E2800 系列）


* 要创建启用 Data Assurance (DA) 的卷，您计划使用的主机连接必须支持 DA。
+
.选择具有安全功能的池或卷组
[%collapsible]
====
如果要创建启用 DA 的卷，请选择支持 DA 的池或卷组（在池和卷组候选表中的"DA"旁边查找 *Yes*）。

DA 功能在 System Manager 中的池和卷组级别呈现。DA 保护会检查并更正数据通过控制器传输到驱动器时可能发生的错误。为新卷选择支持 DA 的池或卷组可确保检测并更正任何错误。

如果存储阵列中控制器上的任何主机连接不支持 DA，则关联的主机无法访问启用 DA 的卷上的数据。

====
* 要创建启用安全的卷，必须为存储阵列创建安全密钥。
+
.选择具有安全功能的池或卷组
[%collapsible]
====
如果要创建启用安全的卷，请选择支持安全的池或卷组（在池和卷组候选项表中的"支持安全"旁边查找 *是*）。

驱动器安全功能在 System Manager 中的池和卷组级别呈现。具有安全功能的驱动器可防止对从存储阵列中物理移除的驱动器上的数据进行未经授权的访问。启用安全的驱动器在写入期间对数据进行加密，并在读取期间使用唯一的_加密密钥_对数据进行解密。

池或卷组可以同时包含具有安全功能和不具有安全功能的驱动器，但所有驱动器都必须具有安全功能才能使用其加密功能。

====
* 要创建资源调配的卷，所有驱动器都必须是具有 Deallocated or Unwritten Logical Block Error (DULBE) 选项的 NVMe 驱动器。


.关于此任务
您可以从池或卷组创建卷。添加/编辑卷对话框显示存储阵列上所有符合条件的池和卷组。对于每个符合条件的池和卷组，将显示可用的驱动器数量和可用总容量。

对于某些特定于应用程序的工作负载，每个符合条件的池或卷组将根据建议的卷配置显示建议的容量，并以 GiB 显示剩余可用容量。对于其他工作负载，当您将卷添加到池或卷组并指定报告的容量时，将显示建议的容量。

.步骤
. 根据您是选择了"其他"还是特定于应用程序的工作负载，选择以下操作之一：
+
** *其他* -- 在要用于创建一个或多个卷的每个池或卷组中单击 *添加新卷*。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 字段 | 说明 


 a| 
卷名称
 a| 
在卷创建顺序期间，System Manager 将为卷分配默认名称。您可以接受默认名称，也可以提供一个更具描述性的名称来指示卷中存储的数据类型。



 a| 
已报告容量
 a| 
定义新卷的容量和要使用的容量单位（MiB、GiB 或 TiB）。对于厚卷，最小容量为 1 MiB，最大容量由池或卷组中驱动器的数量和容量决定。

请记住，复制服务（快照映像、快照卷、卷副本和远程镜像）也需要存储容量；因此，不要将所有容量分配给标准卷。

池中的容量以 4-GiB 或 8-GiB 的增量分配，具体取决于您的驱动器类型。任何不是 4-GiB 或 8-GiB 的倍数的容量都已分配，但不可用。为确保整个容量可用，请以 4-GiB 或 8-GiB 增量指定容量。如果存在不可用的容量，则重新获得它的唯一方法是增加卷的容量。



 a| 
卷块大小（仅限 EF300 和 EF600）
 a| 
显示可以为卷创建的块大小：

*** 512 -- 512 字节
*** 4K -- 4,096 字节




 a| 
区块大小
 a| 
显示区段大小设置，该设置仅对卷组中的卷显示。您可以更改区段大小以优化性能。

*允许的段大小转换* -- System Manager 确定允许的段大小转换。从当前段大小进行不适当转换的段大小在下拉列表中不可用。允许的转换通常是当前段大小的两倍或一半。例如，如果当前卷段大小为 32 KiB，则允许 16 KiB 或 64 KiB 的新卷段大小。

*启用 SSD Cache 的卷* -- 您可以为启用 SSD Cache 的卷指定 4-KiB 段大小。确保仅为处理小块 I/O 操作的启用 SSD Cache 的卷选择 4-KiB 段大小（例如，16 KiB I/O 块大小或更小）。如果为处理大块顺序操作的启用 SSD Cache 的卷选择 4 KiB 作为段大小，性能可能会受到影响。

*更改段大小的时间量* -- 更改卷的段大小的时间量取决于以下变量：

*** 来自主机的 I/O 负载
*** 卷的修改优先级
*** 卷组中的驱动器数
*** 驱动器通道数
*** 存储阵列控制器的处理能力


当您更改卷的段大小时，I/O 性能会受到影响，但您的数据仍然可用。



 a| 
支持安全功能
 a| 
只有当池或卷组中的驱动器具有安全功能时，*是* 才会显示在 "Secure-capable" 旁边。

驱动器安全性可防止对从存储阵列中物理移除的驱动器上的数据进行未经授权的访问。仅当启用了驱动器安全功能并为存储阵列设置了安全密钥时，此选项才可用。

池或卷组可以同时包含具有安全功能和不具有安全功能的驱动器，但所有驱动器都必须具有安全功能才能使用其加密功能。



 a| 
DA
 a| 
*是* 仅在池或卷组中的驱动器支持数据保障 (DA) 时显示在 "DA" 旁边。

DA 提高了整个存储系统的数据完整性。DA 使存储阵列能够检查数据通过控制器传输到驱动器时可能发生的错误。对新卷使用 DA 可确保检测到任何错误。



 a| 
已配置资源（仅限 EF300 和 EF600）
 a| 
只有当驱动器支持此选项时，*是*才会显示在"资源调配"旁边。资源调配是 EF300 和 EF600 存储阵列中提供的一项功能，它允许卷立即投入使用，而无需后台初始化过程。

== 步骤 4：检查卷配置

查看要创建的卷的摘要并进行任何必要的更改。

.步骤
. 查看要创建的卷。单击 *返回* 进行任何更改。
. 对卷配置感到满意后，单击 *完成* 。


.结果
System Manager 在选定的池和卷组中创建新卷，然后在 All Volumes 表中显示新卷。

.完成后
* 在应用程序主机上执行任何必要的操作系统修改，以便应用程序可以使用此卷。
* 运行特定于操作系统的实用程序（可从第三方供应商处获得），然后运行 SMcli 命令 `-identifyDevices`以将卷名称与主机存储阵列名称相关联。
+
SMcli 可直接通过 SANtricity System Manager 获得。此可下载版本的 SMcli 可在 E4000、EF600、EF600C、EF300、EF300C、E5700、EF570、E2800 和 EF280 控制器上使用。要在 SANtricity System Manager 中下载 SMcli，请选择*设置* > *系统*和*附加组件* > *命令行界面*。
