[[what-can-i-learn-from-performance-data]]
== 我可以从性能数据中学到什么？

性能图表和表格以近乎实时的方式显示性能数据，可帮助您确定存储阵列是否遇到问题。您还可以保存性能数据以构建存储阵列的历史视图，并确定问题何时开始或导致问题的原因。

了解详情：
