[[what-is-a-hot-spare-drive]]
== 什么是热备盘驱动器？

热备盘在 RAID 1、RAID 5 或 RAID 6 卷组中充当备用驱动器。它们是功能齐全的驱动器，不包含任何数据。如果卷组中的驱动器出现故障，控制器会自动将故障驱动器的数据重建到热备盘。

如果存储阵列中的驱动器出现故障，热备盘驱动器将自动替换出现故障的驱动器，而无需进行物理交换。如果热备盘驱动器在驱动器发生故障时可用，则控制器使用冗余数据将数据从发生故障的驱动器重建到热备盘驱动器。

热备盘驱动器不专用于特定的卷组。相反，您可以为存储阵列中容量相同或较小的任何故障驱动器使用热备盘驱动器。热备盘驱动器必须与其保护的驱动器具有相同的介质类型（HDD 或 SSD）。

[NOTE]
====
池不支持热备盘驱动器。池使用包含池的每个驱动器中的保留容量，而不是热备盘驱动器。

====


[[what-is-preservation-capacity]]
== 什么是保存容量？

保留容量是在池中保留的容量（驱动器数量），用于支持潜在的驱动器故障。

创建池后，系统会根据池中的驱动器数量自动保留默认的保留容量。

池在重建期间使用保留容量，而卷组使用热备盘驱动器用于相同的目的。与热备盘驱动器相比，保留容量方法是一种改进，因为它可以更快地进行重建。保留容量分布在池中的多个驱动器上，而不是热备盘驱动器的一个驱动器上，因此您不受一个驱动器的速度或可用性的限制。



[[why-would-i-logically-replace-a-drive]]
== 我为什么要在逻辑上更换驱动器？

如果驱动器出现故障或由于任何其他原因要更换它，并且存储阵列中存在未分配的驱动器，则可以从逻辑上将出现故障的驱动器替换为未分配的驱动器。如果没有未分配的驱动器，则可以改为实际更换驱动器。

来自原始驱动器的数据被复制或重建至替换驱动器。



[[where-can-i-view-the-status-of-a-drive-undergoing-reconstruction]]
== 在哪里可以查看正在重建的驱动器的状态？

您可以从"正在进行的操作"仪表板查看驱动器重建状态。

在主页中，单击右上角的 *查看正在进行的操作* 链接。

根据驱动器的不同，完整的重建可能需要相当长的时间。如果卷所有权发生变化，则可能会进行完全重建而不是快速重建。
