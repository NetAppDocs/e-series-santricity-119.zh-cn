= 更改 SANtricity System Manager 中卷的设置
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以更改卷的设置，例如其名称、主机分配、段大小、修改优先级、缓存等。

.开始之前
要更改的卷处于最佳状态。


NOTE: 在对卷设置进行更改时，某些操作可能不可用

.步骤
. 选择菜单：Storage[Volumes]。
. 选择要更改的卷，然后选择 *View/Edit Settings*。
+
此时将显示"卷设置"对话框。此对话框中将显示所选卷的配置设置。

. 选择 *Basic* 选项卡以更改卷的名称和主机分配。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
名称
 a| 
显示卷的名称。当当前名称不再有意义或不再适用时，更改卷的名称。



 a| 
容量
 a| 
显示选定卷的已报告和已分配容量。

对于厚卷，报告的容量和分配的容量是相同的，但对于精简卷则不同。对于厚卷，物理分配的空间等于向主机报告的空间。对于精简卷，报告的容量是报告给主机的容量，而分配的容量是当前分配用于写入数据的驱动器空间量。



 a| 
池 / 卷组
 a| 
显示池或卷组的名称和 RAID 级别。指示池或卷组是否具有安全功能并启用了安全功能。



 a| 
主机
 a| 
显示卷分配。将卷分配给主机或主机群集，以便可以访问该卷进行 I/O 操作。此分配授予主机或主机群集对特定卷或存储阵列中的多个卷的访问权限。

** *分配给* -- 标识可以访问所选卷的主机或主机群集。
** *LUN* -- 逻辑单元编号 (LUN) 是分配给主机用于访问卷的地址空间的编号。卷以 LUN 的形式作为容量呈现给主机。每个主机都有自己的 LUN 地址空间。因此，不同的主机可以使用相同的 LUN 来访问不同的卷。
+

NOTE: 对于 NVMe 接口，此列显示命名空间 ID。命名空间是为块访问而格式化的 NVM 存储。它类似于 SCSI 中的逻辑单元，与存储阵列中的卷相关。命名空间 ID 是 NVMe 控制器的命名空间唯一标识符，可以设置为 1 到 255 之间的值。它类似于 SCSI 中的逻辑单元号 (LUN)。





 a| 
标识符
 a| 
显示选定卷的标识符。

** *全球标识符 (WWID)* -- 卷的唯一十六进制标识符。
** *扩展唯一标识符 (EUI)* -- 卷的 EUI-64 标识符。
** *子系统标识符 (SSID)* -- 卷的存储阵列子系统标识符。


|===
====
. 选择 *Advanced* 选项卡以更改池或卷组中卷的其他配置设置。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
应用程序和工作负载信息
 a| 
在创建卷期间，您可以创建特定于应用程序的工作负载或其他工作负载。如果适用，将显示选定卷的工作负载名称、应用程序类型和卷类型。

您可以根据需要更改工作负荷名称。



 a| 
服务质量设置
 a| 
*永久禁用 Data Assurance* -- 仅当卷启用了 Data Assurance (DA) 时才会显示此设置。DA 检查并更正数据通过控制器传输到驱动器时可能发生的错误。使用此选项可永久禁用所选卷上的 DA。禁用时，无法在此卷上重新启用 DA。

*启用预读冗余检查* -- 仅当卷为厚卷时才会显示此设置。预读冗余检查确定每次执行读取时卷上的数据是否一致。如果控制器固件确定数据不一致，启用此功能的卷将返回读取错误。



 a| 
控制器所有权
 a| 
定义被指定为卷的拥有者或主控制器的控制器。

控制器所有权非常重要，应仔细规划。控制器应尽可能紧密地平衡总 I/O。



 a| 
区段大小调整
 a| 
显示区段大小设置，该设置仅对卷组中的卷显示。您可以更改区段大小以优化性能。

*允许的段大小转换* -- System Manager 确定允许的段大小转换。从当前段大小进行不适当转换的段大小在下拉列表中不可用。允许的转换通常是当前段大小的两倍或一半。例如，如果当前卷段大小为 32 KiB，则允许 16 KiB 或 64 KiB 的新卷段大小。

*启用 SSD Cache 的卷* -- 您可以为启用 SSD Cache 的卷指定 4-KiB 段大小。确保仅为处理小块 I/O 操作的启用 SSD Cache 的卷选择 4-KiB 段大小（例如，16 KiB I/O 块大小或更小）。如果为处理大块顺序操作的启用 SSD Cache 的卷选择 4 KiB 作为段大小，性能可能会受到影响。

*更改段大小的时间量* -- 更改卷的段大小的时间量取决于以下变量：

** 来自主机的 I/O 负载
** 卷的修改优先级
** 卷组中的驱动器数
** 驱动器通道数
** 存储阵列控制器的处理能力 当您更改卷的段大小时，I/O 性能会受到影响，但您的数据仍然可用。




 a| 
修改优先级
 a| 
显示修改优先级的设置，该设置仅对卷组中的卷显示。

修改优先级定义相对于系统性能为卷修改操作分配多少处理时间。您可以提高卷修改优先级，尽管这可能会影响系统性能。

移动滑块栏以选择优先级。

*修改优先级比率* -- 最低优先级比率有利于系统性能，但修改操作需要更长时间。最高优先级比率有利于修改操作，但系统性能可能会受到影响。



 a| 
缓存
 a| 
显示缓存设置，您可以更改该设置以影响卷的整体 I/O 性能。



 a| 
SSD 缓存
 a| 
显示 SSD Cache 设置，您可以在兼容卷上启用该设置，以提高只读性能。如果卷共享相同的驱动器安全和 Data Assurance 功能，则它们是兼容的。

*SSD Cache 功能使用单个或多个固态硬盘 (SSD) 来实现读缓存*。由于 SSD 的读取时间更快，因此提高了应用程序性能。由于读缓存在存储阵列中，因此缓存在使用存储阵列的所有应用程序之间共享。只需选择要缓存的卷，即可实现自动和动态缓存。

|===
====
. 单击 *Save*。
+
System Manager 根据您的选择更改卷的设置。



.完成后
选择菜单：Home[View Operations in Progress] 以查看当前为所选卷运行的更改操作的进度。
