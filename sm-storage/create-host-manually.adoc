= 在 SANtricity System Manager 中手动创建主机
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
对于无法自动发现的主机，您可以手动创建主机。创建主机是让存储阵列知道哪些主机连接到它并允许对卷进行 I/O 访问所需的步骤之一。

.关于此任务
创建主机时，请牢记以下准则：

* 您必须定义与该主机关联的主机标识符端口。
* 请确保提供与主机分配的系统名称相同的名称。
* 如果您选择的名称已在使用中，此操作将不会成功。
* 名称长度不能超过 30 个字符。


.步骤
. 选择菜单：Storage[Hosts]。
. 单击菜单：Create[Host]。
+
此时将显示创建主机对话框。

. 根据需要选择主机的设置。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
名称
 a| 
输入新主机的名称。



 a| 
主机操作系统类型
 a| 
从下拉列表中选择正在新主机上运行的操作系统。



 a| 
主机接口类型
 a| 
（可选）如果存储阵列上支持多种类型的主机接口，请选择要使用的主机接口类型。



 a| 
主机端口
 a| 
执行以下操作之一：

** *选择 I/O 接口*
+
通常，主机端口应已登录并可从下拉列表中使用。您可以从列表中选择主机端口标识符。

** *手动添加*
+
如果列表中未显示主机端口标识符，则表示主机端口尚未登录。HBA 实用程序或 iSCSI 启动程序实用程序可用于查找主机端口标识符并将其与主机相关联。

+
您可以手动输入主机端口标识符，或将它们从实用程序（一次一个）复制/粘贴到 *Host ports* 字段中。

+
您必须一次选择一个主机端口标识符才能将其与主机关联，但您可以继续选择与主机关联的多个标识符。每个标识符都显示在*主机端口*字段中。如有必要，您也可以选择旁边的*X*来删除标识符。





 a| 
CHAP 启动程序
 a| 
（可选）如果选择或手动输入带有 iSCSI IQN 的主机端口，并且如果要求尝试访问存储阵列的主机使用质询握手身份验证协议（CHAP）进行身份验证，请选中 *CHAP initiator* 复选框。对于您选择或手动输入的每个 iSCSI 主机端口，请执行以下操作：

** 输入在每个 iSCSI 主机启动程序上为 CHAP 身份验证设置的相同 CHAP 密码。如果要使用双方 CHAP 身份验证（双向身份验证，使主机能够向存储阵列验证自身，并使存储阵列能够向主机验证自身），还必须在初始设置或更改设置时为存储阵列设置 CHAP 密码。
** 如果您不需要主机身份验证，请将此字段留空。


目前，System Manager 使用的唯一 iSCSI 身份验证方法是 CHAP。

|===
====
. 单击 *Create*。


.结果
成功创建主机后，系统会为该主机配置的每个主机端口创建一个默认名称（用户标签）。

默认别名为 <``Hostname_Port Number``>。例如，为  `host IPT is IPT_1` 创建的第一个端口的默认别名。
