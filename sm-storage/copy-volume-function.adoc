= 了解 SANtricity System Manager 中的 Copy Volume
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
Copy Volume 功能可通过在同一存储阵列上创建两个单独的卷（源卷和目标卷）来创建卷的时间点副本。

此函数执行从源卷到目标卷的逐字节复制，使目标卷上的数据与源卷上的数据相同。



== 数据复制以获得更大的访问权限

当您对卷的存储要求发生变化时，您可以使用 Copy Volume 功能将数据从使用较小容量驱动器的池或卷组复制到使用较大容量驱动器的池或卷组。例如，您可以使用 Copy Volume 功能执行以下操作：

* 将数据移动到更大的驱动器。
* 更改为数据传输速率更高的驱动器。
* 改用采用新技术的驱动器，以获得更高的性能。
* 将薄卷更改为厚卷。


复制源卷和目标卷必须具有相同的报告主机可寻址/逻辑块大小（扇区大小）。

报告的卷块大小为：

* *Native block size* – 卷的块大小与驱动器块大小匹配，可以是 512 或 4K。
* *模拟 512 块大小* - 驱动器为 4K，但报告的块大小为 512。




== 将精简卷更改为厚卷

如果要将精简卷更改为厚卷，请使用 Copy Volume 操作创建精简卷的副本。Copy Volume 操作的目标始终是厚卷。

[NOTE]
====
System Manager 不提供创建精简卷的选项。如果要创建精简卷，请使用命令行界面 (CLI)。

====


== 备份数据

复制卷功能允许您通过将数据从一个卷复制到同一存储阵列上的另一个卷来备份卷。您可以将目标卷用作源卷的备份、用于系统测试或备份到其他设备（如磁带驱动器）。



== 将快照卷数据还原到基本卷

如果需要将数据从其关联的快照卷还原到基本卷，可以使用 Copy Volume 功能将数据从快照卷复制到基本卷。您可以在快照卷上创建数据的卷副本，然后将数据复制到基本卷。
