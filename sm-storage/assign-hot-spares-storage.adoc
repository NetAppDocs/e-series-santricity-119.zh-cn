= 在 SANtricity System Manager 中分配热备用磁盘
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以将热备盘分配为备用驱动器，以便在 RAID 1、RAID 5 或 RAID 6 卷组中进行额外的数据保护。如果驱动器在其中一个卷组中发生故障，则控制器将数据从发生故障的驱动器重新构建到热备盘。

.开始之前
* 必须创建 RAID 1、RAID 5 或 RAID 6 卷组。（热备盘不能用于池。相反，池会在每个驱动器内使用备用容量来进行数据保护。）
* 必须提供符合以下条件的驱动器：
+
** 未分配，状态为最佳。
** 与卷组中的驱动器相同的介质类型（例如 SSD）。
** 与卷组中的驱动器相同的接口类型（例如 SAS）。
** 容量等于或大于卷组中驱动器的已用容量。




.关于此任务
此任务介绍如何从 Hardware 页面手动分配热备盘。建议的覆盖范围是每个驱动器集两个热备盘。

[CAUTION]
====
热备盘也可以通过初始设置向导进行分配。您可以通过在 Hardware 页面上查找以粉红色显示的驱动器托架来确定是否已分配热备盘。

====
.步骤
. 选择 *Hardware*。
. 如果图形显示控制器，请单击 *Drives* 选项卡。
+
图形更改为显示驱动器而不是控制器。

. 选择要用作热备盘的未分配驱动器（以灰色显示）。
+
驱动器的上下文菜单打开。

. 选择 *Assign hot spare*。
+
如果驱动器已启用安全功能，则会打开 *Secure Erase Drive* 对话框。要将启用安全的驱动器用作热备盘，您必须首先执行 Secure Erase 操作以删除其所有数据并重置其安全属性。

+
[CAUTION]
====
*可能丢失数据* -- 确保选择了正确的驱动器。完成安全擦除操作后，您将无法恢复任何数据。

====
+
如果驱动器*未*启用安全功能，则将打开"确认分配热备盘驱动器"对话框。

. 查看对话框中的文本，然后确认操作。
+
驱动器在"硬件"页面上以粉红色显示，这表明它现在是热备盘。





== 结果

如果 RAID 1、RAID 5 或 RAID 6 卷组中的驱动器发生故障，控制器会自动使用冗余数据将故障驱动器的数据重建到热备盘。
