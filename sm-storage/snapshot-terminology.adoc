= 了解 SANtricity 软件中的快照术语
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
了解 Snapshot 术语如何适用于您的存储阵列。

[cols="25h,~"]
|===
| 术语 | 说明 


 a| 
Snapshot 功能
 a| 
Snapshots 功能用于创建和管理卷的映像。



 a| 
Snapshot 图像
 a| 
快照映像是在特定时间点捕获的卷数据的逻辑副本。像还原点一样，快照映像允许您回滚到已知良好的数据集。虽然主机可以访问快照映像，但不能直接读写。



 a| 
基础卷
 a| 
基本卷是创建快照映像的源。它可以是厚卷或精简卷，通常分配给主机。基本卷可以驻留在卷组或磁盘池中。



 a| 
Snapshot 卷
 a| 
快照卷允许主机访问快照映像中的数据。快照卷包含其自己的保留容量，该容量可保存对基本卷的任何修改，而不会影响原始快照映像。



 a| 
Snapshot 组
 a| 
快照组是来自单个基本卷的快照图像的集合。



 a| 
预留容量卷
 a| 
保留容量卷跟踪基本卷的哪些数据块被覆盖以及这些块的保留内容。



 a| 
Snapshot 计划
 a| 
Snapshot 计划是用于创建自动快照映像的时间表。通过该计划，您可以控制映像创建的频率。



 a| 
快照一致性组
 a| 
快照一致性组是创建快照映像时被视为单个实体的卷集合。每个卷都有自己的快照映像，但所有映像都是在相同的时间点创建的。



 a| 
Snapshot 一致性组成员卷
 a| 
属于快照一致性组的每个卷称为成员卷。将卷添加到快照一致性组时，System Manager 会自动创建与此成员卷对应的新快照组。



 a| 
回滚
 a| 
回滚是将基本卷中的数据返回到上一个时间点的过程。



 a| 
预留容量
 a| 
保留容量是用于任何复制服务操作和存储对象的物理分配容量。主机无法直接读取。

|===
