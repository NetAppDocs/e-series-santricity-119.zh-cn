= 在 SANtricity System Manager 中更改主机的主机端口标识符
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当要更改主机端口标识符上的用户标签、向主机添加新的主机端口标识符或从主机删除主机端口标识符时，请更改主机端口标识符。

.关于此任务
更改主机端口标识符时，请记住以下准则：

* *添加* -- 添加主机端口时，您正在将主机端口标识符关联到为连接到存储阵列而创建的主机。您可以使用主机总线适配器 (HBA) 实用程序手动输入端口信息。
* *编辑* -- 您可以编辑主机端口，将主机端口移动（关联）到其他主机。您可能已将主机总线适配器或 iSCSI 启动程序移动到其他主机，因此必须将主机端口移动（关联）到新主机。
* *删除* -- 您可以删除主机端口以从主机中删除（取消关联）主机端口。


.步骤
. 选择菜单：Storage[Hosts]。
. 选择端口将关联的主机，然后单击 *View/Edit Settings*。
+
如果要将端口添加到主机群集中的主机，请展开主机群集并选择所需的主机。无法在主机群集级别添加端口。

+
此时将显示一个对话框，显示当前主机设置。

. 单击 *Host Ports* 选项卡。
+
此对话框显示当前主机端口标识符。

. 根据需要更改主机端口标识符设置。
+
[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
主机端口
 a| 
您可以从以下选项中进行选择：

** *添加* -- 使用添加将新的主机端口标识符关联到主机。主机端口标识符名称的长度由主机接口技术决定。Fibre Channel 和 Infiniband 主机端口标识符名称必须包含 16 个字符。iSCSI 主机端口标识符名称最多包含 223 个字符。端口必须是唯一的。不允许使用已配置的端口号。
** *Delete* -- 使用 Delete 删除（取消关联）主机端口标识符。Delete 选项不会物理删除主机端口。此选项删除主机端口和主机之间的关联。除非卸下主机总线适配器或 iSCSI 启动程序，否则控制器仍可识别主机端口。
+
[NOTE]
====
如果删除主机端口标识符，它将不再与此主机关联。此外，主机将无法通过此主机端口标识符访问其分配的任何卷。

====




 a| 
标签
 a| 
要更改端口标签名称，请单击*编辑*图标（铅笔）。端口标签名称必须是唯一的。不允许使用已配置的标签名称。



 a| 
CHAP 密钥
 a| 
仅对 iSCSI 主机显示。您可以设置或更改启动器（iSCSI 主机）的 CHAP 密码。

System Manager 使用质询握手身份验证协议 (CHAP) 方法，该方法在初始链接期间验证目标和启动程序的身份。身份验证基于名为 CHAP 密钥的共享安全密钥。

|===
. 单击 *Save*。
