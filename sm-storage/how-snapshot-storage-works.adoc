快照功能使用写时复制技术来存储快照映像并使用分配的预留容量。



[[how-snapshot-images-are-used]]
== 如何使用快照映像

快照映像是在特定时间点捕获的卷内容的逻辑只读副本。您可以使用快照来防止数据丢失。

快照映像对于测试环境也很有用。通过创建数据的虚拟副本，您可以使用快照测试数据，而无需更改实际卷本身。此外，主机对快照映像没有写入权限，因此快照始终是安全的备份资源。



[[snapshot-creation]]
== Snapshot 创建

创建快照时， Snapshots 功能按如下方式存储图像数据：

* 创建快照映像时，它与基本卷完全匹配。快照功能使用写时复制技术。拍摄快照后，对基本卷上的任何块或块集的第一次写入会导致在将新数据写入基本卷之前将原始数据复制到保留容量。
* 后续快照仅包括已更改的数据块。在基本卷上覆盖数据之前，Snapshots 功能使用其写入时复制技术将受影响扇区的所需映像保存到快照保留容量。
+
image::../media/sam1130-dwg-snapshots-cow-overview.gif[Snapshot 概述]



^1^ 基本卷（物理磁盘容量）；^2^ 快照（逻辑磁盘容量）；^3^ 保留容量（物理磁盘容量）

* 保留容量存储拍摄快照后已更改的基本卷部分的原始数据块，并包括用于跟踪更改的索引。通常，保留容量的大小默认为基本卷的 40%。（如果您需要更多保留容量，可以增加保留容量。）
* 快照映像根据其时间戳按特定顺序存储。只有基本卷的最旧快照映像可用于手动删除。




[[snapshot-restoration]]
== Snapshot 恢复

要将数据还原到基本卷，您可以使用快照卷或快照映像：

* *快照卷* -- 如果需要检索已删除的文件，请从已知良好的快照映像创建快照卷，然后将其分配给主机。
* *Snapshot 映像* -- 如果需要将基本卷还原到特定的时间点，请使用先前的 snapshot 映像将数据回滚到基本卷。
