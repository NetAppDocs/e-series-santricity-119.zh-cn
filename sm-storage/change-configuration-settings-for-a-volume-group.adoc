= 在 SANtricity System Manager 中更改卷组的配置设置
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以编辑卷组的设置，包括其名称和 RAID 级别。

.开始之前
如果要更改 RAID 级别以适应访问卷组的应用程序的性能需求，请务必满足以下先决条件：

* 卷组必须处于最佳状态。
* 您必须在卷组中具有足够的容量才能转换到新的 RAID 级别。


.步骤
. 选择菜单：Storage[Pools & Volume Groups]。
. 选择要编辑的卷组，然后单击 *View/Edit Settings*。
+
此时将显示卷组设置对话框。

. 选择 *Settings* 选项卡，然后根据需要编辑卷组设置。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
名称
 a| 
您可以更改用户提供的卷组的名称。需要指定卷组的名称。



 a| 
RAID 级别
 a| 
从下拉菜单中选择新的 RAID 级别。

** *RAID 0 条带化* -- 提供高性能，但不提供任何数据冗余。如果卷组中的单个驱动器出现故障，则所有关联的卷都会出现故障，并且所有数据都会丢失。条带化 RAID 组将两个或多个驱动器合并为一个大型逻辑驱动器。
** *RAID 1 镜像* -- 提供高性能和最佳数据可用性，适用于在企业或个人级别存储敏感数据。通过将一个驱动器的内容自动镜像到镜像对中的第二个驱动器来保护您的数据。在发生单个驱动器故障时，它可以提供保护。
** *RAID 10 条带化/镜像* -- 提供 RAID 0（条带化）和 RAID 1（镜像）的组合，在选择四个或更多驱动器时实现。RAID 10 适用于需要高性能和容错的大容量事务应用程序，例如数据库。
** *RAID 5* -- 最适合多用户环境（如数据库或文件系统存储），其中典型 I/O 大小较小且读取活动比例较高。
** *RAID 6* -- 适用于需要超出 RAID 5 的冗余保护但不需要高写入性能的环境。


只能使用命令行界面 (CLI) 将 RAID 3 分配给卷组。

更改 RAID 级别时，无法在操作开始后取消此操作。在更改期间，您的数据仍然可用。



 a| 
优化容量（仅限 EF600 阵列）
 a| 
创建卷组时，将生成推荐的优化容量，以提供可用容量与性能和驱动器磨损寿命之间的平衡。您可以通过将滑块向右移动来调整此平衡，以获得更好的性能和驱动器磨损寿命，但会减少可用容量，或者将滑块向左移动以增加可用容量，但会降低性能和驱动器磨损寿命。

当未分配部分容量时，SSD 驱动器将具有更长的使用寿命和更好的最大写入性能。对于与卷组相关联的驱动器，未分配的容量由组的可用容量（卷未使用的容量）和作为额外优化容量预留的可用容量的一部分组成。额外的优化容量通过减少可用容量来确保最低限度的优化容量，因此无法用于卷创建。

|===
====
. 单击 *Save*。
+
如果由于 RAID 级别更改而导致容量减少、卷冗余丢失或架子/抽屉丢失保护丢失，则会出现一个确认对话框。选择 *Yes* 继续；否则单击 *No*。



.结果
如果更改卷组的 RAID 级别，System Manager 将更改构成卷组的每个卷的 RAID 级别。操作过程中可能会轻微影响性能。
