= 在 SANtricity System Manager 中为 Snapshot 一致性组成员卷启动 Snapshot 映像回滚
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
可以执行回滚操作，以更改 snapshot 一致性组成员卷的内容，使其与 snapshot 映像中保存的内容相匹配。

回滚操作不会更改与 Snapshot 一致性组相关联的 Snapshot 映像的内容。

.开始之前
* 有足够的保留容量可用于启动回滚操作。
* 选定的快照映像为最佳，选定的卷为最佳。
* 所选卷没有正在进行的回滚操作。


.关于此任务
回滚启动序列允许您在快照一致性组的快照映像上开始回滚，同时提供添加存储容量的选项。一次不能为快照一致性组启动多个回滚操作。

[NOTE]
====
主机可以立即访问新的回滚卷，但在回滚启动后，现有成员卷不再允许主机读写访问。您可以在开始回滚之前创建成员卷的快照映像，以保留用于恢复目的的预回滚基本卷。

====
开始回滚快照一致性组的快照映像的过程是一个多步骤过程。



[[step-1-select-members]]
== 步骤 1：选择成员

必须选择要回滚的成员卷。

.步骤
. 选择菜单：Storage[Snapshots]。
. 选择 *Snapshot Images* 选项卡。
. 选择快照一致性组快照映像，然后选择菜单：Rollback[Start]。
+
此时将显示"开始回滚"对话框。

. 选择成员卷。
. 单击 *Next*，然后执行以下操作之一：
+
** 如果任何所选成员卷与存储快照图像的多个保留容量对象相关联，将显示"查看容量"对话框。转到 <<步骤 2：审查容量>>。
** 如果所选成员卷均未与存储快照图像的多个保留容量对象相关联，则将显示"编辑优先级"对话框。转到 <<步骤 3：编辑优先级>>。






[[step-2-review-capacity]]
== 步骤 2：审查容量

如果选择了与多个保留容量对象相关联的成员卷，例如快照组和保留容量卷，则可以查看并增加回滚卷的保留容量。

.步骤
. 在保留容量非常低（或为零）的任何成员卷旁边，单击 *Edit* 列中的 *Increase capacity* 链接。
+
此时将显示"增加保留容量"对话框。

. 使用微调框调整容量百分比，然后单击 *Increase*。
+
如果包含所选存储对象的池或卷组上不存在可用容量，且存储阵列具有未分配容量，则可以添加容量。您可以创建新的池或卷组，并使用该池或卷组上的新可用容量重试此操作。

. 单击 *Next*，然后转到 <<步骤 3：编辑优先级>>。
+
此时将显示"编辑优先级"对话框。





[[step-3-edit-priority]]
== 步骤 3：编辑优先级

如果需要，您可以编辑回滚操作的优先级。

.关于此任务
回滚优先级确定以牺牲系统性能为代价将多少系统资源专用于回滚操作。

.步骤
. 使用滑块根据需要调整回滚优先级。
. 确认您要执行此操作，然后单击 *Finish*。


.结果
System Manager 执行以下操作：

* 使用选定快照映像上保存的内容还原快照一致性组成员卷。
* 使回滚卷立即可用于主机访问。无需等待回滚操作完成。


.完成后
选择菜单：Home[View Operations in Progress] 以查看回滚操作的进度。

如果回滚操作不成功，则操作暂停。您可以恢复暂停的操作，如果仍然不成功，请按照 Recovery Guru 程序更正问题或联系技术支持。
