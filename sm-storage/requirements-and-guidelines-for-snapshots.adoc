= SANtricity System Manager 中快照的要求和准则
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
创建和使用快照时，请查看以下要求和准则。



== 快照映像和快照组

* 每个快照映像仅与一个快照组关联。
* 第一次为关联对象创建计划或即时快照映像时，即会创建快照组。这将创建保留容量。
+
您可以从池和卷组页面查看快照组。

* 当存储阵列脱机或关闭电源时，不会发生计划的快照映像。
* 如果删除具有快照计划的快照组，也会删除快照计划。
* 如果您有一个不再需要的快照卷，则可以重复使用它以及任何关联的保留容量，而不是将其删除。这会创建相同基本卷的不同快照卷。您可以将快照卷或快照一致性组快照卷与相同的快照映像或不同的快照映像重新关联，只要快照映像位于相同的基本卷中即可。




== 快照一致性组

* 快照一致性组包含作为快照一致性组成员的每个卷的一个快照组。
* 一个快照一致性组只能与一个计划相关联。
* 如果删除具有快照计划的快照一致性组，也会删除快照计划。
* 不能单独管理与快照一致性组关联的快照组。相反，必须在快照一致性组级别执行管理操作（创建快照映像、删除快照映像或快照组以及回滚快照映像）。




== 基础卷

* 快照卷必须具有与关联的基本卷相同的数据保证 (DA) 和安全设置。
* 无法为出现故障的基本卷创建快照卷。
* 如果基本卷驻留在卷组中，则任何关联的快照一致性组的成员卷都可以驻留在池或卷组中。
* 如果基本卷驻留在池中，则任何关联的快照一致性组的所有成员卷都必须驻留在与基本卷相同的池中。




== 预留容量

* 保留容量仅与一个基本卷相关联。
* 使用计划可能会产生大量快照图像。确保您有足够的保留容量用于计划的快照。
* 快照一致性组的保留容量卷必须与快照一致性组成员卷的相关基本卷具有相同的数据保证 (DA) 和安全设置。




== 挂起的 Snapshot 映像

在以下情况下，快照映像创建可能保持"待处理"状态：

* 包含此快照映像的基本卷是异步镜像组的成员。
* 基本卷当前处于同步操作中。快照映像创建在同步操作完成后立即完成。




== 快照图像的最大数量

* 如果卷是快照一致性组的成员，则 System Manager 会为该成员卷创建一个快照组。此快照组计入每个基本卷允许的最大快照组数。
* 如果尝试在快照组或快照一致性组上创建快照映像，但关联的组已达到其快照映像的最大数量，您有两种选择：
+
** 为快照组或快照一致性组启用自动删除。
** 从快照组或快照一致性组中手动删除一个或多个快照图像并重试此操作。






== 自动删除

如果快照组或快照一致性组已启用自动删除，则当系统为该组创建新快照映像时，System Manager 会删除最旧的快照映像。



== 回滚操作

* 正在执行回滚操作时，无法执行以下操作：
+
** 删除用于回滚的快照映像。
** 为参与回滚操作的基本卷创建新的快照映像。
** 更改关联快照组的 Repository-Full 策略。


* 当以下任一操作正在进行时，您无法启动回滚操作：
+
** 容量扩展（向池或卷组添加容量）
** 卷扩展（增加卷的容量）
** 卷组的 RAID 级别更改
** 卷的段大小更改


* 如果基本卷参与卷副本，则无法启动回滚操作。
* 如果基本卷是远程镜像中的辅助卷，则无法启动回滚操作。
* 如果关联快照存储库卷中的任何已用容量具有不可读扇区，则回滚操作将失败。
