= 在 SANtricity System Manager 中取消分配卷
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果不再需要从主机或主机群集对该卷进行 I/O 访问，请取消分配主机或主机群集的卷。

.关于此任务
取消分配卷时，请记住以下准则：

* 如果您要从主机群集中删除最后分配的卷，并且主机群集还具有分配了特定卷的主机，请确保在删除主机群集的最后一个分配之前删除或移动这些分配。
* 如果将主机群集、主机或主机端口分配给已注册到操作系统的卷，则必须先清除此注册，然后才能删除这些节点。


.步骤
. 选择菜单：Storage[Hosts]。
. 选择要编辑的主机或主机群集，然后单击 *取消分配卷*。
+
此时将显示一个对话框，其中显示当前分配的所有卷。

. 选中要取消分配的每个卷旁边的复选框，或选中表头中的复选框以选择所有卷。
. 单击 *Unassign*。


.结果
* 未分配的卷可用于新分配。
* 在主机上配置更改之前，主机操作系统仍可识别卷。
