= 在 SANtricity System Manager 中手动创建池
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果池自动配置功能未提供满足您需求的池，您可以手动（从一组候选项中）创建池。

池提供必要的逻辑存储容量，您可以从中创建单个卷，然后可用于托管应用程序。

.开始之前
* 必须至少有 11 个驱动器具有相同的驱动器类型（HDD 或 SSD）。
* 盘架丢失保护要求构成池的驱动器至少位于六个不同的驱动器盘架中，并且一个驱动器盘架中不超过两个驱动器。
* 抽屉丢失保护要求构成存储池的驱动器位于至少五个不同的抽屉中，并且存储池包括来自每个抽屉的同等数量的驱动器架。
* 配置 EF600 或 EF300 存储阵列时，确保每个控制器可以访问前 12 个插槽中的数量相等的驱动器，以及最后 12 个插槽中的数量相等的驱动器。此配置有助于控制器更有效地使用驱动器端 PCIe 总线。当前 System Manager 允许在创建卷组时在高级功能下选择驱动器。要创建池，建议使用存储阵列中的所有驱动器。


.步骤
. 选择菜单：Storage[Pools & Volume Groups]。
. 单击菜单：创建 [Pool]。
+
此时将显示"创建池"对话框。

. 输入池的名称。
. *可选：*如果您的存储阵列中有多个类型的驱动器，请选择要使用的驱动器类型。
+
结果表列出了您可以创建的所有可能的池。

. 根据以下特征选择要使用的池候选，然后单击 *创建*。
+
[cols="25h,~"]
|===
| 特征 | 用途 


 a| 
空闲容量
 a| 
显示池候选的空闲容量（以 GiB 为单位）。选择一个具有满足应用程序存储需求的容量的候选池。

保护（备用）容量也分布在整个池中，不属于可用容量。



 a| 
驱动器总数
 a| 
显示池候选项中可用的驱动器数量。

System Manager 会自动为保留容量保留尽可能多的驱动器（对于池中的每六个驱动器，System Manager 会为保留容量保留一个驱动器）。

当发生驱动器故障时，保留容量用于保存重建的数据。



 a| 
驱动器块尺寸（仅限 EF300 和 EF600）
 a| 
显示池中的驱动器可以写入的块大小（扇区大小）。值可能包括：

** 512 -- 512 字节扇区大小。
** 4K -- 4,096 字节扇区大小。




 a| 
支持安全功能
 a| 
指示此候选池是否完全由支持安全的驱动器组成，这些驱动器可以是 Full Disk Encryption (FDE) 驱动器或 Federal Information Processing Standard (FIPS) 驱动器。

** 您可以使用 Drive Security 保护池，但所有驱动器必须具有安全功能才能使用此功能。
** 如果要创建仅限 FDE 的池，请在"支持安全"列中查找 *Yes - FDE*。如果要创建仅限 FIPS 的池，请查找 *Yes - FIPS* 或 *Yes - FIPS (Mixed)*。"Mixed" 表示 140-2 和 140-3 级别驱动器的混合。如果您使用这些级别的混合，请注意，池将在较低的安全级别 (140-2) 运行。
** 您可以创建一个由驱动器组成的池，这些驱动器可能具有安全功能，也可能不具有安全功能，或者是安全级别的混合。如果池中的驱动器包括不具备安全功能的驱动器，则无法确保池安全。




 a| 
启用安全？
 a| 
提供使用具有安全功能的驱动器启用 Drive Security 功能的选项。如果池具有安全功能，并且您已创建安全密钥，则可以通过选中复选框来启用安全性。

[NOTE]
====
启用 Drive Security 后删除它的唯一方法是删除池并擦除驱动器。

====


 a| 
支持 DA
 a| 
指示此池候选项是否可用 Data Assurance (DA)。DA 检查并更正数据通过控制器传输到驱动器时可能发生的错误。

如果所有驱动器都支持 DA，则启用 DA。创建卷后，可以通过选择菜单：存储[卷 > 查看/编辑设置 > 高级 > 永久禁用 Data Assurance] 来禁用 DA。如果在卷上禁用 DA，则无法重新启用它。



 a| 
支持资源调配（仅限 EF300 和 EF600）
 a| 
显示资源调配是否可用于此池候选。资源调配是 EF300 和 EF600 存储阵列中提供的一项功能，它允许卷立即投入使用，而无需后台初始化过程。



 a| 
磁盘架丢失保护
 a| 
显示磁盘架丢失保护是否可用。

如果使用单个驱动器盘架完全失去通信，盘架丢失保护可保证对池中卷上的数据的可访问性。



 a| 
抽屉丢失保护
 a| 
显示抽屉丢失保护是否可用，仅当您使用包含抽屉的驱动器架时才提供。

如果与驱动器架中的单个抽屉发生完全通信中断，抽屉丢失保护可保证对池中卷上的数据的可访问性。



 a| 
支持的卷块大小（仅限 EF300 和 EF600）
 a| 
显示可以为池中的卷创建的块大小：

** 512n -- 原生 512 字节。
** 512e -- 模拟 512 字节。
** 4K -- 4,096 字节。


|===
