= 在 SANtricity System Manager 中创建快照一致性组
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
为确保您拥有一致的副本，您可以创建一组名为 _snapshot consistency group_ 的多个卷。

此组允许您同时制作所有卷的快照映像，以实现一致性。属于快照一致性组的每个卷都称为_成员卷_。将卷添加到快照一致性组时，系统会自动创建与此成员卷对应的新快照组。

.关于此任务
快照一致性组创建顺序允许您为该组选择成员卷，并为成员卷分配容量。

创建快照一致性组的过程是一个多步骤过程。



== 步骤 1：将成员添加到快照一致性组

选择成员以指定构成快照一致性组的卷集合。您在快照一致性组上执行的任何操作均统一扩展到选定的成员卷。

.开始之前
成员卷必须为 Optimal。

.步骤
. 选择菜单：Storage[Snapshots]。
. 单击 *Snapshot Consistency Groups* 选项卡。
. 选择菜单：Create[Snapshot consistency group]。
+
此时将显示"创建快照一致性组"对话框。

. 选择要作为成员卷添加到快照一致性组的卷。
. 单击 *Next*，然后转到 <<步骤 2：为快照一致性组保留容量>>。




== 步骤 2：为快照一致性组保留容量

将保留容量关联到快照一致性组。System Manager 根据快照一致性组的属性建议卷和容量。您可以接受建议的保留容量配置或自定义分配的存储。

.关于此任务
在"保留容量"对话框中，卷候选表仅显示支持指定保留容量的候选。保留容量是用于任何复制服务操作和存储对象的物理分配容量。主机无法直接读取。

.步骤
. 使用微调框为快照一致性组分配保留容量。执行以下操作之一：
+
** *接受默认设置*。
+
使用此推荐选项为具有默认设置的每个成员卷分配保留容量。

** *分配您自己的预留容量设置，以满足您的数据存储需求。*
+
使用以下指南分配预留容量。

+
*** 保留容量的默认设置为基本卷容量的 40%。通常这个容量就足够了。
*** 所需的容量因 I/O 写入卷的频率和大小以及快照映像收集的数量和持续时间而异。




. *可选：* 如果更改默认保留容量设置，请单击 *Refresh Candidates* 以刷新指定保留容量的候选列表。
. 单击 *Next*，然后转到 <<步骤 3：编辑快照一致性组的设置>>。




== 步骤 3：编辑快照一致性组的设置

接受或选择快照一致性组的自动删除设置和预留容量警报阈值。

.关于此任务
快照一致性组创建顺序允许您为该组选择成员卷，并为成员卷分配容量。

.步骤
. 根据需要接受或更改快照一致性组的默认设置。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
*Snapshot 一致性组设置*



 a| 
名称
 a| 
指定快照一致性组的名称。



 a| 
启用自动删除快照映像时...
 a| 
如果要在指定限制后自动删除快照图像，请选中此复选框；使用旋转框更改限制。如果清除此复选框，快照图像创建将在 32 个图像后停止。



 a| 
*保留容量设置*



 a| 
在...时提醒我
 a| 
使用微调框可调整系统在快照一致性组的保留容量接近满时发送警报通知的百分比点。

当快照一致性组的保留容量超过指定阈值时，请使用提前通知来增加保留容量或在剩余空间用完之前删除不必要的对象。



 a| 
完全保留容量的政策
 a| 
从下列策略中选择一项：

** *清除最旧的快照映像* -- 系统会自动清除快照一致性组中最旧的快照映像，从而释放快照映像保留容量，以便在组内重复使用。
** *拒绝对基本卷的写入* -- 当保留容量达到其最大定义百分比时，系统会拒绝对触发保留容量访问的基本卷的任何 I/O 写入请求。


|===
====
. 对快照一致性组配置感到满意后，单击 *完成*。
