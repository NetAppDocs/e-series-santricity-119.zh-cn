[[why-dont-i-see-all-my-volumes-hosts-or-host-clusters]]
== 为什么我没有看到所有的卷、主机或主机集群？

具有启用 DA 的基本卷的快照卷没有资格分配给不支持数据保障 (DA) 的主机。必须先在基本卷上禁用 DA，然后才能将快照卷分配给不支持 DA 的主机。

对于要向其分配快照卷的主机，请考虑以下准则：

* 如果主机通过不支持 DA 的 I/O 接口连接到存储阵列，则主机不支持 DA。
* 如果主机群集至少有一个主机成员不具备 DA 功能，则该主机群集不具备 DA 功能。


[NOTE]
====
无法在与快照（一致性组、快照组、快照映像和快照卷）、卷副本和镜像关联的卷上禁用 DA。在基本卷上禁用 DA 之前，必须删除所有关联的保留容量和快照对象。

====


[[what-is-a-snapshot-image]]
== 什么是快照映像？

快照映像是在特定时间点捕获的卷内容的逻辑副本。快照映像使用最少的存储空间。

快照图像数据的存储方式如下：

* 创建快照映像时，它与基本卷完全匹配。拍摄快照后，当基本卷上的任何块或块集发生第一次写入请求时，原始数据将在新数据写入到基本卷之前复制到快照保留容量。
* 后续快照仅包括自创建第一个快照映像以来已更改的数据块。每次后续的写入时复制操作都会将即将在基本卷上覆盖的原始数据保存到快照保留容量，然后再将新数据写入到基本卷。




[[why-use-snapshot-images]]
== 为什么要使用快照映像？

您可以使用快照来防止意外或恶意的数据丢失或损坏，并允许从中恢复。

选择一个基本卷或一组基本卷（称为快照一致性组），然后通过以下一种或多种方式捕获快照映像：

* 您可以创建单个基本卷的快照映像或由多个基本卷组成的快照一致性组。
* 您可以手动拍摄快照，也可以为基本卷或快照一致性组创建计划，以自动捕获定期快照映像。
* 您可以创建快照映像的主机可访问快照卷。
* 您可以执行回滚操作以还原快照图像。


系统保留多个快照图像作为还原点，您可以使用它们在特定时间点回滚到已知良好的数据集。回滚功能可防止意外删除数据和数据损坏。



[[what-kinds-of-volumes-can-be-used-for-snapshots]]
== 可以使用哪些类型的卷进行快照？

标准卷和精简卷是唯一可用于存储快照映像的卷类型。不能使用非标准卷。基本卷可以驻留在池或卷组上。



[[why-would-i-create-a-snapshot-consistency-group]]
== 为什么要创建快照一致性组？

如果要确保同时在多个卷上拍摄快照映像，请创建一个快照一致性组。

例如，由多个卷组成的数据库需要保持一致以进行恢复，因此需要快照一致性组来收集所有卷的协调快照，并使用它们来还原整个数据库。

快照一致性组中包含的卷称为 _成员卷_。

可以在快照一致性组上执行以下快照操作：

* 创建快照一致性组的快照映像以获取成员卷的同时映像。
* 为快照一致性组创建一个计划，以自动捕获成员卷的定期同时映像。
* 创建快照一致性组映像的主机可访问快照卷。
* 对快照一致性组执行回滚操作。




[[what-is-a-snapshot-volume-and-when-does-it-need-reserved-capacity]]
== 什么是快照卷？什么时候需要保留容量？

快照卷允许主机访问快照映像中的数据。快照卷包含其自己的保留容量，该容量可保存对基本卷的任何修改，而不会影响原始快照映像。主机无法读取或写入快照映像。如果要读取或写入快照数据，请创建快照卷并将其分配给主机。

您可以创建两种类型的快照卷。快照卷的类型决定它是否使用保留容量。

* *只读* -- 创建为只读的快照卷为主机应用程序提供了对快照映像中包含的数据副本的读取访问权限。只读快照卷不使用保留容量。
* *读写* -- 创建为读写的快照卷允许您对快照卷进行更改，而不会影响引用的快照映像。读写快照卷使用保留容量来存储这些更改。您可以随时将只读快照卷转换为读写卷。




[[what-is-a-snapshot-group]]
== 什么是快照组？

快照组是单个关联基本卷的时间点快照映像的集合。

System Manager 将快照映像组织成_快照组_。快照组无需用户操作，但您可以随时调整快照组上的保留容量。此外，当满足以下条件时，可能会提示您创建保留容量：

* 每当您拍摄尚未具有快照组的基本卷的快照时，System Manager 都会自动创建快照组。这将为用于存储后续快照映像的基本卷创建保留容量。
* 每当您为基本卷创建快照计划时，System Manager 都会自动创建快照组。




[[why-would-i-disable-a-snapshot-volume]]
== 为什么要禁用快照卷？

如果要将不同的快照卷分配给快照映像，请禁用快照卷。可以保留禁用的快照卷供以后使用。

如果您不再需要快照卷或一致性组快照卷，并且不打算在以后重新创建它，则应删除该卷，而不是禁用它。



[[what-is-the-disabled-state]]
== 什么是禁用状态？

处于禁用状态的快照卷当前未分配给快照映像。要启用快照卷，必须使用重新创建操作将新的快照映像分配给禁用的快照卷。

快照卷特性由分配给它的快照映像定义。处于已禁用状态的快照卷上的读写活动已挂起。



[[why-would-i-suspend-a-snapshot-schedule]]
== 为什么要暂停快照计划？

当计划被暂停时，计划的快照映像创建不会发生。您可以暂停快照计划以节省存储空间，然后在以后恢复计划的快照。

如果不需要快照计划，则应删除该计划，而不是将其挂起。
