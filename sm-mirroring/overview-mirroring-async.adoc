异步镜像功能为本地存储阵列和远程存储阵列之间的数据复制提供了控制器级、基于固件的机制。



[[what-is-asynchronous-mirroring]]
== 什么是异步镜像？

_Asynchronous mirroring_ 捕获特定时间点的主卷的状态，并仅复制自上次图像捕获以来已更改的数据。可以立即更新主站点，并在带宽允许的情况下更新辅助站点。当网络资源可用时，信息将被缓存并稍后发送。

异步镜像是基于每个卷创建的，但在组级别进行管理，允许您将不同的远程镜像卷与给定存储阵列上的任何主卷相关联。这种类型的镜像非常适合满足不间断操作的需求，并且一般来说，对于周期性流程来说，网络效率要高得多。
