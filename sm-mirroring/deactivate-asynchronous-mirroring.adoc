= 在 SANtricity System Manager 中停用异步镜像
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以停用本地和远程存储阵列上的异步镜像，以重新建立存储阵列上专用端口的正常使用。

.开始之前
* 您必须删除所有镜像关系。验证是否已从本地和远程存储阵列中删除所有镜像一致性组和镜像对。
* 本地存储阵列和远程存储阵列必须通过 Fibre Channel 结构或 iSCSI 接口连接。


.关于此任务
停用异步镜像时，本地和远程存储阵列上不会发生镜像活动。

.步骤
. 选择菜单：Storage[Asynchronous Mirroring]。
. 选择菜单：Uncommon Tasks[Deactivate]。
+
系统显示确认信息。

. 选择 *是* 确认。


.结果
* 控制器专用于异步镜像通信的 HBA 主机通道现在可以接受主机读取和写入请求。
* 此存储阵列中的任何卷都不能作为主卷或辅助卷参与镜像关系。
