= 了解 SANtricity 软件中的同步镜像术语
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
了解同步镜像术语如何适用于您的存储阵列。

[cols="25h,~"]
|===
| 术语 | 说明 


 a| 
本地存储阵列
 a| 
本地存储阵列是您要执行操作的存储阵列。

当您在本地角色列中看到 *Primary* 时，它指示存储阵列包含在镜像关系中占有主要角色的卷。当您在本地角色列中看到 *Secondary* 时，它指示存储阵列包含在镜像关系中具有辅助角色的卷。



 a| 
镜像对
 a| 
镜像对由两个卷组成，一个主卷和一个辅助卷。



 a| 
主卷
 a| 
镜像对的主卷是要镜像的源卷。



 a| 
恢复点目标 (RPO)
 a| 
恢复点目标 (RPO) 表示一个目标，指示镜像对中主卷和辅助卷之间被认为可接受的差异。RPO 为零表示不能容忍主卷和辅助卷之间的任何差异。RPO 大于零表示辅助卷不够新或落后于主卷。



 a| 
远程存储阵列
 a| 
远程存储阵列通常被指定为辅助站点，它通常在镜像配置中保存数据的副本。



 a| 
预留容量
 a| 
保留容量是用于任何复制服务操作和存储对象的物理分配容量。主机无法直接读取。



 a| 
角色更改
 a| 
角色变更是指将主要角色分配给辅助卷，反之亦然。



 a| 
二级卷
 a| 
镜像对的辅助卷通常位于辅助站点，并保存数据的副本。



 a| 
同步
 a| 
在本地存储阵列和远程存储阵列之间的初始同步时进行同步。当通信中断后主卷和辅助卷不同步时，也会发生同步。当通信链路再次工作时，任何未复制的数据都将同步到辅助卷的存储阵列。

|===
