= 了解 SANtricity System Manager 中的同步镜像状态
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
同步镜像对的状态指示主卷和辅助卷上的数据是否已同步。镜像状态与镜像对中卷的组件状态无关。

[NOTE]
====
此功能在 EF600/EF600C 或 EF300/EF300C 存储系统中不可用。

====
同步镜像对可具有以下状态之一：

* *最佳*
+
指示镜像对中的卷是同步的，这意味着存储阵列之间的结构连接是可操作的，并且每个卷都处于所需的工作状态。

* *正在同步*
+
显示镜像对之间的数据同步进度。此状态也将在初始同步期间显示。

+
通信链路中断后，仅将链路中断期间主卷上已更改的数据块复制到辅助卷。

* *未同步*
+
指示主卷的存储阵列无法将传入数据写入远程阵列。本地主机可以继续写入主卷，但远程写入不会发生。不同的条件可能会阻止主卷的存储阵列将传入数据写入辅助卷，例如：

+
** 辅助卷不可访问。
** 远程存储数组不可访问。
** 存储阵列之间的结构连接不可访问。
** 无法使用新的全球标识符 (WWID) 更新辅助卷。


* *已暂停*
+
指示同步镜像操作已被用户挂起。当镜像对被挂起时，不会尝试接触辅助卷。对主卷的任何写入都会持续记录在镜像保留容量卷中。

* *失败*
+
表示由于主卷、辅助卷或镜像保留容量出现故障，同步镜像操作无法正常运行。
