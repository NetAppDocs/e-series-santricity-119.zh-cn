= 了解 SANtricity 软件中的同步镜像
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
同步镜像功能提供远程存储阵列之间的在线实时数据复制。

[NOTE]
====
此功能在 EF600/EF600C 或 EF300/EF300C 存储系统中不可用。

====


== 什么是同步镜像？

_同步镜像_ 实时复制数据卷，以确保连续可用性。存储阵列控制器管理镜像操作，对主机和软件应用程序透明。

这种类型的镜像非常适合业务连续性目的，例如灾难恢复。
