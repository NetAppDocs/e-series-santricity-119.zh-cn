= 在 SANtricity System Manager 中测试镜像一致性组的通信
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以测试通信链路，以诊断本地存储阵列和与镜像一致性组关联的远程存储阵列之间可能存在的通信问题。

.开始之前
要测试的镜像一致性组必须存在于本地和远程存储阵列上。

.关于此任务
您可以运行四种不同的测试：

* *连接* -- 验证两个控制器是否有通信路径。连接测试在存储阵列之间发送阵列间消息，然后验证远程存储阵列上是否存在对应的镜像一致性组。它还验证远程存储阵列上的镜像一致性组的成员卷是否与本地存储阵列上的镜像一致性组的成员卷匹配。
* *延迟* -- 向与镜像一致性组关联的远程存储阵列上的每个镜像卷发送 SCSI Test Unit 命令，以测试最小、平均和最大延迟。
* *带宽* -- 向远程存储阵列发送两条阵列间消息，以测试执行测试的阵列上的端口的最小、平均和最大带宽以及协商的链路速度。
* *端口连接* -- 显示本地存储阵列上用于镜像的端口以及远程存储阵列上接收镜像数据的端口。


.步骤
. 选择菜单：Storage[Asynchronous Mirroring]。
. 选择 *Mirror Consistency Groups* 选项卡，然后选择要测试的镜像一致性组。
. 选择 *Test Communication*。
+
此时将显示"测试通信"对话框。

. 选择要在与所选镜像一致性组关联的本地和远程存储阵列之间执行的一个或多个通信测试，然后单击 *Test*。
. 查看 Results 窗口中显示的信息。
+
[cols="35h,~"]
|===
| 通信测试状态 | 说明 


 a| 
正常且无错误
 a| 
镜像一致性组正在正确通信。



 a| 
通过状态（但不正常）
 a| 
检查可能的网络或连接问题并重试测试。



 a| 
失败状态
 a| 
说明了故障原因。请参见 Recovery Guru 以纠正此问题。



 a| 
端口连接错误
 a| 
原因可能是本地存储阵列未连接或无法连接到远程存储阵列。请参阅 Recovery Guru 以纠正问题。

|===


.结果
通信测试完成后，此对话框显示"正常"状态、"通过"状态或"失败"状态。

如果通信测试返回 Failed 状态，则在关闭此对话框后测试会继续运行，直到恢复镜像一致性组之间的通信。
