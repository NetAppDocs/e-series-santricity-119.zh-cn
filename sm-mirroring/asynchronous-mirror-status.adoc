= 在 SANtricity System Manager 中查看异步镜像状态
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
镜像状态定义了镜像一致性组和镜像卷对的状态。



== 镜像一致性组的状态

[cols="25h,~"]
|===
| 状态 | 说明 


 a| 
正在同步（初始同步）
 a| 
镜像卷对之间已完成的初始数据同步进度。

在初始同步期间，卷可以转换为以下状态：降级/失败/最佳/未知。



 a| 
正在同步（间隔同步）
 a| 
已在镜像卷对之间完成的定期数据同步的进度。



 a| 
系统已挂起
 a| 
存储系统在镜像一致性组级别暂停所有镜像对上的数据同步。

镜像一致性组中至少有一个镜像对处于"已停止"或"失败"状态。



 a| 
用户已暂停
 a| 
用户在镜像一致性组级别暂停所有镜像对上的数据同步。

此状态有助于减少在将本地存储阵列上的任何更改数据复制到远程存储阵列时可能对主机应用程序产生的任何性能影响。



 a| 
已暂停
 a| 
由于访问远程存储阵列时出错，数据同步过程已暂停。



 a| 
孤立
 a| 
当一致性镜像组中的成员卷已在一致性镜像组的一侧（主侧或辅助侧）被删除但未在另一侧删除时，就会存在孤立的镜像对卷。

当恢复阵列间通信且镜像配置的两侧协调镜像参数时，会检测到孤立的镜像对卷。

您可以删除镜像对以更正孤立的镜像对状态。



 a| 
角色变更待定/正在进行中
 a| 
镜像一致性组之间的角色更改处于待处理状态或正在进行中。

角色反转更改（更改为主要角色或次要角色）会影响选定镜像一致性组中的所有异步镜像对。

您可以取消待定角色更改，但不能取消正在进行的角色更改。



 a| 
角色冲突
 a| 
由于角色更改操作期间本地存储阵列和远程存储阵列之间的通信问题，镜像一致性组之间发生角色冲突。

当通信问题得到解决时，会发生角色冲突。使用 Recovery Guru 从此错误中恢复。

解决角色冲突时不允许强制提升。

|===


== 镜像对的状态

镜像对的状态指示主卷和辅助卷上的数据是否已同步。

[cols="25h,~"]
|===
| 状态 | 说明 


 a| 
正在同步
 a| 
镜像对之间已完成的初始或定期数据同步的进度。

有两种类型的同步：初始同步和定期同步。初始同步进度也会显示在"长期运行操作"对话框中。



 a| 
最佳
 a| 
镜像对中的卷是同步的，这表明存储阵列之间的连接是可操作的，并且每个卷都处于所需的工作状态。



 a| 
未完成
 a| 
远程存储阵列上的异步镜像对不完整，因为镜像对创建序列是在 System Manager 不支持的存储阵列上启动的，并且镜像对尚未在辅助阵列上完成。

当卷添加到远程存储阵列上的镜像一致性组时，镜像对创建过程即完成。此卷将成为异步镜像对中的辅助卷。

如果远程存储阵列由 System Manager 管理，则镜像对将自动完成。



 a| 
失败
 a| 
由于主卷、辅助卷或镜像保留容量出现故障，异步镜像操作无法正常运行。



 a| 
孤立
 a| 
当一致性镜像组中的成员卷已在一致性镜像组的一侧（主侧或辅助侧）被删除但未在另一侧删除时，就会存在孤立的镜像对卷。

当两个存储阵列之间恢复通信且镜像配置的两侧协调镜像参数时，会检测到孤立的镜像对卷。

您可以删除镜像对以更正孤立的镜像对状态。



 a| 
已停止
 a| 
镜像对处于停止状态，因为镜像一致性组处于系统挂起状态。

|===
