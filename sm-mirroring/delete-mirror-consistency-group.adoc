= 在 SANtricity System Manager 中删除镜像一致性组
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以删除本地存储阵列和远程存储阵列上不再需要的镜像一致性组。

.开始之前
必须从镜像一致性组中删除所有镜像对。

.步骤
. 选择菜单：Storage[Asynchronous Mirroring]。
. 选择 *Mirror Consistency Groups* 选项卡。
+
将显示 Mirror Consistency Group（镜像一致性组）表，并显示与存储阵列关联的所有镜像一致性组。

. 选择要删除的镜像一致性组，然后选择 menu:Uncommon Tasks[Delete]。
+
系统显示确认信息。

. 选择 *是* 删除镜像一致性组。


.结果
System Manager 执行以下操作：

* 首先删除本地存储阵列上的镜像一致性组，然后删除远程存储阵列上的镜像一致性组。
* 从 Mirror Consistency Group 表中删除镜像一致性组。


.完成后
有时，可能会出现从本地存储阵列中成功删除镜像一致性组的情况，但通信错误会阻止从远程存储阵列中删除镜像一致性组。在此情况下，必须访问远程存储阵列以删除相应的镜像一致性组。
