= 在 SANtricity System Manager 中暂停和恢复镜像对的同步
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 Suspend 选项和 Resume 选项来控制何时同步镜像对中主卷和辅助卷上的数据。

.关于此任务
如果手动挂起镜像对，则该镜像对在手动恢复之前不会同步。

.步骤
. 选择菜单：Storage[Synchronous Mirroring]。
. 选择要暂停或恢复的镜像对，然后选择 menu:More[Suspend] 或 menu:More[Resume]。
+
系统显示确认信息。

. 选择 *是* 确认。


.结果
System Manager 执行以下操作：

* 暂停或恢复镜像对之间的数据传输，而不删除镜像关系。
* 对于 _suspended_ 镜像对：
+
** 在镜像配对表中显示 *已挂起*。
** 记录在同步挂起时写入镜像对主卷的任何数据。


* 对于 _resumed_ 镜像对，在恢复同步时，将数据自动写入镜像对的辅助卷。无需完全同步。
