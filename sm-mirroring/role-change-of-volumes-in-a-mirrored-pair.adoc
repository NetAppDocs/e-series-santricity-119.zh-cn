= 了解 SANtricity 软件中镜像对中的卷角色更改
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在镜像对中的卷之间更改角色。您可以通过将主卷降级为辅助角色或将辅助卷升级为主角色来执行此操作。

[NOTE]
====
EF600/EF600C 或 EF300/EF300C 存储系统上不提供同步镜像。

====
查看有关角色更改操作的以下信息：

* 当主卷降级为辅助角色时，该镜像对中的辅助卷将提升为主角色，反之亦然。
* 当主卷降级为辅助角色时，已分配给该卷的主机不再具有对该卷的写入权限。
* 当辅助卷升级为主卷时，正在访问该卷的任何主机现在都可以对其进行写入。
* 如果本地存储阵列无法与远程存储阵列通信，则可以在本地存储阵列上强制更改角色。




== 强制角色更改

当本地存储阵列和远程存储阵列之间的通信问题阻止了辅助卷的升级或主卷的降级时，可以强制在镜像对中的卷之间进行角色更改。

您可以强制辅助端的卷过渡到主要角色。然后，恢复主机可以访问新升级的卷，业务运营可以继续。

[NOTE]
====
当远程存储阵列已恢复且任何通信问题都已解决时，将出现同步镜像 - 主卷冲突情况。恢复步骤包括重新同步卷。使用 Recovery Guru 从此错误中恢复。

====


== 什么时候允许和不允许强制提升？

在以下情况下，不允许强制提升镜像对中的卷：

* 镜像对中的任何卷都处于初始同步过程中。
* 镜像对处于"失败"、"角色更改挂起"或"角色更改正在进行"状态，或者任何关联的保留容量卷出现故障。




== 角色更改进行中状态

如果镜像配置中的两个存储阵列断开连接，并且镜像对的主卷被强制降级为辅助角色，并且镜像对的辅助卷被强制提升为主角色，则在恢复通信时，两个存储阵列上的卷都将处于 Role-Change-In-Progress 状态。

系统将通过传输更改日志、重新同步、将镜像对状态设置回正常操作状态并继续同步来完成角色更改过程。
