= 了解 SANtricity 软件中同步镜像的卷所有权
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以更改镜像对中的首选控制器所有者。

[NOTE]
====
此功能不适用于 EF600/EF600C 或 EF300/EF300C 存储系统上的同步镜像。

====
如果镜像对的主卷由控制器 A 所有，则辅助卷也将由远程存储阵列的控制器 A 所有。更改主卷的所有者将自动更改辅助卷的所有者，以确保两个卷由同一个控制器所有。主端的当前所有权变更会自动传播到辅助端的相应当前所有权变更。

例如，主卷由控制器 A 所有，然后将控制器所有者更改为控制器 B。在这种情况下，下一次远程写入会将辅助卷的控制器所有者从控制器 A 更改为控制器 B。由于辅助端的控制器所有权更改由主端控制，因此不需要存储管理员进行任何特殊干预。



== 控制器重置

控制器重置会导致主端的卷所有权从首选控制器所有者更改为存储阵列中的备用控制器。

有时，在远程写入可以写入辅助卷之前，控制器重置或存储阵列电源循环会中断远程写入。在这种情况下，控制器不需要执行镜像对的完全同步。

当控制器重置期间远程写入被中断时，主端的新控制器所有者读取存储在首选控制器所有者保留容量卷中的日志文件中的信息。然后，新的控制器所有者将受影响的数据块从主卷复制到辅助卷，无需完全同步镜像卷。
