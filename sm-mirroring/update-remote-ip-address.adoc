= 在 SANtricity System Manager 中更新远程存储阵列 IP 地址
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以更新远程存储阵列的 iSCSI IP 地址，以重新建立与本地存储阵列的连接。

.开始之前
必须将本地存储阵列和远程存储阵列配置为使用 iSCSI 连接进行异步镜像。

.步骤
. 选择菜单：Storage[Asynchronous Mirroring]。
. 选择 *Mirror Consistency Groups* 选项卡。
+
Mirror Consistency Group 表显示与存储阵列关联的所有镜像一致性组。

. 选择要更新的镜像一致性组，然后选择菜单：更多[更新远程 IP 地址]。
+
系统显示更新远程 IP 地址对话框。

. 选择 *Update* 以更新远程存储阵列的 iSCSI IP 地址。


.结果
系统重置远程存储阵列的 IP 地址，以重新建立与本地存储阵列的连接。
