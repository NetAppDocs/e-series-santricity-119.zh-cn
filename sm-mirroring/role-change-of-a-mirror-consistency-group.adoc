= 在 SANtricity 软件中更改镜像一致性组角色
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以更改镜像一致性组中镜像对之间的角色。为此，可以将主镜像一致性组降级为辅助角色，或将辅助镜像一致性组升级为主角色。

查看有关角色更改操作的以下信息：

* 角色更改会影响选定镜像一致性组中的所有镜像对。
* 当镜像一致性组降级到辅助角色时，该镜像一致性组中的所有镜像对也会降级到辅助角色，反之亦然。
* 当主镜像一致性组降级为辅助角色时，已分配给该组中成员卷的主机不再具有对它们的写入权限。
* 当镜像一致性组被提升为主角色时，访问该组中成员卷的任何主机现在都可以对其进行写入。
* 如果本地存储阵列无法与远程存储阵列通信，则可以在本地存储阵列上强制更改角色。




[[force-role-change]]
== 强制角色更改

当本地存储阵列和远程存储阵列之间的通信问题导致次镜像一致性组中的成员卷无法升级或主镜像一致性组中的成员卷无法降级时，可以强制在镜像一致性组之间更改角色。

您可以强制二级侧的镜像一致性组过渡到主角色。然后，恢复主机能够访问该镜像一致性组中新提升的成员卷，并且业务运营可以继续。



[[when-is-a-forced-promotion-allowed-and-not-allowed]]
== 什么时候允许和不允许强制提升？

仅当镜像一致性组的所有成员卷都已同步并且具有一致的恢复点时，才允许强制升级镜像一致性组。

在以下情况下不允许强制提升镜像一致性组：

* 镜像一致性组的任何成员卷都处于初始同步过程中。
* 镜像一致性组的任何成员卷都没有恢复点的时间点映像（例如，由于完全保留的容量错误）。
* 镜像一致性组不包含成员卷。
* 镜像一致性组处于 Failed、Role-Change-Pending 或 Role-Change-In-Progress 状态，或者任何关联的成员卷或保留容量卷出现故障。




[[mirror-group-role-conflict]]
== 镜像组角色冲突

当本地和远程存储阵列之间的通信问题得到解决时，会出现镜像组角色冲突情况。使用 Recovery Guru 从此错误中恢复。在解决双重角色冲突时，不允许强制提升。

要避免镜像组角色冲突情况和后续恢复步骤，请等待存储阵列之间的连接正常运行以强制角色更改。



[[role-change-in-progress-state]]
== 角色更改进行中状态

如果镜像配置中的两个存储阵列断开连接，并且镜像一致性组的主端被强制降级为辅助角色，并且镜像一致性组的辅助端被强制提升为主角色，则在恢复通信时，两个存储阵列上的镜像一致性组都将处于 Role-Change-In-Progress 状态。

系统将通过传输更改日志、重新同步、将镜像一致性组状态设置回正常运行状态并继续定期同步来完成角色更改过程。
