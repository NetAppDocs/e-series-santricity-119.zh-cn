= 在 SANtricity 软件中使用同步镜像的要求
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您计划使用同步镜像，请记住以下要求。



== Unified Manager

要启用和配置两个阵列之间的镜像，必须使用 Unified Manager 界面。Unified Manager 与 Web Services Proxy 一起安装在主机系统上。

* Web Services Proxy 服务必须正在运行。
* Unified Manager 必须通过 HTTPS 连接在本地主机上运行。
* Unified Manager 必须显示存储阵列的有效 SSL 证书。您可以使用 Unified Manager 接受自签名证书或安装您自己的安全证书，并导航到菜单：Certificate[Certificate Management]。




== 存储阵列

[NOTE]
====
EF300/EF300C 或 EF600/EF600C 存储阵列上不提供同步镜像。

====
* 您必须有两个存储阵列。
* 每个存储阵列必须有两个控制器。
* 必须在 Unified Manager 中发现两个存储阵列。
* 主阵列和辅助阵列中的每个控制器都必须配置以太网管理端口，并且必须连接到您的网络。
* 存储阵列的最低固件版本为 7.84。（它们可以各自运行不同的 OS 版本。）
* 您必须知道本地和远程存储阵列的密码。
* 必须在远程存储阵列上具有足够的可用容量，才能创建等于或大于要镜像的主卷的辅助卷。
* 您的本地和远程存储阵列通过 Fibre Channel 结构连接。




== 支持的连接

仅在具有光纤通道 (FC) 主机端口的控制器上支持同步镜像的通信。

同步镜像在本地存储阵列和远程存储阵列上的每个控制器上使用编号最高的主机端口。控制器主机总线适配器 (HBA) 主机端口 4 通常保留用于镜像数据传输。



== 镜像卷候选项

* RAID 级别、缓存参数和段大小在同步镜像对的主卷和辅助卷上可以不同。
* 同步镜像对中的主卷和辅助卷必须是标准卷。它们不能是精简卷或快照卷。
* 辅助卷必须至少与主卷一样大。
* 只有主卷可以具有与其关联的快照和/或是卷复制操作中的源卷或目标卷。
* 一个卷只能参与一个镜像关系。
* 给定存储阵列上支持的卷数有限制。确保存储阵列上配置的卷数小于支持的限制。当同步镜像处于活动状态时，创建的两个保留容量卷将计入卷限制。




== 预留容量

* 主卷和辅助卷需要保留容量来记录写入信息，以便从控制器重置和其他临时中断中恢复。
* 激活同步镜像时，将自动创建保留容量卷。由于镜像对中的主卷和辅助卷都需要保留容量，因此您必须确保在参与同步镜像关系的两个存储阵列上都有足够的可用容量。




== 驱动器安全功能

* 如果使用具有安全功能的驱动器，则主卷和辅助卷必须具有兼容的安全设置。此限制未强制执行；因此，您必须自己验证。
* 如果使用具有安全功能的驱动器，则主卷和辅助卷应使用相同的驱动器类型。此限制未强制执行；因此，您必须自己验证。
+
** 如果主卷使用 Full Disk Encryption (FDE) 驱动器，则辅助卷应使用 FDE 驱动器。
** 如果主卷使用 Federal Information Processing Standards 140-2 (FIPS) 验证的驱动器，则辅助卷应使用 FIPS 140-2 验证的驱动器。


* 如果使用数据保障 (DA)，则主卷和辅助卷必须具有相同的 DA 设置。
