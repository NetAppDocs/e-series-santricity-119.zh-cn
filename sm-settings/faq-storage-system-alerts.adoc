== 如果已禁用警报，该怎么办？

如果希望管理员接收有关存储阵列中发生的重要事件的通知，则必须配置警报方法。

对于使用 SANtricity System Manager 管理的存储阵列，您可以从"警报"页面配置警报。警报通知可以通过电子邮件、SNMP 陷阱或 syslog 消息发送。此外，可以从初始设置向导配置电子邮件警报。



== 如何配置 SNMP 或 syslog 警报？

除了电子邮件警报外，您还可以将警报配置为通过简单网络管理协议 (SNMP) 陷阱或 syslog 消息发送。

要配置 SNMP 或 syslog 警报，请转到菜单：设置[警报]。



== 为什么数组和警报之间的时间戳不一致？

当存储阵列发送警报时，它不会更正接收警报的目标服务器或主机的时区。相反，存储阵列使用本地时间 (GMT) 来创建用于警报记录的时间戳。因此，您可能会看到存储阵列的时间戳与接收警报的服务器或主机之间存在不一致。

由于存储阵列在发送警报时未针对时区进行校正，因此警报上的时间戳是 GMT 相关的，其时区偏移量为零。要计算适合您当地时区的时间戳，您应该从 GMT 确定小时偏移量，然后从时间戳中添加或减去该值。
