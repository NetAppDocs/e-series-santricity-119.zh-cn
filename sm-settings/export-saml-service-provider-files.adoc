= 在 SANtricity System Manager 中导出 SAML 服务提供程序文件
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如有必要，您可以导出存储阵列的 Service Provider 元数据，然后将文件重新导入 Identity Provider (IdP) 系统。

.开始之前
* 必须使用包含 Security admin 权限的用户配置文件登录。否则，将不会显示 Access Management 功能。
* 已配置并启用 SAML。


.关于此任务
在此任务中，您可以从控制器导出元数据（每个控制器一个文件）。IdP 需要此元数据来与控制器建立信任关系并处理身份验证请求。此文件包括 IdP 可用于发送请求的控制器域名或 IP 地址等信息。

.步骤
. 选择菜单：Settings[Access Management]。
. 选择 *SAML* 选项卡。
. 选择 *Export*。
+
此时将打开 Export Service Provider Files 对话框。

. 对于每个控制器，单击 *导出* 将元数据文件保存到本地系统。
+
[NOTE]
====
每个控制器的域名字段都是只读的。

====
+
记下文件的存储位置。

. 从本地系统中，找到您导出的 Service Provider 元数据文件。
+
每个控制器都有一个 XML 格式的文件。

. 从 IdP 服务器导入 Service Provider 元数据文件。您可以直接导入文件，也可以从中手动输入控制器信息。
. 单击 *Close*。
