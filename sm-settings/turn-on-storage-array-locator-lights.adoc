= 在 SANtricity System Manager 中打开存储阵列定位器指示灯
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要查找存储阵列在机柜中的物理位置，您可以打开其定位器 (LED) 指示灯。

.步骤
. 选择菜单：Settings[System]。
. 在 *常规* 下，单击 *打开存储阵列定位器指示灯*。
+
打开"打开存储阵列定位器指示灯"对话框，相应存储阵列的定位器指示灯打开。

. 物理定位存储阵列后，返回对话框并选择 *Turn Off*。


.结果
定位器灯关闭，对话框关闭。
