= 在 SANtricity System Manager 中为警报添加系统日志服务器
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您最多可为 syslog 警报添加五台服务器。

.开始之前
* syslog 服务器地址必须可用。此地址可以是完全限定的域名、IPv4 地址或 IPv6 地址。
* syslog 服务器的 UDP 端口号必须可用。此端口通常为 514。


.步骤
. 选择菜单：Settings[Alerts]。
. 选择 *Syslog* 选项卡。
. 选择 *Add Syslog Servers*。
+
此时将打开添加 Syslog 服务器对话框。

. 选择 *Add another syslog server*。
. 输入 syslog 服务器的信息，然后单击 *Add*。
+
** *Syslog 服务器地址* -- 输入完全限定的域名、IPv4 地址或 IPv6 地址。
** *UDP 端口* -- 通常，syslog 的 UDP 端口为 514。


+

NOTE: 您最多可以配置五个 syslog 服务器。



.结果
syslog 服务器地址显示在表中。
