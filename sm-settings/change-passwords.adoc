= 在 SANtricity System Manager 中更改密码
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在 Access Management 中更改每个用户配置文件的用户密码。

.开始之前
* 您必须以本地管理员身份登录，其中包括 Root 管理员权限。
* 您必须知道本地管理员密码。


.关于此任务
选择密码时，请记住以下准则：

* 任何新的本地用户密码都必须满足或超过当前设置的最低密码要求（在 View/Edit Settings 中）。
* 密码区分大小写。
* 设置密码时，不会从密码中删除尾随空格。如果密码中包含空格，请务必包含空格。
* 为提高安全性，请至少使用 15 个字母数字字符，并经常更改密码。


[NOTE]
====
在 System Manager 中更改密码也会在命令行界面 (CLI) 中更改密码。此外，密码更改会导致用户的活动会话终止。

====
.步骤
. 选择菜单：Settings[Access Management]。
. 选择 *Local User Roles* 选项卡。
. 从表中选择一个用户。
+
"更改密码"按钮变为可用。

. 选择 *Change Password*。
+
此时将打开更改密码对话框。

. 如果未为本地用户密码设置最小密码长度，则可以选中该复选框，要求所选用户输入密码以访问存储阵列，然后可以为所选用户键入新密码。
. 输入您的本地管理员密码，然后单击 *Change*。


.结果
如果用户当前已登录，密码更改将导致用户的活动会话终止。
