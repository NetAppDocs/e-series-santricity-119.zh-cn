= 删除 SANtricity System Manager 中用于警报的系统日志服务器
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以删除 syslog 服务器，使其不再接收警报。

.步骤
. 选择菜单：Settings[Alerts]。
. 选择 *Syslog* 选项卡。
. 选择一个 syslog 服务器地址，然后单击右上角的 *Remove*。
+
此时将打开确认删除 Syslog 服务器对话框。

. 确认操作，然后单击 *Delete*。


.结果
您删除的服务器不再接收来自事件监视器的警报。
