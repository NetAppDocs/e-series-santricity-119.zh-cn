= 在 SANtricity System Manager 中同步存储阵列时钟
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果未启用网络时间协议 (NTP)，则可以手动设置控制器上的时钟，以便它们与管理客户端（用于运行访问 SANtricity System Manager 的浏览器的系统）同步。

.关于此任务
同步可确保事件日志中的事件时间戳与写入主机日志文件的时间戳匹配。在同步过程中，控制器保持可用和可操作。

[NOTE]
====
如果在 System Manager 中启用了 NTP，请不要使用此选项来同步时钟。相反，NTP 使用 SNTP（Simple Network Time Protocol）自动将时钟与外部主机同步。

====
[NOTE]
====
同步后，您可能会注意到性能统计数据丢失或偏斜，时间表受到影响（ASUP、快照等），日志数据中的时间戳偏斜。使用 NTP 可以避免此问题。

====
.步骤
. 选择菜单：Settings[System]。
. 在 *常规* 下，单击 *同步存储阵列时钟*。
+
同步存储阵列时钟对话框打开。它显示控制器和用作管理客户端的计算机的当前日期和时间。

+
[NOTE]
====
对于单工存储阵列，仅显示一个控制器。

====
. 如果对话框中显示的时间不匹配，请单击 *Synchronize*。


.结果
同步成功后，事件日志和主机日志的事件时间戳相同。
