= 在 SANtricity System Manager 中查看 iSCSI 统计信息包
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以查看有关 iSCSI 连接到存储阵列的数据。

.关于此任务
System Manager 显示这些类型的 iSCSI 统计信息。所有统计信息都是只读的，无法设置。

* *以太网 MAC 统计信息* -- 提供媒体访问控制 (MAC) 的统计数据。MAC 还提供了一种称为物理地址或 MAC 地址的寻址机制。MAC 地址是分配给每个网络适配器的唯一地址。MAC 地址有助于将数据包发送到子网内的目的地。
* *以太网 TCP/IP 统计信息* -- 提供 TCP/IP 的统计数据，即 iSCSI 设备的传输控制协议 (TCP) 和互联网协议 (IP)。使用 TCP，网络主机上的应用程序可以相互创建连接，从而可以在数据包中交换数据。IP 是一种面向数据的协议，可在分组交换的互联网络中传输数据。IPv4 统计数据和 IPv6 统计数据分别显示。
* *本地目标/启动器（协议）统计信息* -- 显示 iSCSI 目标的统计信息，该目标提供对其存储介质的块级访问，并显示存储阵列在异步镜像操作中用作启动器时的 iSCSI 统计信息。
* *DCBX 运行状态统计* -- 显示各种数据中心桥接交换 (DCBX) 功能的运行状态。
* *LLDP TLV 统计数据* -- 显示链路层发现协议 (LLDP) 类型长度值 (TLV) 统计数据。
* *DCBX TLV 统计信息* -- 显示标识数据中心桥接 (DCB) 环境中存储阵列主机端口的信息。此信息将与网络对等设备共享，用于识别和功能目的。


您可以将这些统计数据中的每一个查看为原始统计数据或基线统计数据。原始统计数据是自控制器启动以来收集的所有统计数据。基线统计数据是自您设置基线时间以来收集的时间点统计数据。

.步骤
. 选择菜单：Settings[System]。
. 选择 *View iSCSI Statistics Packages*。
. 单击选项卡可查看不同的统计信息集。
. *可选：*要设置基线，请单击*设置新基线*。
+
设置基线为统计数据的收集设置了一个新的起点。相同的基线用于所有 iSCSI 统计信息。



有关不同类型统计信息的详细信息，请参见以下部分。

[[dcbx-operational-state-statistics]]
== DCBX 操作状态统计

选择 Data Center Bridging Exchange (DCBX) 操作状态统计信息时，将显示 DCBX 统计信息。

.DCBX 统计信息：
[%collapsible]
====
[cols="25h,~"]
|===
| 统计 | 定义 


 a| 
iSCSI 主机端口
 a| 
以 Controller #、Port # 格式指示检测到的主机端口的位置。



 a| 
优先级组
 a| 
指示优先级组 (PG) 应用程序的运行状态。状态为"已启用"或"已禁用"。



 a| 
基于优先级的流量控制
 a| 
指示基于优先级的流量控制 (PFC) 功能的运行状态。状态为"已启用"或"已禁用"。



 a| 
iSCSI 功能
 a| 
指示 Internet 小型计算机系统接口 (iSCSI) 应用程序的运行状态。状态为"已启用"或"已禁用"。



 a| 
FCoE 带宽
 a| 
指示以太网光纤通道 (FCoE) 带宽的状态。状态为 True 或 False。



 a| 
无 FCoE/FIP 映射不匹配
 a| 
指示 FCoE 和 FCoE Initialization Protocol (FIP) 之间是否存在映射不匹配。该值为 True 或 False。

|===
====

NOTE: 您可以在状态捕获文件中找到其他 DCBX 操作状态统计信息。

.LLDP TLV 统计：
[%collapsible]
====
[cols="25h,~"]
|===
| 统计 | 定义 


 a|

 a| 
以 Controller #、Port # 格式指示检测到的主机端口的位置。



 a| 
机箱 ID
 a| 
指示机箱 ID。



 a| 
机箱 ID 子类型
 a| 
指示机箱 ID 子类型。



 a| 
端口 ID
 a| 
指示端口 ID。



 a| 
端口 ID 子类型
 a| 
指示端口 ID 子类型。



 a|

指示接收方 LLDP 代理认为信息有效的秒数。

|===
====

NOTE: 您可以在状态捕获文件中找到其他 LLDP TLV 统计信息。



[[dcbx-tlv-statistics]]
== DCBX TLV 统计

选择 Data Center Bridging Exchange (DCBX) Type Length Value (TLV) Statistics（数据中心桥接交换 (DCBX) 类型长度值 (TLV) 统计信息）时，将显示以下统计信息：

* *局部统计* -- 出厂时在控制器上配置的 DCBX 参数。
* *运营统计* -- 由 DCBX 协商产生的 DCBX 参数。
* *远程统计* -- 来自控制器连接的对等设备的 DCBX 参数，通常是交换机。


.DCBX TLV 统计：
[%collapsible]
====
[cols="25h,~"]
|===
| 统计 | 定义 


 a| 
iSCSI 主机端口
 a| 
以 Controller #、Port # 格式指示检测到的主机端口的位置。



 a| 
流量控制模式
 a| 
整个端口的流量控制模式。有效值为 Disabled、Standard、Per Priority 或 Indeterminate。



 a| 
协议
 a| 
通信协议。有效值为 FCoE、FIP、iSCSI 或 UNKNOWN。



 a| 
优先级
 a| 
表示通信优先级编号的整数值。



 a| 
优先级组
 a| 
表示已分配协议的优先级组的整数值。



 a| 
优先级组 % 带宽
 a| 
指示分配给优先级组的带宽量的百分比值。



 a| 
DCBX PFC 状态
 a| 
特定端口的基于优先级的流量控制 (PFC) 状态。此值为启用或禁用。

|===
====

NOTE: 您可以在状态捕获文件中找到其他 DCBX TLV 统计信息。
