= 了解 SANtricity System Manager 中的证书
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 SANtricity System Manager 创建证书签名请求 (CSR)、导入证书和管理现有证书。



[[what-are-certificates]]
== 什么是证书？

_Certificates_ 是用于识别网站和服务器等在线实体的数字文件，用于在互联网上进行安全通信。有两种类型的证书：_signed certificate_ 由证书颁发机构 (CA) 进行验证，_self-signed certificate_ 由实体的所有者而不是第三方进行验证。

了解详情：

* link:how-certificates-work-sam.html["证书的工作原理"]
* link:certificate-terminology.html["证书术语"]




[[how-do-i-configure-signed-certificates]]
== 如何配置已签名的证书？

您可以从 System Manager 或外部使用私钥和公钥对生成签名请求。签名请求被发送到 CA 以生成证书文件。CA 返回证书文件后，您可以使用 System Manager 导入它们。

了解详情：

* link:use-ca-signed-certificates-for-controllers.html["对控制器使用 CA 签名的证书"]
* link:use-ca-signed-certificates-for-authentication-with-a-key-management-server.html["使用 CA 签名的证书对密钥管理服务器进行身份验证"]
