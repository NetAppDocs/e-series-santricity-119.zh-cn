= 在 SANtricity System Manager 中启用 iSCSI 发现设置
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以启用与 iSCSI 网络中存储设备发现相关的设置。

目标发现设置允许您使用 Internet Storage Name Service (iSNS) 协议注册存储阵列的 iSCSI 信息，并确定是否允许未命名的发现会话。

.开始之前
如果 iSNS 服务器使用静态 IP 地址，则该地址必须可用于 iSNS 注册。支持 IPv4 和 IPv6。

.关于此任务
您可以启用以下与 iSCSI 发现相关的设置：

* *启用 iSNS 服务器以注册目标* -- 启用后，存储阵列将其 iSCSI Qualified Name (IQN) 和端口信息注册到 iSNS 服务器。此设置允许 iSNS 发现，以便启动器可以从 iSNS 服务器检索 IQN 和端口信息。
* *启用未命名发现会话* -- 启用未命名发现会话后，发起方（iSCSI 主机）无需在登录序列期间为发现类型连接提供目标（控制器）的 IQN。禁用时，主机确实需要提供 IQN 以建立对控制器的发现会话。但是，正常（I/O 承载）会话始终需要目标 IQN。禁用此设置可以防止未经授权的 iSCSI 主机仅使用其 IP 地址连接到控制器。


[NOTE]
====
只有当您的存储阵列支持 iSCSI 时，iSCSI 设置和功能才会显示在"设置"页面上。

====
.步骤
. 选择菜单：Settings[System]。
. 在 *iSCSI 设置*下，单击*查看/编辑目标发现设置*。
+
此时将显示"目标发现设置"对话框。在 *Enable iSNS server*... 字段下方，该对话框指示控制器是否已经注册。

. 要注册控制器，请选择 *启用 iSNS 服务器以注册我的目标*，然后选择以下选项之一：
+
** *从 DHCP 服务器自动获取配置* -- 如果要使用动态主机配置协议 (DHCP) 服务器配置 iSNS 服务器，请选择此选项。请注意，如果使用此选项，则控制器上的所有 iSCSI 端口也必须配置为使用 DHCP。如有必要，请更新您的控制器 iSCSI 端口设置以启用此选项。
+
[NOTE]
====
要使 DHCP 服务器提供 iSNS 服务器地址，必须将 DHCP 服务器配置为使用选项 43 -- "`Vendor Specific Information.`" 此选项需要在数据字节 0xa-0xd (10-13) 中包含 iSNS 服务器 IPv4 地址。

====
** *手动指定静态配置* -- 如果要为 iSNS 服务器输入静态 IP 地址，请选择此选项。（如果需要，您可以将地址剪切并粘贴到字段中。）在字段中，输入 IPv4 地址或 IPv6 地址。如果两者都配置，则默认为 IPv4。同时输入 TCP 侦听端口（使用默认值 3205 或输入介于 49152 和 65535 之间的值）。


. 要允许存储阵列参与未命名的发现会话，请选择 *启用未命名的发现会话* 。
+
** 启用后，iSCSI 启动程序无需指定目标 IQN 即可检索控制器的信息。
** 禁用时，除非启动器提供目标 IQN，否则将阻止发现会话。禁用未命名的发现会话可提高安全性。


. 单击 *Save*。


.结果
当 System Manager 尝试向 iSNS 服务器注册控制器时，将出现一个进度条。此过程可能需要长达五分钟时间。
