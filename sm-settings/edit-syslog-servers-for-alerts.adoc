= 在 SANtricity System Manager 中编辑警报的系统日志服务器
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以编辑用于接收 syslog 警报的服务器地址。

.步骤
. 选择菜单：Settings[Alerts]。
. 选择 *Syslog* 选项卡。
. 从表中选择一个 syslog 服务器地址，然后单击最右侧的*编辑*（铅笔）图标。
+
该行成为可编辑字段。

. 编辑服务器地址和 UDP 端口号，然后单击 *Save*（复选标记）图标。


.结果
已更新的服务器地址将显示在表中。
