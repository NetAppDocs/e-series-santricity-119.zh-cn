= 在 SANtricity System Manager 中为警报配置系统日志服务器
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要配置 syslog 警报，您必须输入 syslog 服务器地址和 UDP 端口。最多允许五个 syslog 服务器。

.开始之前
* syslog 服务器地址必须可用。此地址可以是完全限定的域名、IPv4 地址或 IPv6 地址。
* syslog 服务器的 UDP 端口号必须可用。此端口通常为 514。


.关于此任务
此任务描述如何输入 syslog 服务器的地址和端口，然后测试您输入的地址。

.步骤
. 选择菜单：Settings[Alerts]。
. 选择 *Syslog* 选项卡。
+
如果尚未定义 syslog 服务器，警报页面将显示"添加 Syslog 服务器"。

. 单击 *Add Syslog Servers*。
+
此时将打开添加 Syslog 服务器对话框。

. 输入一个或多个 syslog 服务器的信息（最多五个），然后单击*添加*。
+
** *服务器地址* -- 输入完全限定域名、IPv4 地址或 IPv6 地址。
** *UDP Port* -- 通常，syslog 的 UDP 端口为 514。该表显示了已配置的 syslog 服务器。


. 要向服务器地址发送测试警报，请选择 *Test All Syslog Servers*。


.结果
每当发生可警报事件时，事件监视器都会向 syslog 服务器发送警报。要进一步配置审核日志的 syslog 设置，请参见 https://docs.netapp.com/us-en/e-series-santricity/sm-settings/configure-syslog-server-for-audit-logs.html["为审核日志配置 syslog 服务器"]。


NOTE: 如果配置了多个 syslog 服务器，则所有配置的 syslog 服务器都将收到审核日志。
