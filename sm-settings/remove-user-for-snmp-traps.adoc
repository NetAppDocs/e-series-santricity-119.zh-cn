= 在 SANtricity System Manager 中删除 SNMPv3 陷阱的用户
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以删除 SNMPv3 陷阱的用户。

.步骤
. 选择菜单：Settings[Alerts]。
. 选择 *SNMP* 选项卡。
+
陷阱目标和用户名显示在"警报"页面上。

. 选择 *Configure Users*。
+
此时将打开配置 SNMPv3 用户对话框。

. 选择要删除的用户名，然后单击 *Delete*。
. 确认操作，然后单击 *Delete*。


.结果
用户名及其关联的陷阱目标将从"警报"页面中删除。
