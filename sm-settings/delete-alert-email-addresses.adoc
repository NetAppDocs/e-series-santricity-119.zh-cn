= 删除 SANtricity System Manager 中用于警报的邮件服务器或电子邮件地址
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以删除先前定义的邮件服务器，以便不再将警报发送到电子邮件地址，也可以删除单个电子邮件地址。

.步骤
. 选择菜单：Settings[Alerts]。
. 选择 *Email* 选项卡。
. 从表中，执行以下操作之一：
+
** 要删除邮件服务器，以便不再将警报发送到电子邮件地址，请选择邮件服务器所在的行。
** 要删除电子邮件地址，以便不再将警报发送到此地址，请选择要删除的电子邮件地址的行。表格右上角的 *Delete* 按钮可供选择。


. 点击 *Delete*，并确认操作。
