= 在 SANtricity System Manager 中为 SNMPv2c 陷阱添加社区
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您最多可以为 SNMPv2c 陷阱添加 256 个社区名称。

.步骤
. 选择菜单：Settings[Alerts]。
. 选择 *SNMP* 选项卡。
+
陷阱目标和社区名称显示在表中。

. 选择 *Configure Communities* 。
+
此时将打开"配置社区"对话框。

. 选择 *Add another community* 。
. 输入新的社区名称，然后单击 *Save*。


.结果
新的社区名称将显示在警报页面的 SNMP 选项卡中。
