= 在 SANtricity System Manager 中使用本地用户角色配置访问管理
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
对于访问管理，管理员可以使用在存储阵列中实施的 RBAC（基于角色的访问控制）功能。这些功能称为"本地用户角色"。



[[configuration-workflow]]
== 配置工作流

已为存储阵列预配置本地用户角色。要使用本地用户角色进行身份验证，管理员可以执行以下操作：

. 管理员使用包含安全管理员权限的用户配置文件登录到 System Manager。
+
[NOTE]
====
 `admin` 用户可以完全访问系统中的所有功能。

====
. 管理员审阅用户配置文件，这些配置文件是预定义的，无法修改。
. 可选地，管理员为每个用户配置文件分配新密码。
. 用户使用其分配的凭据登录到系统。




[[management]]
== 管理

当仅使用本地用户角色进行身份验证时，管理员可以执行以下管理任务：

* 更改密码。
* 设置密码的最小长度。
* 允许用户无需密码即可登录。
