= 在 SANtricity System Manager 中更改存储阵列缓存设置
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
对于存储阵列中的所有卷，您可以调整刷新和块大小的缓存内存设置。

.关于此任务
缓存内存是控制器上的临时易失性存储区域，具有比驱动器介质更快的访问时间。要调整缓存性能，您可以调整以下设置：

[cols="25h,~"]
|===
| 缓存设置 | 说明 


 a| 
启动按需缓存刷新
 a| 
启动需求缓存刷新指定缓存中触发缓存刷新（写入磁盘）的未写入数据的百分比。默认情况下，当未写入数据达到 80% 容量时，缓存刷新开始。对于主要进行写入操作的环境，较高的百分比是一个不错的选择，因此可以通过缓存处理新的写入请求，而无需访问磁盘。在 I/O 不稳定（具有数据突发）的环境中，较低的设置更好，因此系统会在数据突发之间频繁刷新缓存。但是，低于 80% 的启动百分比可能会导致性能下降。



 a| 
缓存块大小
 a| 
缓存块大小确定每个缓存块的最大大小，这是缓存管理的组织单位。默认情况下，块大小为 32 KiB。系统允许缓存块大小为 4、8、16 或 32 KiBs。应用程序使用不同的块大小，这会影响存储性能。对于文件系统或数据库应用程序，较小的大小是一个不错的选择。较大的尺寸非常适合生成顺序 I/O 的应用程序，例如多媒体。

|===
.步骤
. 选择菜单：Settings[System]。
. 向下滚动到 *Additional Settings*，然后单击 *Change Cache Settings*。
+
此时将打开更改缓存设置对话框。

. 调整以下值：
+
** *启动需求缓存刷新* -- 选择适合环境中使用的 I/O 的百分比。如果选择低于 80% 的值，您可能会注意到性能下降。
** **缓存块大小 -- **选择适合您的应用程序的大小。


. 单击 *Save*。
