= 在 SANtricity System Manager 中配置基于 RoCE 的 NVMe 端口
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您的控制器包含 NVMe over RoCE（RDMA over Converged Ethernet）的连接，则可以从"系统"页面配置 NVMe 端口设置。

.开始之前
* 控制器必须包含基于 RoCE 的 NVMe 主机端口；否则，System Manager 中无法使用基于 RoCE 的 NVMe 设置。
* 您必须知道主机连接的 IP 地址。


.步骤
. 选择菜单：Settings[System]。
. 在 *NVMe over ROCE settings* 下，选择 *Configure NVMe over ROCE ports*。
. 选择具有要配置的 NVMe over RoCE 端口的控制器。单击 *Next*。
. 从下拉列表中选择要配置的 HIC 端口。单击*下一步*。
. 配置端口设置。
+
要查看所有端口设置，请单击对话框右侧的 *Show more port settings* 链接。

+
.字段详细信息
[%collapsible]
====
[cols="1a,1a"]
|===
| 端口设置 | 说明 


 a| 
配置的以太网端口速度
 a| 
选择与端口上 SFP 的速度能力相匹配的速度。



 a| 
启用 IPv4 / 启用 IPv6
 a| 
选择一个或两个选项以启用对 IPv4 和 IPv6 网络的支持。


NOTE: 如果要禁用端口访问，请取消选中两个复选框。



 a| 
MTU 大小（可通过单击*显示更多端口设置*获得。）
 a| 
如有必要，请输入最大传输单元 (MTU) 的新大小（以字节为单位）。

默认最大传输单元 (MTU) 大小为每帧 1500 字节。必须输入介于 1500 和 9000 之间的值。

|===
====
+
如果您选择了*启用 IPv4*，点击*下一步*后将打开一个对话框，用于选择 IPv4 设置。如果您选择了*启用 IPv6*，点击*下一步*后将打开一个对话框，用于选择 IPv6 设置。如果您选择了这两个选项，则首先打开 IPv4 设置的对话框，然后单击*下一步*后，将打开 IPv6 设置的对话框。

. 自动或手动配置 IPv4 和/或 IPv6 设置。
+
.字段详细信息
[%collapsible]
====
[cols="1a,1a"]
|===
| 端口设置 | 说明 


 a| 
自动获取配置
 a| 
选择此选项可自动获取配置。



 a| 
手动指定静态配置
 a| 
选择此选项，然后在字段中输入静态地址。（如果需要，您可以将地址剪切并粘贴到字段中。）对于 IPv4，包括网络子网掩码和网关。对于 IPv6，包括可路由 IP 地址和路由器 IP 地址。如果要使用支持 200Gb 的 HIC 配置 EF600 存储阵列，则此对话框将显示两组网络参数字段，一组用于物理端口（外部），另一组用于虚拟端口（内部）。您应该为两个端口分配唯一参数。这些设置允许主机在每个端口之间建立路径，并使 HIC 实现最大性能。如果不为虚拟端口分配 IP 地址，HIC 将以大约一半的速度运行。

|===
====
. 单击 *Finish*。
