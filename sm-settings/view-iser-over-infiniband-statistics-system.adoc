= 在 SANtricity System Manager 中查看基于 InfiniBand 的 iSER 统计信息
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果存储阵列的控制器包含 iSER over InfiniBand 端口，则可以查看有关主机连接的数据。

.关于此任务
System Manager 显示以下类型的 iSER over InfiniBand 统计信息。所有统计信息都是只读的，无法设置。

* *本地目标（协议）统计信息* -- 提供 iSER over InfiniBand 目标的统计信息，显示对其存储介质的块级访问。
* *iSER over InfiniBand Interface statistics* -- 提供 InfiniBand 接口上所有 iSER 端口的统计信息，其中包括与每个交换机端口关联的性能统计信息和链路错误信息。


您可以将这些统计数据中的每一个查看为原始统计数据或基线统计数据。原始统计数据是自控制器启动以来收集的所有统计数据。基线统计数据是自您设置基线时间以来收集的时间点统计数据。

.步骤
. 选择菜单：Settings[System]。
. 选择 *View iSER over InfiniBand Statistics*。
. 单击选项卡可查看不同的统计信息集。
. *可选：*要设置基线，请单击*设置新基线*。
+
设置基线为统计数据的收集设置了一个新的起点。相同的基线用于所有 iSER over InfiniBand 统计。
