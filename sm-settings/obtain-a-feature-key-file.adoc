= 在 SANtricity System Manager 中获取功能密钥文件
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要在存储阵列上启用高级功能或功能包，必须首先获取功能密钥文件。一个密钥仅与一个存储阵列相关联。

.关于此任务
此任务介绍如何收集功能所需的信息，然后发送功能密钥文件请求。必填信息包括：

* 机箱序列号
* 功能启用标识符
* 功能激活码


.步骤
. 在 System Manager 中，找到并记录机箱序列号。您可以将鼠标悬停在 Support Center 图块上来查看此序列号。
. 在 System Manager 中，找到功能启用标识符。转到菜单：Settings[System]，然后向下滚动到*附加组件*。寻找*功能启用标识符*。记录功能启用标识符的编号。
. 找到并记录用于功能激活的代码。对于功能包，此代码在执行转换的相应说明中提供。
+
对于高级功能，您可以从 Support 站点访问激活码，如下所示：

+
.. 登录到  https://mysupport.netapp.com/site/global/dashboard["NetApp 支持"^]。
.. 转至产品的 *Software Licenses*。
.. 输入存储阵列机箱的序列号，然后单击 *Go*。
.. 在*许可证密钥*列中查找功能激活码。
.. 记录所需功能的功能激活码。


. 通过向您的存储供应商发送包含以下信息的电子邮件或文本文档来请求功能密钥文件：机箱序列号、启用标识符和功能激活代码。
+
您还可以转到 http://partnerspfk.netapp.com["NetApp 许可证激活：存储阵列高级功能激活"^]并输入所需的信息，以获取功能或功能包。（本网站上的说明适用于高级功能，而不是功能包。）



.完成后
当您有功能密钥文件时，您可以启用高级功能或功能包。
