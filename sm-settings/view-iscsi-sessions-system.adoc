= 在 SANtricity System Manager 中查看 iSCSI 会话
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以查看有关到存储阵列的 iSCSI 连接的详细信息。iSCSI 会话可以与异步镜像关系中的主机或远程存储阵列一起进行。

.步骤
. 选择菜单：Settings[System]。
. 选择 *View/End iSCSI Sessions*。
+
此时将显示当前 iSCSI 会话的列表。

. *可选：* 要查看有关特定 iSCSI 会话的其他信息，请选择一个会话，然后单击 *查看详细信息*。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 项目 | 说明 


 a| 
会话标识符 (SSID)
 a| 
标识 iSCSI 启动程序和 iSCSI 目标之间会话的十六进制字符串。SSID 由 ISID 和 TPGT 组成。



 a| 
启动程序 Session ID (ISID)
 a| 
会话标识符的启动程序部分。启动程序在登录期间指定 ISID。



 a| 
目标门户组
 a| 
iSCSI 目标。



 a| 
目标门户组标记 (TPGT)
 a| 
会话标识符的目标部分。iSCSI 目标门户组的 16 位数字标识符。



 a| 
启动程序 iSCSI 名称
 a| 
启动器的全球唯一名称。



 a| 
启动程序 iSCSI 标签
 a| 
在 System Manager 中设置的用户标签。



 a| 
启动程序 iSCSI 别名
 a| 
也可以与 iSCSI 节点关联的名称。该别名允许组织将用户友好的字符串与 iSCSI 名称关联。但是，别名不能替代 iSCSI 名称。iSCSI 启动程序别名只能在主机上设置，不能在 System Manager 中设置



 a| 
主机
 a| 
向存储阵列发送输入和输出的服务器。



 a| 
连接 ID (CID)
 a| 
启动程序和目标之间的会话内连接的唯一名称。启动程序生成此 ID 并在登录请求期间将其提供给目标。在关闭连接的注销过程中也会提供连接 ID。



 a| 
端口标识符
 a| 
与连接关联的控制器端口。



 a| 
启动程序 IP 地址
 a| 
启动程序的 IP 地址。



 a| 
协商登录参数
 a| 
在 iSCSI 会话登录期间处理的参数。



 a| 
身份验证方法
 a| 
对希望访问 iSCSI 网络的用户进行身份验证的技术。有效值为 *CHAP* 和 *None*。



 a| 
标头摘要方法
 a| 
显示 iSCSI 会话可能的报头值的技术。HeaderDigest 和 DataDigest 可以是 *None* 或 *CRC32C*。两者的默认值均为 *None*。



 a| 
数据摘要方法
 a| 
显示 iSCSI 会话的可能数据值的技术。HeaderDigest 和 DataDigest 可以是 *None* 或 *CRC32C*。两者的默认值均为 *None*。



 a| 
最大连接数
 a| 
iSCSI 会话允许的最大连接数。最大连接数可以是 1 到 4。默认值为 *1*。



 a| 
目标别名
 a| 
与目标关联的标签。



 a| 
启动程序别名
 a| 
与启动程序关联的标签。



 a| 
目标 IP 地址
 a| 
iSCSI 会话目标的 IP 地址。不支持 DNS 名称。



 a| 
初始 R2T
 a| 
初始传输准备就绪状态。状态可以是 *是* 或 *否*。



 a| 
最大突发长度
 a| 
此 iSCSI 会话的最大 SCSI 负载（以字节为单位）。最大突发长度可以为 512 到 262,144 (256 KB)。默认值为 *262,144 (256 KB)*。



 a| 
首个突发长度
 a| 
此 iSCSI 会话未经请求的数据的 SCSI 负载（以字节为单位）。第一个突发长度可以是 512 到 131,072 (128 KB)。默认值为 *65,536 (64 KB)*。



 a| 
默认等待时间
 a| 
在连接终止或连接重置后，尝试建立连接之前等待的最小秒数。默认等待时间值可以是 0 到 3600。默认值为 *2*。



 a| 
默认保留时间
 a| 
在连接终止或连接重置后，仍然可以进行连接的最大秒数。默认保留时间为 0 至 3600。默认值为 *20*。



 a| 
最大未结 R2T
 a| 
此 iSCSI 会话的"准备好传输"未完成的最大数量。最大未完成准备传输值可以为 1 到 16。默认值为 *1*。



 a| 
错误恢复级别
 a| 
此 iSCSI 会话的错误恢复级别。错误恢复级别值始终设置为 *0*。



 a| 
最大接收数据段长度
 a| 
启动程序或目标可以在任何 iSCSI 有效负载数据单元 (PDU) 中接收的最大数据量。



 a| 
目标名称
 a| 
目标的正式名称（而不是别名）。具有 _iqn_ 格式的目标名称。



 a| 
启动程序名称
 a| 
启动程序的正式名称（不是别名）。使用 _iqn_ 或 _eui_ 格式的启动程序名称。

|===
