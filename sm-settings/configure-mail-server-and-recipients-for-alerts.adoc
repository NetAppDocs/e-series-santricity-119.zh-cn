= 在 SANtricity System Manager 中配置邮件服务器和警报收件人
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要配置电子邮件警报，必须指定邮件服务器地址和警报收件人的电子邮件地址。最多允许 20 个电子邮件地址。

.开始之前
* 邮件服务器的地址必须可用。地址可以是 IPv4 或 IPv6 地址，也可以是完全限定域名。
+
[NOTE]
====
要使用完全限定的域名，必须在两个控制器上配置 DNS 服务器。您可以从硬件页面配置 DNS 服务器。

====
* 要用作警报发件人的电子邮件地址必须可用。这是警报消息"发件人"字段中显示的地址。SMTP 协议中需要发件人地址；如果没有它，将导致错误。
* 警报收件人的电子邮件地址必须可用。收件人通常是网络管理员或存储管理员的地址。您最多可以输入 20 个电子邮件地址。


.关于此任务
此任务介绍如何配置邮件服务器、输入发件人和收件人的电子邮件地址，以及测试从 Alerts 页面输入的所有电子邮件地址。

[NOTE]
====
电子邮件警报也可以通过 Initial Setup 向导进行配置。

====
.步骤
. 选择菜单：Settings[Alerts]。
. 选择 *Email* 选项卡。
+
如果尚未配置电子邮件服务器，Email 选项卡将显示"Configure Mail Server"。

. 选择 *Configure Mail Server*。
+
此时将打开 Configure Mail Server 对话框。

. 输入邮件服务器信息，然后单击 *保存*。
+
** *邮件服务器地址* -- 输入邮件服务器的完全限定域名、IPv4 地址或 IPv6 地址。
+
[NOTE]
====
要使用完全限定的域名，必须在两个控制器上配置 DNS 服务器。您可以从硬件页面配置 DNS 服务器。

====
** *电子邮件发件人地址* -- 请输入要用作电子邮件发件人的有效电子邮件地址。此地址将显示在电子邮件的"发件人"字段中。
** *加密* -- 如果要加密邮件，请选择 *SMTPS* 或 *STARTTLS* 作为加密类型，然后选择加密邮件的端口号。否则，请选择 *None*。
** *用户名和密码* -- 如果需要，请输入用户名和密码，以便与发件人和邮件服务器进行身份验证。
** *在电子邮件中包含联系信息* -- 要将发件人的联系信息包含在警报消息中，请选择此选项，然后输入姓名和电话号码。
+
点击 *保存* 后，电子邮件地址将显示在"提醒"页面的"电子邮件"选项卡中。



. 选择 *Add Emails*。
+
此时将打开添加电子邮件对话框。

. 输入警报收件人的一个或多个电子邮件地址，然后单击 *Add*。
+
电子邮件地址将显示在"提醒"页面上。

. 如果要确保电子邮件地址有效，请单击 *Test All Emails* 以向收件人发送测试消息。


.结果
配置电子邮件警报后，每当发生可警报事件时，事件监视器都会向指定的收件人发送电子邮件。
