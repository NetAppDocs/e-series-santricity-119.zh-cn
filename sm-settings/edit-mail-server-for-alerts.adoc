= 在 SANtricity System Manager 中编辑警报的邮件服务器
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以更改用于电子邮件警报的邮件服务器地址和电子邮件发件人地址。

.开始之前
您要更改的邮件服务器的地址必须可用。地址可以是 IPv4 或 IPv6 地址，也可以是完全限定域名。

[NOTE]
====
要使用完全限定的域名，必须在两个控制器上配置 DNS 服务器。您可以从硬件页面配置 DNS 服务器。

====
.步骤
. 选择菜单：Settings[Alerts]。
. 选择 *Email* 选项卡。
. 选择 *Configure Mail Server*。
+
此时将打开 Configure Mail Server 对话框。

. 编辑邮件服务器地址、发件人信息和联系信息。
+
** *邮件服务器地址* -- 编辑邮件服务器的完全限定域名、IPv4 地址或 IPv6 地址。
+
[NOTE]
====
要使用完全限定的域名，必须在两个控制器上配置 DNS 服务器。您可以从硬件页面配置 DNS 服务器。

====
** *电子邮件发件人地址* -- 编辑要用作电子邮件发件人的电子邮件地址。此地址将显示在电子邮件的"发件人"字段中。
** *在电子邮件中包含联系信息* -- 要编辑发件人的联系信息，请选择此选项，然后编辑姓名和电话号码。


. 单击 *Save*。
