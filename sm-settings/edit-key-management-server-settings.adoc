= 在 SANtricity System Manager 中编辑密钥管理服务器设置
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果配置了外部密钥管理，则可以随时查看和编辑密钥管理服务器设置。

.步骤
. 选择菜单：Settings[System]。
. 在 *Security key management* 下，选择 *View/Edit Key Management Server Settings*。
. 在以下字段中编辑信息：
+
** *密钥管理服务器地址* -- 输入用于密钥管理的服务器的完全限定域名或 IP 地址（IPv4 或 IPv6）。
** *密钥管理端口号* -- 输入用于密钥管理互操作性协议 (KMIP) 通信的端口号。
+
*可选：* 您可以通过单击 *添加密钥服务器* 添加另一个密钥服务器。



. 单击 *Save*。
