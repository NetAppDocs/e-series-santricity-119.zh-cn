= 在 SANtricity System Manager 中更改安全密钥
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以随时用新密钥替换安全密钥。如果您的公司存在潜在的安全漏洞，并且希望确保未经授权的人员无法访问驱动器数据，则可能需要更改安全密钥。

.步骤
. 选择菜单：Settings[System]。
. 在 *Security key management* 下，选择 *Change Key*。
+
此时将打开更改安全密钥对话框。

. 在以下字段中输入信息。
+
** *定义安全密钥标识符* -- （仅适用于内部安全密钥。）接受默认值（存储阵列名称和时间戳，由控制器固件生成）或输入您自己的值。您最多可以输入 189 个字母数字字符，无需空格、标点符号或符号。
+
[NOTE]
====
其他字符将自动生成，并附加到您输入的字符串的两端。生成的字符有助于确保标识符是唯一的。

====
** *Define a pass phrase/Re-enter pass phrase* -- 在这些字段中，输入您的通行短语。该值可以包含 8 到 32 个字符，并且必须包含以下每个字符：
+
*** 大写字母（一个或多个）。请注意，密码短语区分大小写。
*** 一个数字（一个或多个）。
*** 非字母数字字符，例如 !、*、@（一个或多个）。




. 对于外部安全密钥，如果要在创建新安全密钥时删除旧安全密钥，请选中对话框底部的"Delete current security key..."复选框。
+
[CAUTION]
====
*请务必记录您的条目以供以后使用* -- 如果您需要从存储阵列中移动启用安全的驱动器，则必须知道标识符和密码短语才能解锁驱动器数据。

====
. 单击 *Change*。
+
新的安全密钥将覆盖上一个不再有效的密钥。

+
[NOTE]
====
下载文件的路径可能取决于浏览器的默认下载位置。

====
. 记录您的密钥标识符、密码以及下载的密钥文件的位置，然后单击 *Close*。


.完成后
您应该验证安全密钥，以确保密钥文件未损坏。
