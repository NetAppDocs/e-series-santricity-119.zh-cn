= 在 SANtricity System Manager 中查看本地用户角色
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
从本地用户角色选项卡，您可以查看用户配置文件到默认角色的映射。这些映射是在存储阵列中实施的 RBAC（基于角色的访问控制）的一部分。

.开始之前
必须使用包含 Security admin 权限的用户配置文件登录。否则，将不会显示 Access Management 功能。

.关于此任务
无法更改用户配置文件和映射。只能修改密码。

.步骤
. 选择菜单：Settings[Access Management]。
. 选择 *Local User Roles* 选项卡。
+
用户配置文件显示在表中：

+
** *Root admin* (admin) -- 有权访问系统中所有功能的超级管理员。此用户配置文件包括所有角色。
** *Storage admin* （存储） -- 负责所有存储配置的管理员。此用户配置文件包括以下角色：Storage Admin、Support Admin 和 Monitor。
** *Security admin* （安全） -- 负责安全配置的用户，包括访问管理、证书管理和启用安全的驱动器功能。此用户配置文件包括以下角色：Security Admin 和 Monitor。
** *Support admin*（support）-- 负责硬件资源、故障数据和固件升级的用户。此用户配置文件包括以下角色：Support Admin 和 Monitor。
** *Monitor*（monitor）-- 对系统具有只读访问权限的用户。此用户配置文件仅包括 Monitor 角色。
