== 将导入哪些设置？

导入设置功能是一种批处理操作，可将配置从一个存储阵列加载到多个存储阵列。在此操作期间导入的设置取决于如何在 SANtricity System Manager 中配置源存储阵列。

可以将以下设置导入到多个存储阵列：

* *电子邮件警报* -- 设置包括邮件服务器地址和警报收件人的电子邮件地址。
* *Syslog 警报* -- 设置包括 syslog 服务器地址和 UDP 端口。
* *SNMP 警报* -- 设置包括 SNMP 服务器的社区名称和 IP 地址。
* *AutoSupport* -- 设置包括单独的功能（基本 AutoSupport、AutoSupport OnDemand 和远程诊断）、维护时段、交付方法和派遣计划。
* *目录服务* -- 配置包括 LDAP（轻型目录访问协议）服务器的域名和 URL，以及 LDAP 服务器的用户组到存储阵列预定义角色的映射。
* *存储配置* -- 配置包括卷（仅限厚卷和非存储库卷）、卷组、池和热备盘驱动器分配。
* *系统设置* -- 配置包括卷的媒体扫描设置、控制器的 SSD 缓存和自动负载平衡（不包括主机连接报告）。




== 为什么我没有看到所有的存储阵列？

在导入设置操作期间，某些存储阵列可能在目标选择对话框中不可用。

由于以下原因，可能无法显示存储阵列：

* 固件版本低于 8.50。
* 此存储阵列已脱机。
* 系统无法与该阵列通信（例如，阵列存在证书、密码或网络问题）。
