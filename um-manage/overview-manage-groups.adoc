= 了解 SANtricity Unified Manager 中的组概述
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
从"管理组"页面，您可以创建一组存储阵列组，以便于管理。



== 什么是数组组？

您可以通过对一组存储阵列进行分组来管理物理和虚拟化基础架构。您可能需要对存储阵列进行分组，以便更轻松地运行监控或报告作业。

有两种类型的组：

* *All group* -- All group 是默认组，包括组织中发现的所有存储阵列。可以从主视图访问 All group。
* *用户创建的组* -- 用户创建的组包括您手动选择添加到该组的存储阵列。可以从主视图访问用户创建的组。




== 如何配置组？

从"管理组"页面，您可以创建组，然后将数组添加到该组。
