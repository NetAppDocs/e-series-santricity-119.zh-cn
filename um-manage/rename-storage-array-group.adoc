= 在 SANtricity Unified Manager 中重命名存储阵列组
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当当前名称不再有意义或适用时，您可以更改存储阵列组的名称。

.关于此任务
请牢记这些准则。

* 一个名称可以由字母、数字和特殊字符下划线(_)、连字符(-)和井号(#)组成。如果选择任何其他字符，则会显示错误消息。系统会提示您选择其他名称。
* 将名称限制为 30 个字符。删除名称中的任何前导空格和尾随空格。
* 使用易于理解和记忆的独特、有意义的名称。
* 避免使用任意名称或将来会很快失去意义的名称。


.步骤
. 在主视图中，选择 *管理*，然后选择要重命名的存储阵列组。
. 选择菜单：Manage Groups[Rename storage array group]。
. 在 *Group Name* 字段中，为组键入一个新名称。
. 单击 *重命名* 。
