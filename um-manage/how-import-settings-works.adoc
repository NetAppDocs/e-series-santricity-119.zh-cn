= 了解如何在 SANtricity Unified Manager 中配置多个存储阵列
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以使用 SANtricity Unified Manager 将设置从一个存储阵列导入到多个存储阵列。导入设置功能是一种批处理操作，可在需要在网络中配置多个阵列时节省时间。



[[settings-available-for-import]]
== 可用于导入的设置

可以将以下配置导入到多个数组：

* *警报* -- 使用电子邮件、syslog 服务器或 SNMP 服务器向管理员发送重要事件的警报方法。
* *AutoSupport* -- 一种监控存储阵列运行状况并将自动派遣发送给技术支持的功能。
* *目录服务* -- 通过 LDAP（轻型目录访问协议）服务器和目录服务（例如 Microsoft 的 Active Directory）管理的用户身份验证方法。
* *存储配置* -- 与以下内容相关的配置：
+
** 卷（仅限厚卷和非存储库卷）
** 卷组和池
** 热备用驱动器分配


* *系统设置* -- 与以下内容相关的配置：
+
** 卷的媒体扫描设置
** SSD 设置
** 自动负载平衡（不包括主机连接报告）






[[configuration-workflow]]
== 配置工作流

要导入设置，请按照以下工作流程操作：

. 在要用作源的存储阵列上，使用 System Manager 配置设置。
. 在要用作目标的存储阵列上，使用 System Manager 备份其配置。
. 在 Unified Manager 中，转到 *Manage* 页面并导入设置。
. 从 *Operations* 页面，查看 Import Settings 操作的结果。
