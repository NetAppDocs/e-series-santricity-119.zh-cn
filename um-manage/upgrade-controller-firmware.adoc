= 升级 SANtricity 操作系统
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
使用最新软件和 NVSRAM 升级一个或多个存储阵列，以确保您拥有所有最新功能和错误修复。控制器 NVSRAM 是一个控制器文件，用于指定控制器的默认设置。

.开始之前
* 运行 SANtricity Web Services Proxy 和 Unified Manager 的主机系统上提供了最新的 SANtricity 操作系统文件。
* 您知道是要现在激活软件升级还是以后激活。
+
您可以选择稍后激活，原因如下：

+
** *时间* -- 激活软件可能需要很长时间，因此您可能需要等待 I/O 负载较轻。控制器在激活期间发生故障转移，因此在升级完成之前，性能可能会低于正常水平。
** *软件包类型* -- 在升级其他存储阵列上的文件之前，您可能需要在一个存储阵列上测试新的 OS 软件。





IMPORTANT: 系统必须运行 SANtricity 操作系统 11.70.5 才能升级到 11.80.x 或更高版本。

.关于此任务
++ ++

[NOTE]
====
数据丢失或存储阵列损坏的风险 - 升级过程中请勿对存储阵列进行更改。保持存储阵列的电源。

====
.步骤
. 如果您的存储阵列仅包含一个控制器或未使用多路径驱动程序，请停止对存储阵列的 I/O 活动，以防止出现应用程序错误。如果您的存储阵列有两个控制器，并且您安装了多路径驱动程序，则无需停止 I/O 活动。
. 在主视图中，选择 *Manage*，然后选择要升级的一个或多个存储阵列。
. 选择菜单：Upgrade Center[Upgrade SANtricity OS Software]。
+
此时将显示升级 SANtricity 操作系统软件页面。

. 从 NetApp 支持站点将最新的 SANtricity 操作系统软件包下载到本地计算机。
+
.. 单击 *Add new file to software repository*。
.. 单击链接以查找最新的 *SANtricity OS Downloads*。
.. 单击 *Download Latest Release* 链接。
.. 按照其余说明将 SANtricity 操作系统文件和 NVSRAM 文件下载到本地计算机。


+
[NOTE]
====
8.42 及更高版本需要数字签名固件。如果您尝试下载未签名的固件，则会显示错误并中止下载。

====
. 选择要用于升级控制器的 OS 软件文件和 NVSRAM 文件：
+
.. 从 *Select a SANtricity OS software file* 下拉菜单中，选择您下载到本地计算机的 OS 文件。
+
如果有多个可用文件，这些文件将从最新日期到最早日期进行排序。

+
[NOTE]
====
软件存储库列出与 Web Services Proxy 关联的所有软件文件。如果未看到要使用的文件，则可以单击链接*将新文件添加到软件存储库*，以浏览到要添加的 OS 文件所在的位置。

====
.. 从 *Select an NVSRAM file* 下拉列表中，选择要使用的控制器文件。
+
如果存在多个文件，文件将从最新日期到最旧日期进行排序。



. 在"兼容存储阵列"表中，查看与所选 OS 软件文件兼容的存储阵列，然后选择要升级的阵列。
+
** 在"管理"视图中选定且与选定固件文件兼容的存储阵列默认选定在"兼容存储阵列"表中。
** 无法使用所选固件文件更新的存储阵列在兼容存储阵列表中不可选择，如状态 *不兼容* 所示。


. *可选：* 要将软件文件传输到存储阵列而不激活它们，请选择 *将 OS 软件传输到存储阵列，将其标记为暂存，并在稍后激活* 复选框。
. 单击 *Start*。
. 根据您是选择立即激活还是稍后激活，执行以下操作之一：
+
** 键入 *TRANSFER* 以确认要在您选择升级的阵列上传输建议的操作系统软件版本，然后单击 *Transfer*。
+
要激活传输的软件，请选择菜单：Upgrade Center[Activate Staged OS Software]。

** 键入 *UPGRADE* 以确认要在您选择升级的阵列上传输并激活建议的操作系统软件版本，然后单击 *Upgrade*。
+
系统将软件文件传输到您选择升级的每个存储阵列，然后通过启动重新启动来激活该文件。



+
升级操作期间发生以下操作：

+
** 升级前运行状况检查作为升级过程的一部分运行。升级前运行状况检查会评估所有存储阵列组件，以确保升级可以继续。
** 如果存储阵列的任何运行状况检查失败，则升级将停止。您可以单击省略号 (...) 并选择 *Save Log* 以查看错误。您也可以选择覆盖运行状况检查错误，然后单击 *Continue* 以继续升级。
** 您可以在升级前运行状况检查后取消升级操作。


. *可选：*升级完成后，您可以通过单击省略号 (...) ，然后选择*保存日志*，查看针对特定存储阵列升级的内容列表。
+
此文件将以此名称保存在浏览器的 Downloads 文件夹中 `upgrade_log-<date>.json`。
