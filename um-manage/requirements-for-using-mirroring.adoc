= 在 SANtricity Unified Manager 中使用镜像的要求
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您计划配置镜像，请记住以下要求。



[[unified-manager]]
== Unified Manager

* Web Services Proxy 服务必须正在运行。
* Unified Manager 必须通过 HTTPS 连接在本地主机上运行。
* Unified Manager 必须显示存储阵列的有效 SSL 证书。您可以使用 Unified Manager 接受自签名证书或安装您自己的安全证书，并导航到菜单：Certificate[Certificate Management]。




[[storage-arrays]]
== 存储阵列

[NOTE]
====
EF600/EF600C 或 EF300/EF300C 存储阵列上不提供同步镜像。

====
* 您必须有两个存储阵列。
* 每个存储阵列必须有两个控制器。
* 必须在 Unified Manager 中发现两个存储阵列。
* 主阵列和辅助阵列中的每个控制器都必须配置以太网管理端口，并且必须连接到您的网络。
* 存储阵列的最低固件版本为 7.84。（它们可以各自运行不同的 OS 版本。）
* 您必须知道本地和远程存储阵列的密码。
* 必须在远程存储阵列上具有足够的可用容量，才能创建等于或大于要镜像的主卷的辅助卷。
* 异步镜像在具有 Fibre Channel (FC) 或 iSCSI 主机端口的控制器上受支持，而同步镜像仅在具有 FC 主机端口的控制器上受支持。




[[connectivity-requirements]]
== 连接要求

通过 FC 接口（异步或同步）进行镜像需要满足以下要求：

* 存储阵列的每个控制器都将其编号最高的 FC 主机端口专用于镜像操作。
* 如果控制器同时具有基本 FC 端口和主机接口卡 (HIC) FC 端口，则编号最高的端口在 HIC 上。登录到专用端口的任何主机都已注销，并且不接受任何主机登录请求。此端口上的 I/O 请求仅接受来自参与镜像操作的控制器。
* 专用镜像端口必须连接到支持目录服务和名称服务接口的 FC 结构环境。特别是，不支持 FC-AL 和点对点作为参与镜像关系的控制器之间的连接选项。


通过 iSCSI 接口（仅限异步）进行镜像需要满足以下要求：

* 与 FC 不同，iSCSI 不需要专用端口。在 iSCSI 环境中使用异步镜像时，不必将存储阵列的任何前端 iSCSI 端口专用于异步镜像；这些端口为异步镜像流量和主机到阵列 I/O 连接共享。
* 控制器维护 iSCSI 启动程序尝试与之建立会话的远程存储系统列表。成功建立 iSCSI 连接的第一个端口用于与该远程存储阵列的所有后续通信。如果通信失败，将尝试使用所有可用端口进行新会话。
+

NOTE: E4000 控制器不支持 iSCSI 镜像。

* iSCSI 端口是逐个端口在阵列级别配置的。用于配置消息传递和数据传输的控制器间通信使用全局设置，包括以下设置：
+
** VLAN：本地和远程系统必须具有相同的 VLAN 设置才能进行通信
** iSCSI 侦听端口
** 巨型帧
** 以太网优先级




[NOTE]
====
iSCSI 控制器间通信必须使用主机连接端口，而不是管理以太网端口。

====


[[mirrored-volume-candidates]]
== 镜像卷候选项

* 在镜像对的主卷和辅助卷上，RAID 级别、缓存参数和段大小可以不同。
+

NOTE: 对于 EF600 和 EF300 控制器，异步镜像对的主卷和辅助卷必须匹配相同的协议、托盘级别、段大小、安全类型和 RAID 级别。不符合条件的异步镜像对将不会出现在可用卷列表中。

* 辅助卷必须至少与主卷一样大。
* 一个卷只能参与一个镜像关系。
* 对于同步镜像对，主卷和辅助卷必须是标准卷。它们不能是精简卷或快照卷。
* 对于同步镜像，给定存储阵列上支持的卷数有限制。确保存储阵列上配置的卷数小于支持的限制。当同步镜像处于活动状态时，创建的两个保留容量卷将计入卷限制。
* 对于异步镜像，主卷和辅助卷必须具有相同的 Drive Security 功能。
+
** 如果主卷支持 FIPS，则辅助卷必须支持 FIPS。
** 如果主卷具有 FDE 功能，则辅助卷必须具有 FDE 功能。
** 如果主卷未使用 Drive Security，则辅助卷不得使用 Drive Security。


* 主卷和辅助卷不得启用 Resource Partitioning。




[[reserved-capacity]]
== 预留容量

异步镜像：

* 镜像对中的主卷和辅助卷需要保留容量卷来记录写入信息，以便从控制器重置和其他临时中断中恢复。
* 由于镜像对中的主卷和辅助卷都需要额外的保留容量，因此您必须确保镜像关系中的两个存储阵列都有可用的空闲容量。


同步镜像：

* 主卷和辅助卷需要保留容量来记录写入信息，以便从控制器重置和其他临时中断中恢复。
* 激活同步镜像时，将自动创建保留容量卷。由于镜像对中的主卷和辅助卷都需要保留容量，因此您必须确保在参与同步镜像关系的两个存储阵列上都有足够的可用容量。




[[drive-security-feature]]
== 驱动器安全功能

* 如果使用具有安全功能的驱动器，则主卷和辅助卷必须具有兼容的安全设置。此限制未强制执行；因此，您必须自己验证。
* 如果使用具有安全功能的驱动器，则主卷和辅助卷应使用相同的驱动器类型。此限制未强制执行；因此，您必须自己验证。
* 如果使用数据保障 (DA)，则主卷和辅助卷必须具有相同的 DA 设置。
