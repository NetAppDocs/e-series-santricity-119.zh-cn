= 了解 SANtricity Unified Manager 中的发现
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要管理存储资源，必须首先发现网络中的存储阵列。



== 如何发现阵列？

使用"添加/发现"页面可以查找和添加要在组织网络中管理的存储阵列。可以发现多个阵列，也可以发现单个阵列。为此，输入网络 IP 地址，然后 Unified Manager 尝试单独连接到该范围内的每个 IP 地址。

了解详情：

* link:considerations-for-discovering-arrays.html["发现阵列的注意事项"]
* link:discover-multiple-arrays.html["发现多个存储阵列"]
* link:discover-single-array.html["发现单个阵列"]




== 如何管理阵列？

发现阵列后，转到 *管理 - 全部* 页面。从此页面，您可以滚动浏览网络中发现的存储阵列列表，查看其状态，并在单个阵列或一组阵列上执行操作。

如果要管理单个阵列，可以选择它并打开 System Manager。

了解详情：

* link:launch-considerations.html["访问 System Manager 的注意事项"]
* link:launch-system-manager.html["管理单个存储阵列"]
* link:storage-array-status.html["查看存储阵列状态"]
