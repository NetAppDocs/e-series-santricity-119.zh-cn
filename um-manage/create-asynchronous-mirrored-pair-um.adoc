= 在 SANtricity Unified Manager 中创建异步镜像对
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要配置异步镜像，请创建一个镜像对，其中包括本地阵列上的主卷和远程阵列上的辅助卷。

.开始之前
在创建镜像对之前，请满足 Unified Manager 的下列要求：

* Web Services Proxy 服务必须正在运行。
* Unified Manager 必须通过 HTTPS 连接在本地主机上运行。
* Unified Manager 必须显示存储阵列的有效 SSL 证书。您可以使用 Unified Manager 接受自签名证书或安装您自己的安全证书，并导航到菜单：Certificate[Certificate Management]。


此外，请务必满足存储阵列和卷的以下要求：

* 每个存储阵列必须有两个控制器。
* 必须在 Unified Manager 中发现两个存储阵列。
* 主阵列和辅助阵列中的每个控制器都必须配置以太网管理端口，并且必须连接到您的网络。
* 存储阵列的最低固件版本为 7.84。（它们可以各自运行不同的 OS 版本。）
* 您必须知道本地和远程存储阵列的密码。
* 必须在远程存储阵列上具有足够的可用容量，才能创建等于或大于要镜像的主卷的辅助卷。
* 您的本地和远程存储阵列通过光纤通道结构或 iSCSI 接口连接。
* 您已创建要在异步镜像关系中使用的主卷和辅助卷。
* 辅助卷必须至少与主卷一样大。


.关于此任务
创建异步镜像对的过程是一个多步骤过程。



[[step-1-create-or-select-a-mirror-consistency-group]]
== 步骤 1：创建或选择镜像一致性组

在此步骤中，您创建新的镜像一致性组或选择现有的一致性组。镜像一致性组是主卷和辅助卷（镜像对）的容器，并为组中的所有对指定所需的重新同步方法（手动或自动）。

.步骤
. 从 *Manage* 页面中，选择要用于源的本地存储阵列。
. 选择菜单：Actions[Create Asynchronous Mirrored Pair]。
+
创建异步镜像对向导打开。

. 选择现有镜像一致性组或创建新镜像一致性组。
+
要选择现有组，请确保选择了 *现有镜像一致性组*，然后从表中选择该组。一致性组可以包括多个镜像对。

+
要创建新组，请执行以下操作：

+
.. 选择 *A new mirror consistency group*，然后单击 *Next*。
.. 输入最能描述将在两个存储阵列之间镜像的卷上的数据的唯一名称。名称只能由字母、数字和特殊字符下划线 (_)、短划线 (-) 和哈希符号 (#) 组成。名称不能超过 30 个字符，也不能包含空格。
.. 选择要与本地存储阵列建立镜像关系的远程存储阵列。
+
[NOTE]
====
如果您的远程存储阵列受密码保护，系统将提示输入密码。

====
.. 选择是手动还是自动同步镜像对：
+
*** *手动* -- 选择此选项可手动启动此组中所有镜像对的同步。请注意，如果要稍后执行重新同步，则必须为主存储阵列启动 System Manager，然后转到菜单：Storage[Asynchronous Mirroring]，从 *Mirror Consistency Groups* 选项卡中选择组，然后选择菜单：More[Manually resynchronize]。
*** *自动* -- 选择从上一次更新开始到下一次更新开始的所需时间间隔，以 *分钟*、*小时* 或 *天* 为单位。例如，如果同步间隔设置为 30 分钟，并且同步过程从下午 4:00 开始，则下一个过程从下午 4:30 开始。


.. 选择所需的警报设置：
+
*** 对于手动同步，请指定接收警报时的阈值（由剩余容量的百分比定义）。
*** 对于自动同步，您可以设置三种警报方法：当同步在特定时间长度内未完成时，当远程阵列上的恢复点数据早于特定时间限制时，以及当保留容量接近特定阈值时（由剩余容量的百分比定义）。




. 选择 *Next* 并转到 <<步骤 2：选择主卷>>。
+
如果定义了新的镜像一致性组，Unified Manager 将首先在本地存储阵列上创建镜像一致性组，然后在远程存储阵列上创建镜像一致性组。您可以通过为每个阵列启动 System Manager 来查看和管理镜像一致性组。

+
[NOTE]
====
如果 Unified Manager 在本地存储阵列上成功创建镜像一致性组，但未能在远程存储阵列上创建它，它将自动从本地存储阵列中删除镜像一致性组。如果在 Unified Manager 尝试删除镜像一致性组时发生错误，则必须手动删除它。

====




[[step-2-select-the-primary-volume]]
== 步骤 2：选择主卷

在此步骤中，选择要在镜像关系中使用的主卷，并分配其保留容量。当您在本地存储阵列上选择主卷时，系统将显示该镜像对的所有合格卷的列表。任何不符合使用条件的卷都不会显示在该列表中。

添加到本地存储阵列上的镜像一致性组的任何卷都将在镜像关系中扮演主要角色。

.步骤
. 从符合条件的卷列表中，选择要用作主卷的卷，然后单击 *Next* 以分配保留容量。
. 从符合条件的候选项列表中，为主卷选择预留容量。
+
请记住以下准则：

+
** 保留容量的默认设置为基本卷容量的 20%，通常此容量就足够了。如果更改百分比，请单击 *Refresh Candidates*。
** 所需的容量因 I/O 写入主卷的频率和大小以及保留容量所需的时间而异。
** 一般来说，如果存在以下一种或两种情况，请为保留容量选择更大的容量：
+
*** 您打算将镜像对保留很长一段时间。
*** 由于繁重的 I/O 活动，主卷上的大部分数据块将发生变化。使用历史性能数据或其他操作系统实用程序来帮助您确定主卷的典型 I/O 活动。




. 选择 *Next* 并转到 <<步骤 3：选择辅助卷>>。




[[step-3-select-the-secondary-volume]]
== 步骤 3：选择辅助卷

在此步骤中，选择要在镜像关系中使用的辅助卷，并分配其保留容量。当您在远程存储阵列上选择辅助卷时，系统将显示该镜像对的所有合格卷的列表。任何不符合使用条件的卷都不会显示在该列表中。

您添加到远程存储阵列上的镜像一致性组的任何卷都将在镜像关系中担任辅助角色。

.步骤
. 从符合条件的卷列表中，选择要用作镜像对中的辅助卷的卷，然后单击 *Next* 以分配保留容量。
. 从符合条件的候选项列表中，为二级卷选择预留容量。
+
请记住以下准则：

+
** 保留容量的默认设置为基本卷容量的 20%，通常此容量就足够了。如果更改百分比，请单击 *Refresh Candidates*。
** 所需的容量因 I/O 写入主卷的频率和大小以及保留容量所需的时间而异。
** 一般来说，如果存在以下一种或两种情况，请为保留容量选择更大的容量：
+
*** 您打算将镜像对保留很长一段时间。
*** 由于繁重的 I/O 活动，主卷上的大部分数据块将发生变化。使用历史性能数据或其他操作系统实用程序来帮助您确定主卷的典型 I/O 活动。




. 选择 *Finish* 以完成异步镜像序列。


.结果
Unified Manager 执行以下操作：

* 开始本地存储阵列和远程存储阵列之间的初始同步。
* 在本地存储阵列和远程存储阵列上为镜像对创建保留容量。



NOTE: 如果要镜像的卷是精简卷，则在初始同步期间，仅将调配的块（分配的容量而不是报告的容量）传输到辅助卷。这样会减少必须传输才能完成初始同步的数据量。
