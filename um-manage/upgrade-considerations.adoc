= 了解如何使用 SANtricity Unified Manager 升级多个存储阵列
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
在使用 SANtricity Unified Manager 升级多个存储阵列之前，请在规划过程中查看主要注意事项。



== 当前版本

您可以从 Unified Manager 的"管理"页面查看每个发现的存储阵列的当前 SANtricity 操作系统软件版本。版本显示在 SANtricity 操作系统软件列中。当您单击每行中的 SANtricity 操作系统版本时，控制器固件和 NVSRAM 信息在弹出对话框中可用。



== 需要升级的其他组件

作为升级过程的一部分，您可能还需要升级主机的多路径/故障转移驱动程序或 HBA 驱动程序，以便主机可以与控制器正确交互。

有关兼容性信息，请参见 https://imt.netapp.com/matrix/#welcome["NetApp 互操作性矩阵"^]。此外，请参见适用于您的操作系统的 Express Guides 中的步骤。Express Guides 可从 https://docs.netapp.com/us-en/e-series/index.html["E 系列和 SANtricity 文档"^]获得。



== 双控制器

如果存储阵列包含两个控制器，并且您安装了多路径驱动程序，则在升级过程中，存储阵列可以继续处理 I/O。在升级过程中，会发生以下过程：

. 控制器 A 将其所有 LUN 故障切换到控制器 B。
. 升级发生在控制器 A 上。
. 控制器 A 收回其 LUN 和控制器 B 的所有 LUN。
. 升级发生在控制器 B 上。


升级完成后，可能需要在控制器之间手动重新分配卷，以确保卷返回到正确的所有控制器。
