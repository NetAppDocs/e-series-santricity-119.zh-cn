= 清除 SANtricity Unified Manager 中的暂存操作系统软件
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以删除暂存的 OS 软件，以确保不会在以后无意中激活待定版本。删除暂存的 OS 软件不会影响存储阵列上运行的当前版本。

.步骤
. 从主视图中，选择 *管理*，然后选择菜单：升级中心[Clear Staged OS Software]。
+
此时将打开 Clear Staged OS Software（清除暂存操作系统软件）对话框，并列出所有已发现的带有挂起软件或 NVSRAM 的存储系统。

. 如果需要，请对列表中的存储系统进行筛选或排序，以便查看所有已暂存软件的系统。
. 选中具有要清除的挂起软件的存储系统的复选框。
. 单击 *Clear*。
+
操作状态显示在对话框中。
