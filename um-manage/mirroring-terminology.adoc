= 了解 SANtricity Unified Manager 中的镜像术语
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
了解镜像术语如何适用于您的存储阵列。

[cols="25h,~"]
|===
| 术语 | 说明 


 a| 
本地存储阵列
 a| 
本地存储阵列是您要执行操作的存储阵列。



 a| 
镜像一致性组
 a| 
镜像一致性组是一个或多个镜像对的容器。对于异步镜像操作，必须创建镜像一致性组。组中的所有镜像对会同时重新同步，从而保持一致的恢复点。

同步镜像不使用镜像一致性组。



 a| 
镜像对
 a| 
镜像对由两个卷组成，一个主卷和一个辅助卷。

在异步镜像中，镜像对始终属于镜像一致性组。写入操作首先执行到主卷，然后复制到辅助卷。镜像一致性组中的每个镜像对共享相同的同步设置。



 a| 
主卷
 a| 
镜像对的主卷是要镜像的源卷。



 a| 
远程存储阵列
 a| 
远程存储阵列通常被指定为辅助站点，它通常在镜像配置中保存数据的副本。



 a| 
预留容量
 a| 
保留容量是用于任何复制服务操作和存储对象的物理分配容量。主机无法直接读取。

这些卷是必需的，以便控制器可以持久保存将镜像保持在操作状态所需的信息。它们包含增量日志和写入时复制数据等信息。



 a| 
二级卷
 a| 
镜像对的辅助卷通常位于辅助站点，并保存数据的副本。



 a| 
同步
 a| 
在本地存储阵列和远程存储阵列之间的初始同步时进行同步。当通信中断后主卷和辅助卷不同步时，也会发生同步。当通信链路再次工作时，任何未复制的数据都将同步到辅助卷的存储阵列。

|===
