= 在 SANtricity Unified Manager 中发现多个存储阵列
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以发现多个阵列，以检测管理服务器所在子网中的所有存储阵列，并自动将发现的阵列添加到您的管理域。

.开始之前
* 您必须使用包含 Security Admin 权限的用户配置文件登录。
* 必须正确设置和配置存储阵列。
* 必须使用 System Manager 的访问管理磁贴设置存储阵列密码。
* 要解决不受信任的证书问题，您必须具有来自证书颁发机构 (CA) 的受信任证书文件，并且证书文件在本地系统上可用。


发现阵列是一个多步骤过程。



== 步骤 1：输入网络地址

输入要在本地子网中搜索的网络地址范围。成功到达的任何存储阵列都会显示在"发现"页面上，并可能被添加到您的管理域中。

如果出于任何原因需要停止发现操作，请单击 *Stop Discovery*。

.步骤
. 在 Manage 页面中，选择 *Add/Discover*。
+
此时将显示"添加/发现"对话框。

. 选择 *发现网络范围内的所有存储阵列* 单选按钮。
. 输入起始网络地址和结束网络地址以搜索本地子网络，然后单击 *Start Discovery*。
+
发现过程开始。此发现过程可能需要几分钟才能完成。发现存储阵列时，Discover 页面上的表将被填充。

+
[NOTE]
====
如果未发现可管理的阵列，请验证存储阵列已正确连接到您的网络，并且其分配的地址在范围内。单击 *New Discovery Parameters* 返回添加/发现页面。

====
. 查看发现的存储阵列列表。
. 选中要添加到管理域的任何存储阵列旁边的复选框，然后单击 *Next*。
+
Unified Manager 将对要添加到管理域的每个阵列进行凭据检查。您可能需要解析与该阵列关联的任何自签名证书和不受信任的证书。

. 单击 *Next* 继续向导中的下一步。




== 步骤 2：在发现过程中解析自签名证书

作为发现过程的一部分，系统会验证存储阵列是否正在使用受信任来源的证书。

.步骤
. 执行以下操作之一：
+
** 如果信任到发现的存储阵列的连接，请继续到向导中的下一张卡。自签名证书将被标记为可信，存储阵列将被添加到 Unified Manager。
** 如果不信任与存储阵列的连接，请选择 *取消* 并验证每个存储阵列的安全证书策略，然后再将其中任何一个添加到 Unified Manager。


. 单击 *Next* 继续向导中的下一步。




== 步骤 3：在发现期间解析不受信任的证书

当存储阵列尝试与 Unified Manager 建立安全连接，但连接无法确认为安全时，会发生不受信任的证书。在阵列发现过程中，可以通过导入由受信任的第三方颁发的证书颁发机构 (CA) 证书（或 CA 签名的证书）来解决不受信任的证书。

如果满足以下任一情况，则可能需要安装其他受信任的 CA 证书：

* 您最近添加了一个存储阵列。
* 一个或两个证书已过期。
* 一个或两个证书都被吊销。
* 一个或两个证书都缺少根证书或中间证书。


.步骤
. 选中要为其解析不受信任的证书的任何存储阵列旁边的复选框，然后选择 **Import** 按钮。
+
此时将打开一个对话框，用于导入受信任的证书文件。

. 单击 *Browse* 以选择存储阵列的证书文件。
+
文件名显示在对话框中。

. 单击 *Import*。
+
文件已上传并验证。

+
[NOTE]
====
任何具有未解决的不受信任证书问题的存储阵列都不会添加到 Unified Manager。

====
. 单击 *Next* 继续向导中的下一步。




== 步骤 4：提供密码

必须输入要添加到管理域的存储阵列的密码。

.步骤
. 输入要添加到 Unified Manager 的每个存储阵列的密码。
. *可选：* 将存储阵列关联到组：从下拉列表中，选择要与选定存储阵列关联的所需组。
. 单击 *Finish*。


.完成后
存储阵列将添加到您的管理域并与选定组关联（如果指定）。

[NOTE]
====
Unified Manager 连接到指定的存储阵列可能需要几分钟时间。

====
