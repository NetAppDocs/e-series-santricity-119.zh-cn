= SANtricity Unified Manager 的存储镜像常见问题
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您只是在寻找问题的快速答案，此常见问题可以为您提供帮助。



== 在创建镜像一致性组之前，我需要知道什么？

在创建镜像一致性组之前，请遵循这些指南。

满足 Unified Manager 的以下要求：

* Web Services Proxy 服务必须正在运行。
* Unified Manager 必须通过 HTTPS 连接在本地主机上运行。
* Unified Manager 必须显示存储阵列的有效 SSL 证书。您可以使用 Unified Manager 接受自签名证书或安装您自己的安全证书，并导航到菜单：Certificate[Certificate Management]。


此外，请务必满足存储阵列的以下要求：

* 必须在 Unified Manager 中发现两个存储阵列。
* 每个存储阵列必须有两个控制器。
* 主阵列和辅助阵列中的每个控制器都必须配置以太网管理端口，并且必须连接到您的网络。
* 存储阵列的最低固件版本为 7.84。（它们可以各自运行不同的 OS 版本。）
* 您必须知道本地和远程存储阵列的密码。
* 您的本地和远程存储阵列通过光纤通道结构或 iSCSI 接口连接。


[NOTE]
====
EF600/EF600C 或 EF300/EF300C 存储系统上不提供同步镜像。

====


== 创建镜像对之前，我需要知道什么？

在创建镜像对之前，请遵循以下指南。

* 您必须有两个存储阵列。
* 每个存储阵列必须有两个控制器。
* 必须在 Unified Manager 中发现两个存储阵列。
* 主阵列和辅助阵列中的每个控制器都必须配置以太网管理端口，并且必须连接到您的网络。
* 存储阵列的最低固件版本为 7.84。（它们可以各自运行不同的 OS 版本。）
* 您必须知道本地和远程存储阵列的密码。
* 必须在远程存储阵列上具有足够的可用容量，才能创建等于或大于要镜像的主卷的辅助卷。
* 异步镜像在具有 Fibre Channel (FC) 或 iSCSI 主机端口的控制器上受支持，而同步镜像仅在具有 FC 主机端口的控制器上受支持。


[NOTE]
====
EF600/EF600C 或 EF300/EF300C 存储系统上不提供同步镜像。

====


== 为什么要更改此百分比？

对于异步镜像操作，保留容量通常为基本卷的 20%。通常这个容量就足够了。

所需的容量因向基本卷写入 I/O 的频率和大小以及您打算使用存储对象的复制服务操作的时长而异。一般来说，如果存在以下一种或两种情况，请为保留容量选择较大的百分比：

* 如果特定存储对象的复制服务操作的生命周期非常长。
* 如果由于大量 I/O 活动，基本卷上的大量数据块将发生变化。使用历史性能数据或其他操作系统实用程序来帮助您确定基本卷的典型 I/O 活动。




== 为什么我看到多个预留容量候选项？

如果池或卷组中有多个卷符合您为存储对象选择的容量百分比量，则您将看到多个候选项。

您可以通过更改要在基本卷上保留用于复制服务操作的物理驱动器空间百分比来刷新推荐候选列表。根据您的选择显示最佳候选。



== 为什么我没有看到所有的卷？

为镜像对选择主卷时，列表会显示所有符合条件的卷。

不符合使用条件的任何卷都不会显示在该列表中。由于以下任何原因，卷可能不符合条件：

* 卷不是最佳的。
* 此卷已参与镜像关系。
* 对于同步镜像，镜像对中的主卷和辅助卷必须是标准卷。它们不能是精简卷或快照卷。
* 对于异步镜像，精简卷必须启用自动扩展。



NOTE: 对于 EF600 和 EF300 控制器，异步镜像对的主卷和辅助卷必须匹配相同的协议、托盘级别、段大小、安全类型和 RAID 级别。不符合条件的异步镜像对将不会出现在可用卷列表中。



== 为什么我看不到远程存储阵列上的所有卷？

在远程存储阵列上选择辅助卷时，列表会显示该镜像对的所有合格卷。

任何不符合使用条件的卷都不会显示在该列表中。卷可能因以下任何原因而不符合条件：

* 此卷是非标准卷，例如快照卷。
* 卷不是最佳的。
* 此卷已参与镜像关系。
* 对于异步镜像，主卷和辅助卷之间的精简卷属性不匹配。
* 如果使用数据保障 (DA)，则主卷和辅助卷必须具有相同的 DA 设置。
+
** 如果主卷启用了 DA，则辅助卷必须启用 DA。
** 如果主卷未启用 DA，则辅助卷不得启用 DA。


* 对于异步镜像，主卷和辅助卷必须具有相同的 Drive Security 功能。
+
** 如果主卷支持 FIPS，则辅助卷必须支持 FIPS。
** 如果主卷具有 FDE 功能，则辅助卷必须具有 FDE 功能。
** 如果主卷未使用 Drive Security，则辅助卷不得使用 Drive Security。






== 同步优先级对同步速率有何影响？

同步优先级定义了相对于系统性能为同步活动分配的处理时间。

主卷的控制器所有者在后台执行此操作。同时，控制器所有者处理对主卷的本地 I/O 写入和对辅助卷的相关远程写入。由于重新同步会从 I/O 活动中转移控制器处理资源，因此重新同步可能会对主机应用程序产生性能影响。

请记住这些准则，以帮助您确定同步优先级可能需要多长时间，以及同步优先级如何影响系统性能。

可提供以下优先级费率：

* 最低
* 低
* 中
* 高
* 最高


最低优先级速率支持系统性能，但重新同步需要更长的时间。最高优先级速率支持重新同步，但系统性能可能会受到影响。

这些指南大致反映了优先级之间的差异。

== 为什么建议使用手动同步策略？

建议手动重新同步，因为它允许您以一种为恢复数据提供最佳机会的方式管理重新同步过程。

如果使用自动重新同步策略，并且在重新同步过程中发生间歇性通信问题，则辅助卷上的数据可能会暂时损坏。当重新同步完成时，数据将被更正。
