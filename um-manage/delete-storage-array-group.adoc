= 在 SANtricity Unified Manager 中删除存储阵列组
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以删除一个或多个不再需要的存储阵列组。

.关于此任务
此操作仅删除存储阵列组。与已删除组关联的存储阵列仍可通过"全部管理"视图或其关联的任何其他组进行访问。

.步骤
. 从 Manage 页面中，选择菜单：Manage Groups[Delete storage array group]。
. 选择要删除的一个或多个存储阵列组。
. 单击 *Delete*。
