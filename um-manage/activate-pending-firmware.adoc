= 在 SANtricity Unified Manager 中激活暂存操作系统软件
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以选择立即激活软件文件或等待更方便的时间。此过程假设您选择稍后激活软件文件。

.关于此任务
您可以在不激活固件文件的情况下传输固件文件。您可以选择稍后激活，原因如下：

* *一天中的时间* -- 激活软件可能需要很长时间，因此您可能需要等待 I/O 负载较轻。控制器在激活过程中重新启动和故障转移，因此在升级完成之前，性能可能会低于正常水平。
* *包类型* -- 在升级其他存储阵列上的文件之前，您可能需要在一个存储阵列上测试新软件和固件。


[NOTE]
====
激活过程启动后无法停止。

====
.步骤
. 在主视图中，选择 *管理*。如有必要，单击状态列可在页面顶端对所有状态为"OS 升级（等待激活）"的存储阵列进行排序。
. 选择要为其激活软件的一个或多个存储阵列，然后选择菜单：Upgrade Center[Activate Staged OS Software]。
+
升级操作期间发生以下操作：

+
** 升级前运行状况检查在激活过程中运行。升级前运行状况检查会评估所有存储阵列组件，以确保可以继续激活。
** 如果存储阵列的任何运行状况检查失败，则激活将停止。您可以单击省略号 (...) 并选择 *Save Log* 以查看错误。您也可以选择覆盖运行状况检查错误，然后单击 *Continue* 以继续激活。
** 您可以在升级前运行状况检查后取消激活操作。成功完成升级前运行状况检查后，将进行激活。激活所需的时间取决于您的存储阵列配置和要激活的组件。


. *可选：*激活完成后，您可以通过单击省略号 (...) ，然后选择 *Save Log*，查看为特定存储阵列激活的内容列表。
+
此文件将以此名称保存在浏览器的 Downloads 文件夹中 `activate_log-<date>.json`。
