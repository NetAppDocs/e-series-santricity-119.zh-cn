= 了解 SANtricity Unified Manager 中的存储阵列组
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以通过对一组存储阵列进行分组来管理物理和虚拟化基础架构。您可能需要对存储阵列进行分组，以便更轻松地运行监控或报告作业。



[[types-of-storage-array-groups]]
== 存储阵列组的类型

* *所有组*
+
All 组是默认组，包括组织中发现的所有存储阵列。可以从主视图访问 All 组。

* *用户创建的组*
+
用户创建的组包括手动选择添加到该组的存储阵列。可以从主视图访问用户创建的组。
