= 在 SANtricity Unified Manager 中管理单个存储阵列
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果要执行管理操作，可以使用"启动"选项打开一个或多个存储阵列的基于浏览器的 SANtricity System Manager。

.步骤
. 从管理页面中，选择要管理的一个或多个存储阵列。
. 单击 *Launch*。
+
系统打开一个新窗口并显示 System Manager 登录页面。

. 输入您的用户名和密码，然后单击 *Log in*。
