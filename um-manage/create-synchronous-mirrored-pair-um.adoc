= 在 SANtricity Unified Manager 中创建同步镜像对
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要配置同步镜像，请创建镜像对，其中包括本地阵列上的主卷和远程阵列上的辅助卷。

[NOTE]
====
此功能在 EF600/EF600C 或 EF300/EF300C 存储系统中不可用。

====
.开始之前
在创建镜像对之前，请满足 Unified Manager 的下列要求：

* Web Services Proxy 服务必须正在运行。
* Unified Manager 必须通过 HTTPS 连接在本地主机上运行。
* Unified Manager 必须显示存储阵列的有效 SSL 证书。您可以使用 Unified Manager 接受自签名证书或安装您自己的安全证书，并导航到菜单：Certificate[Certificate Management]。


此外，请务必满足存储阵列和卷的以下要求：

* 计划用于镜像的两个存储阵列可在 Unified Manager 中找到。
* 每个存储阵列必须有两个控制器。
* 主阵列和辅助阵列中的每个控制器都必须配置以太网管理端口，并且必须连接到您的网络。
* 存储阵列的最低固件版本为 7.84。（它们可以各自运行不同的 OS 版本。）
* 您必须知道本地和远程存储阵列的密码。
* 您的本地和远程存储阵列通过 Fibre Channel 结构连接。
* 您已创建要在同步镜像关系中使用的主卷和辅助卷。
* 主卷必须为标准卷。它不能是精简卷或快照卷。
* 辅助卷必须为标准卷。它不能是精简卷或快照卷。
* 辅助卷应至少与主卷一样大。


.关于此任务
创建同步镜像对的过程是一个多步骤过程。



== 步骤 1：选择主卷

在此步骤中，选择要在同步镜像关系中使用的主卷。当您在本地存储阵列上选择主卷时，系统将显示该镜像对的所有合格卷的列表。不符合使用条件的任何卷都不会显示在该列表中。您选择的卷在镜像关系中占有主要角色。

.步骤
. 从 *Manage* 页面中，选择要用于源的本地存储阵列。
. 选择菜单：Actions[Create Synchronous Mirrored Pair]。
+
创建同步镜像对向导打开。

. 从符合条件的卷列表中，选择要用作镜像中主卷的卷。
. 选择 *Next* 并转到 <<步骤 2：选择辅助卷>>。




== 步骤 2：选择辅助卷

在此步骤中，选择要在镜像关系中使用的辅助卷。当您在远程存储阵列上选择辅助卷时，系统将显示该镜像对的所有合格卷的列表。任何不符合使用条件的卷都不会显示在该列表中。您选择的卷将保留镜像关系中的次要角色。

.步骤
. 选择要与本地存储阵列建立镜像关系的远程存储阵列。
+
[NOTE]
====
如果您的远程存储阵列受密码保护，系统将提示输入密码。

====
+
** 存储阵列按其存储阵列名称列出。如果您尚未命名存储阵列，则它将被列为"unnamed"。
** 如果要使用的存储阵列不在列表中，请确保已在 Unified Manager 中发现它。


. 从符合条件的卷列表中，选择要用作镜像中辅助卷的卷。
+
[NOTE]
====
如果选择的辅助卷的容量大于主卷，则可用容量将限于主卷的大小。

====
. 单击 *Next* 并转到 <<步骤 3：选择同步设置>>。




== 步骤 3：选择同步设置

在此步骤中，您可以选择确定通信中断后数据同步方式的设置。您可以设置主卷的控制器所有者在通信中断后将数据与辅助卷重新同步的优先级。您还必须选择重新同步策略，手动或自动。

.步骤
. 使用滑块栏设置同步优先级。
+
与服务 I/O 请求相比，同步优先级确定通信中断后有多少系统资源用于完成初始同步和重新同步操作。

+
此对话框上设置的优先级适用于主卷和辅助卷。您可以稍后通过转到 System Manager 并选择菜单：Storage[Synchronous Mirroring > More > Edit Settings] 来修改主卷上的速率。

+
有五个同步优先级：

+
** 最低
** 低
** 中
** 高
** 最高
+
如果将同步优先级设置为最低等级，则会优先处理 I/O 活动，而重新同步操作则需要更长的时间。如果将同步优先级设置为最高等级，则会优先处理重新同步操作，而存储阵列的 I/O 活动可能受到影响。



. 选择是手动还是自动重新同步远程存储阵列上的镜像对。
+
** *Manual*（推荐选项）-- 选择此选项可要求在通信恢复到镜像对后手动恢复同步。此选项为恢复数据提供了最佳机会。
** *自动* -- 选择此选项可在通信恢复到镜像对后自动开始重新同步。
+
要手动恢复同步，请转到 System Manager 并选择菜单：Storage[Synchronous Mirroring]，突出显示表中的镜像对，然后选择 *More* 下的 *Resume*。



. 单击 *Finish* 完成同步镜像序列。


.结果
一旦镜像被激活，系统将执行以下操作：

* 开始本地存储阵列和远程存储阵列之间的初始同步。
* 设置同步优先级和重新同步策略。
* 保留控制器 HIC 的最高编号端口用于镜像数据传输。
+
此端口上接收的 I/O 请求仅接受来自镜像对中辅助卷的远程首选控制器所有者。（允许在主卷上进行预留。）

* 创建两个保留容量卷，每个控制器一个，用于记录写入信息以从控制器重置和其他临时中断中恢复。
+
每个卷的容量为 128 MiB。但是，如果将卷置于池中，则为每个卷保留 4 GiB。



.完成后
转到 System Manager 并选择菜单：主页[查看正在进行的操作]以查看同步镜像操作的进度。此操作可能很长，并可能影响系统性能。
