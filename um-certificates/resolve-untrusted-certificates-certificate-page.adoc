= 解决不受信任的证书
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
当存储阵列尝试与 SANtricity Unified Manager 建立安全连接，但连接无法确认为安全时，会发生不受信任的证书。

从"证书"页面，您可以通过从存储阵列导入自签名证书或导入由受信任的第三方颁发的证书颁发机构 (CA) 证书来解决不受信任的证书。

.开始之前
* 您必须使用包含 Security Admin 权限的用户配置文件登录。
* 如果您计划导入 CA 签名的证书：
+
** 您已为存储阵列中的每个控制器生成了证书签名请求（.CSR 文件），并将其发送到 CA。
** CA 返回了受信任的证书文件。
** 证书文件在您的本地系统上可用。




.关于此任务
如果满足以下任一情况，则可能需要安装其他受信任的 CA 证书：

* 您最近添加了一个存储阵列。
* 一个或两个证书已过期。
* 一个或两个证书都被吊销。
* 一个或两个证书都缺少根证书或中间证书。


.步骤
. 选择 *Certificate Management*。
. 选择 *Trusted* 选项卡。
+
此页面显示存储阵列报告的所有证书。

. 选择 menu:Import[Certificates] 以导入 CA 证书或 menu:Import[Self-Signed storage array certificates] 以导入自签名证书。
+
要限制视图，您可以使用 *Show certificates that are...* 筛选字段，或者可以通过单击其中一个列标题对证书行进行排序。

. 在对话框中，选择证书，然后单击 *Import*。
+
证书已上传并验证。
