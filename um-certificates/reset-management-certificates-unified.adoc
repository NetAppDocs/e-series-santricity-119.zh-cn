= 重置管理证书
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以将管理证书还原为原始的出厂自签名状态。

.开始之前
必须使用包含 Security admin 权限的用户配置文件登录。否则，不会显示证书功能。

.关于此任务
此任务从安装了 Web Services Proxy 和 Unified Manager 的主机系统中删除当前管理证书。重置证书后，主机系统恢复使用自签名证书。

.步骤
. 选择 *Settings > Certificates*。
. 选择 *Array Management* 选项卡，然后选择 *Reset*。
+
将打开确认重置管理证书对话框。

. 在字段中键入 `reset`，然后单击*重置*。
+
刷新浏览器后，浏览器可能会阻止对目标站点的访问，并报告该站点正在使用 HTTP Strict Transport Security。当您切换回自签名证书时会出现这种情况。要清除阻止访问目标的条件，您必须从浏览器中清除浏览数据。



.结果
系统恢复使用来自服务器的自签名证书。因此，系统会提示用户手动接受其会话的自签名证书。
