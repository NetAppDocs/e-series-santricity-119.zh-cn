= 在 SANtricity Unified Manager 中导入阵列的证书
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如有必要，您可以导入存储阵列的证书，以便它们可以通过托管 SANtricity Unified Manager 的系统进行身份验证。证书可以由证书颁发机构 (CA) 签名，也可以进行自签名。

.开始之前
* 必须使用包含 Security admin 权限的用户配置文件登录。否则，不会显示证书功能。
* 如果要导入受信任的证书，则必须使用 System Manager 为存储阵列控制器导入证书。


.步骤
. 选择 *Certificate Management*。
. 选择 *Trusted* 选项卡。
+
此页面显示存储阵列报告的所有证书。

. 选择 menu:Import[Certificates] 以导入 CA 证书或 menu:Import[Self-signed storage array certificates] 以导入自签名证书。
+
要限制视图，您可以使用 *Show certificates that are...* 筛选字段，或者可以通过单击其中一个列标题对证书行进行排序。

. 在对话框中，选择证书，然后单击 *Import*。
+
证书已上传并验证。
