= 在 SANtricity System Manager 中查看正在进行的操作并对其执行操作
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要查看长期运行的操作并对其执行操作，请使用 Operations in Progress 页面。

.关于此任务
对于"正在进行的操作"页面上列出的每个操作，都会显示完成百分比和完成操作的预计剩余时间。在某些情况下，您可以停止操作或将其置于更高或更低的优先级。您还可以从列表中清除已完成的 Volume Copy 操作。

.步骤
. 在主页上，选择 *Show operations in progress* 。
+
此时将显示正在执行的操作页面。

. 如果需要，请使用 Actions 列中的链接停止或更改操作的优先级。
+
[CAUTION]
====
阅读对话框中提供的所有警告文本，特别是在停止操作时。

====
+
您可以停止卷复制操作或更改其优先级。

. 卷复制操作完成后，您可以选择 *清除* 将其从列表中删除。
+
操作完成后，主页顶端将显示一条信息性消息和黄色扳手图标。此消息包含一个链接，允许您从"正在进行的操作"页面中清除操作。
