== 单个卷的性能统计与总量有何关系？

通过聚合所有卷（包括保留容量卷）来计算池和卷组的统计信息。

保留容量由存储系统内部使用，以支持精简卷、快照和异步镜像，并且对 I/O 主机不可见。因此，池、控制器和存储阵列统计信息加起来可能不是可查看卷的总和。

但是，对于应用程序和工作负载统计信息，仅聚合可见卷。



== 为什么数据在图形和表格中显示为零？

当图形和表格中的数据点显示零时，表示该时间点的对象没有 I/O 活动。发生这种情况的原因可能是主机未启动对该对象的 I/O，也可能是该对象本身存在问题。

对象的历史数据仍可供查看。一旦对象的 I/O 活动开始发生，图形和表格将显示非零数据。

下表列出了任何给定对象的数据点值可能为零的最常见原因。

[cols="25h,~"]
|===
| 数组级对象类型 | 原因数据显示为零 


 a| 
卷
 a| 
* 卷无主机分配。




 a| 
卷组
 a| 
* 正在导入卷组。
* 卷组不包含分配给主机的卷，*_and_* 卷组不包含任何保留容量。




 a| 
驱动器
 a| 
* 驱动器出现故障。
* 驱动器已被删除。
* 驱动器处于未知状态。




 a| 
控制器
 a| 
* 控制器已脱机。
* 控制器出现故障。
* 控制器已被移除。
* 控制器处于未知状态。




 a| 
存储阵列
 a| 
* 存储阵列不包含卷。


|===


== 延迟图表显示了什么？

延迟图提供了卷、卷组、池、应用程序和工作负载的延迟统计信息，以毫秒 (ms) 为单位。此图形显示在逻辑视图、物理视图和应用程序和工作负载视图选项卡中。

延迟是指在读取或写入数据时发生的任何延迟。将光标悬停在图形上的某个点上，以毫秒 (ms) 为单位查看该时间点的以下值：

* 阅读时间。
* 写入时间。
* 平均 I/O 大小。




== IOPS 图形显示了什么？

IOPS 图表显示每秒输入/输出操作的统计信息。在主页上，此图表显示存储阵列的统计信息。在性能图块的 Logical View、Physical View 和 Applications & Workloads View 选项卡中，此图表显示存储阵列、卷、卷组、池、应用程序和工作负载的统计信息。

IOPS 是_每秒输入/输出 (I/O) 操作_的缩写。将光标悬停在图形上的某个点上，以查看该时间点的以下值：

* 读取操作数。
* 写入操作数。
* 读取和写入操作总数。




== MiB/s 图表显示了什么？

MiB/s 图表以每秒 mebibyte 为单位显示传输速度统计信息。在主页上，此图表显示存储阵列的统计信息。在性能图块的 Logical View、Physical View 和 Applications & Workloads View 选项卡中，此图表显示存储阵列、卷、卷组、池、应用程序和工作负载的统计信息。

MiB/s 是 _mebibytes per second_ 或 1,048,576 bytes per second 的缩写。将光标悬停在图形上的某个点上，以查看该时间点的以下值：

* 读取的数据量。
* 写入的数据量。
* 读取和写入的总数据量。




== CPU 图形显示了什么？

CPU 图表显示每个控制器（控制器 A 和控制器 B）的处理能力统计信息。CPU 是_中央处理器_的缩写。在主页上，此图表显示存储阵列的统计信息。在性能图块的物理视图选项卡上，此图表显示存储阵列和驱动器的统计信息。

CPU 图形显示针对阵列上的操作使用的 CPU 处理容量的百分比。即使没有发生外部 I/O，CPU 利用率百分比也可以非零，因为存储操作系统可能正在执行后台操作和监视。将光标悬停在图形上的某个点上，以查看该时间点正在使用的处理功能的百分比。



== 净空图表显示了什么？

净空图与存储阵列控制器的剩余性能功能相关。此图形在主页和 Performance 磁贴的 Physical View 选项卡上可见。

净空图表显示存储系统中物理对象的剩余性能能力。将光标悬停在图形上的某个点上，以查看控制器 A 和控制器 B 的 IOPS 和 MiB/s 剩余能力的百分比。
