= 在 SANtricity System Manager 中查看存储层次结构
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
主界面上的 Storage Hierarchy 提供了由存储阵列管理的各种硬件组件和存储对象的组织视图。

要查看存储层次结构，请转到主页，然后单击存储阵列组件或存储对象上的下拉箭头。存储阵列由物理组件和逻辑组件的集合组成。



[[physical-components]]
== 物理组件

下表描述了存储阵列的物理组件。

[cols="25h,~"]
|===
| 组件 | 说明 


 a| 
控制器
 a| 
控制器由主板、固件和软件组成。它控制驱动器并实现 System Manager 功能。



 a| 
磁盘架
 a| 
搁板是安装在机柜或机架上的外壳。它包含存储阵列的硬件组件。有两种类型的搁板：控制器搁板和驱动器搁板。控制器搁板包括控制器和驱动器。驱动器搁板包括输入/输出模块 (IOM) 和驱动器。

[NOTE]
====
如果您的存储阵列包含不同的介质类型或不同的接口类型，则会显示每个驱动器类型的驱动器架。

====


 a| 
驱动器
 a| 
驱动器是提供数据物理存储介质的电磁机械设备或固态存储设备。



 a| 
主机
 a| 
主机是向存储阵列上的卷发送 I/O 的服务器。



 a| 
主机总线适配器 (HBA)
 a| 
主机总线适配器 (HBA) 是驻留在主机中的主板，包含一个或多个主机端口。



 a| 
主机端口
 a| 
主机端口是主机总线适配器 (HBA) 上的端口，它提供与控制器的物理连接，并用于 I/O 操作。



 a| 
管理客户端
 a| 
管理客户端是安装浏览器以访问 System Manager 的计算机。

|===


[[logical-components]]
== 逻辑组件

存储阵列中的驱动器提供数据的物理存储容量。使用 System Manager 将物理容量配置到逻辑组件中，例如池、卷组和卷。这些组件是用于配置、存储、维护和保留存储阵列上的数据的工具。下表描述了存储阵列的逻辑组件。

[cols="25h,~"]
|===
| 组件 | 说明 


 a| 
池
 a| 
池是逻辑上分组的一组驱动器。您可以使用池创建一个或多个可供主机访问的卷。（您可以从池或卷组创建卷。）



 a| 
卷组
 a| 
卷组是具有共享特征的卷的容器。卷组具有定义的容量和 RAID 级别。您可以使用卷组创建一个或多个可供主机访问的卷。（您可以从卷组或池创建卷。）



 a| 
卷
 a| 
卷是应用程序、数据库和文件系统存储数据的容器。它是为主机创建的逻辑组件，用于访问存储阵列上的存储。



 a| 
逻辑单元号 (LUN)
 a| 
逻辑单元号 (LUN) 是分配给主机用于访问卷的地址空间的编号。此卷以 LUN 的形式作为容量呈现给主机。

每个主机都有自己的 LUN 地址空间。因此，不同的主机可以使用相同的 LUN 来访问不同的卷。

|===
