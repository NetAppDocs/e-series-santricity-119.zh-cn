SANtricity System Manager 使用图标和其他几种方法通知您存储阵列存在问题。



[[icons]]
== 图标

System Manager 使用这些图标指示存储阵列及其组件的状态。

|===

 a|

System Manager 在不同位置显示这些图标。

* 主页上的通知区域显示失败图标和消息。
* 导航区域中的 Home 页面图标显示失败图标。
* 在"组件"页面上，驱动器和控制器的图形显示故障图标。




[[alerts-and-leds]]
== 警报和 LED

此外，System Manager 还会以其他方式通知您问题。

* System Manager 发送 SNMP 通知或电子邮件错误消息。
* 硬件上的"需要维修操作" LED 指示灯亮起。


当您收到问题通知时，请使用 Recovery Guru 来帮助您解决问题。如有必要，请将硬件文档与恢复步骤一起使用，以更换出现故障的组件。
