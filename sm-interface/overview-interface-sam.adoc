= 了解 SANtricity System Manager 界面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity System Manager 是一个基于 Web 的界面，允许您在单个视图中管理存储阵列。



== 主页

主页为您的存储阵列的日常管理提供了一个仪表板视图。当您登录到 System Manager 时，主页是显示的第一个屏幕。

仪表板视图包括四个摘要区域，其中包含有关存储阵列状态和运行状况的关键信息。您可以在摘要区域找到更多信息。

[cols="25h,~"]
|===
| 区域 | 说明 


 a| 
通知
 a| 
通知区域显示指示存储阵列及其组件状态的问题通知。此外，此 portlet 还会显示自动警报，可帮助您在问题影响存储环境的其他区域之前对其进行故障排除。



 a| 
性能
 a| 
性能区域允许您比较和对比一段时间内的资源使用情况。您可以查看存储阵列的响应时间 (IOPS)、传输速率 (MiB/s) 和正在使用的处理容量 (CPU) 的性能指标。



 a| 
容量
 a| 
容量区域显示存储阵列中已分配容量、可用存储容量和未分配存储容量的图表视图。



 a| 
存储层次结构
 a| 
存储层次结构区域提供了由存储阵列管理的各种硬件组件和存储对象的组织视图。单击下拉箭头，对该硬件组件或存储对象执行特定操作。

|===


== 接口设置

您可以从主界面更改显示首选项和其他设置。

[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
显示首选项
 a| 
从界面右上角的首选项下拉菜单中更改容量值和时间范围。



 a| 
会话超时
 a| 
配置超时，以便在指定时间后断开用户的非活动会话。



 a| 
帮助
 a| 
从界面右上角的下拉菜单中访问帮助文档和其他资源。

|===
