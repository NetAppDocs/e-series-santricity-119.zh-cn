= SANtricity System Manager 存储系统设置常见问题解答

[role="lead"]
如果您只是在寻找问题的快速答案，此常见问题可以为您提供帮助。



[[what-if-i-dont-see-all-of-my-hardware-components]]
== 如果我没有看到所有硬件组件，该怎么办？

如果在"验证硬件"对话框中未显示所有硬件组件，则可能表示驱动器盘架未正确连接，或者存储阵列中安装了不兼容的盘架。

验证所有驱动器盘架都已正确连接。如果您不确定哪些驱动器盘架是兼容的，请联系技术支持。



[[what-if-i-dont-see-all-of-my-hosts]]
== 如果我没有看到所有主机，该怎么办？

如果未看到已连接的主机，则表示自动检测失败、主机连接不正确或当前未连接任何主机。

完成设置后，您可以稍后配置主机。您可以按以下步骤手动创建主机：

* 您可以通过转到菜单：Storage[Hosts] 来手动创建主机并关联相应的主机端口标识符。手动创建的主机也会显示在 *Initial Setup* 向导中。
* 目标和主机必须配置为主机端口类型（例如，iSCSI 或 NVMe over RoCE），并且必须在自动检测工作之前建立到存储的会话。




[[how-does-identifying-applications-help-me-manage-my-storage-array]]
== 识别应用程序如何帮助我管理存储阵列？

识别应用程序时，SANtricity System Manager 会自动推荐基于应用程序类型优化存储的卷配置。

按应用程序优化卷可以提高数据存储操作的效率。卷配置中包括 I/O 类型、段大小、控制器所有权以及读写缓存等特征。此外，您可以按应用程序和工作负载查看性能数据，以评估应用程序及其相关工作负载的延迟、IOPS 和 MiB/s。



[[what-is-a-workload]]
== 什么是工作负载？

对于网络中的某些应用程序（例如 SQL Server 或 Exchange），可以定义优化该应用程序存储的工作负载。

工作负载是支持应用程序的存储对象。可以为每个应用程序定义一个或多个工作负载或实例。对于某些应用程序，系统将工作负载配置为包含具有类似底层卷特征的卷。这些卷特性是根据工作负载支持的应用程序类型进行优化的。例如，如果创建支持 Microsoft SQL Server 应用程序的工作负载，然后为该工作负载创建卷，则会优化基础卷特征以支持 Microsoft SQL Server。

在创建卷期间，系统会提示您回答有关工作负载使用的问题。例如，如果要为 Microsoft Exchange 创建卷，系统会询问您需要多少个邮箱、平均邮箱容量要求以及所需的数据库副本数。系统使用此信息为您创建最佳卷配置，可以根据需要对其进行编辑。



[[how-do-i-configure-the-delivery-method-for-autosupport]]
== 如何配置 AutoSupport 的传送方式？

要访问 AutoSupport 交付方式的配置任务，请转到菜单：支持[Support Center]，然后单击 *AutoSupport* 选项卡。

支持以下协议： HTTPS 和 SMTP 。



[[how-do-i-know-if-i-should-accept-the-recommended-pool-configuration]]
== 如何知道我是否应该接受建议的池配置？

是否接受推荐的池配置取决于几个因素。

通过回答以下问题，确定最适合您需求的存储类型：

* 您是否更喜欢多个容量较小的池，而不是尽可能大的池？
* 是否更喜欢 RAID 卷组而不是池？
* 您是否更喜欢手动设置驱动器，而不是建议您进行配置？


如果您对这些问题中的任何一个回答为"是"，请考虑拒绝推荐的池配置。
