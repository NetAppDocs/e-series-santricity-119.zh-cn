= 了解 SANtricity System Manager 正在执行的操作页面
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
"正在进行的操作"页面允许您查看当前正在运行或处于挂起、停止或失败状态的长期运行操作的列表。您可以对某些类型的操作执行操作。

长时间运行的操作会影响系统性能。对于某些操作，您可以选择停止操作或更改其优先级，以便更重要的操作首先完成。
