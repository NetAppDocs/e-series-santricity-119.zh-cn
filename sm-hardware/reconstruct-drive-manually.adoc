= 在 SANtricity System Manager 中手动重建驱动器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
驱动器重建通常在更换驱动器后自动开始。如果驱动器重建未自动开始，您可以手动开始重建。

[NOTE]
====
仅在技术支持或 Recovery Guru 的指示下执行此操作。

====
.步骤
. 选择 *Hardware*。
. 如果图形显示控制器，请单击 *Drives* 选项卡。
+
图形更改为显示驱动器而不是控制器。

. 单击要手动重建的驱动器。
+
此时将显示驱动器的上下文菜单。

. 选择 *Reconstruct*，并确认要执行此操作。
