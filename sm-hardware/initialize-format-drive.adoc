= 在 SANtricity System Manager 中初始化（格式化）驱动器
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果将分配的驱动器从一个存储阵列移动到另一个存储阵列，则必须先初始化（格式化）这些驱动器，然后才能在新存储阵列中使用它们。

.关于此任务
初始化会从驱动器中删除以前的配置信息并将其返回到未分配状态。此时驱动器可用于添加到新存储阵列中的新池或卷组。

移动单个驱动器时，请使用初始化驱动器操作。如果要将整个卷组从一个存储阵列移动到另一个存储阵列，则无需初始化驱动器。

[CAUTION]
====
*可能丢失数据* -- 初始化驱动器时，驱动器上的所有数据都会丢失。仅在技术支持人员的指示下执行此操作。

====
.步骤
. 选择 *Hardware*。
. 如果图形显示控制器，请单击 *Drives* 选项卡。
+
图形更改为显示驱动器而不是控制器。

. 单击要初始化的驱动器。
+
此时将显示驱动器的上下文菜单。

. 选择 *Initialize*，并确认要执行此操作。
