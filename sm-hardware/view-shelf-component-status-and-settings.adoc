= 在 SANtricity System Manager 中查看磁盘架组件状态和设置
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
硬件页面提供磁盘架组件的状态和设置，包括电源、风扇和电池。

.关于此任务
可用组件取决于机架类型：

* *驱动器架* -- 在一个架子中包含一组驱动器、电源/风扇罐、输入/输出模块 (IOM) 和其他支持组件。
* *Controller shelf* -- 在一个架子中包含一组驱动器、一个或两个 controller 罐、电源/风扇罐和其他支持组件。


.步骤
. 选择 *Hardware*。
. 选择 Controller Shelf 或 Drive Shelf 的下拉列表，然后选择 *View Settings*。
+
此时将打开"Shelf Components Settings"对话框，其中包含显示与货架组件相关的状态和设置的选项卡。根据所选货架类型，表格中描述的某些选项卡可能不会显示。

+
[cols="25h,~"]
|===
| 选项卡 | 说明 


 a| 
磁盘架
 a| 
*Shelf* 选项卡显示以下属性：

** *Shelf ID* -- 唯一标识存储阵列中的货架。控制器固件分配此编号，但您可以通过选择菜单：Shelf[Change ID] 进行更改。
** *Shelf path redundancy* -- 指定货架和控制器之间的连接是否具有备用方法 (是) 或没有 (否)。
** *当前驱动器类型* -- 显示内置于驱动器中的技术类型（例如，具有安全功能的 SAS 驱动器）。如果有多种驱动器类型，则显示两种技术。
** *序列号* -- 显示货架的序列号。




 a| 
IOM (ESM)
 a| 
*IOM (ESM)* 选项卡显示输入/输出模块 (IOM) 的状态，也称为环境服务模块 (ESM)。它监控驱动器架中组件的状态，并充当驱动器托盘和控制器之间的连接点。

状态可以是 Optimal、Failed、Optimal (Miswire) 或 Uncertified。其他信息包括固件版本和配置设置版本。

选择 *Show more settings* 以查看最大和当前数据速率，以及卡通信的状态（是或否）。

[NOTE]
====
您还可以通过选择 IOM 图标 image:../media/sam1130-ss-hardware-iom-icon.gif[""]（位于 Shelf 下拉列表旁边）来查看此状态。

====


 a| 
电源
 a| 
*Power Supplies* 选项卡显示电源盒和电源本身的状态。状态可以是 Optimal、Failed、Removed 或 Unknown。它还显示了电源的部件号。

[NOTE]
====
您还可以通过选择 Shelf 下拉列表旁边的电源图标 image:../media/sam1130-ss-hardware-power-icon.gif[""] 来查看此状态。

====


 a| 
风扇
 a| 
*Fans* 选项卡显示风扇罐和风扇本身的状态。状态可以是 Optimal、Failed、Removed 或 Unknown。

[NOTE]
====
您还可以通过选择 Shelf 下拉列表旁边的 Fan 图标 image:../media/sam1130-ss-hardware-fan-icon.gif[""] 来查看此状态。

====


 a| 
温度
 a| 
*Temperature* 选项卡显示货架组件的温度状态，例如传感器、控制器和电源/风扇罐。状态可以是 Optimal、Nominal temperature exceeded、Maximum temperature exceeded 或 Unknown。

[NOTE]
====
您还可以通过选择 Shelf 下拉列表旁边的温度图标 image:../media/sam1130-ss-hardware-temp-icon.gif[""] 来查看此状态。

====


 a| 
电池
 a| 
*Batteries* 选项卡显示控制器电池的状态。状态可以是 Optimal、Failed、Removed 或 Unknown。其他信息包括电池寿命、更换前天数、学习周期以及学习周期之间的周数。

[NOTE]
====
您还可以通过选择 Shelf 下拉列表旁边的 Batteries 图标 image:../media/sam1130-ss-hardware-battery-icon.gif[""] 来查看此状态。

====


 a| 
SFP
 a| 
*SFPs* 选项卡显示控制器上小型可插拔 (SFP) 收发器的状态。状态可以是最佳、失败或未知。

选择 *Show more settings* 以查看 SFP 的部件号、序列号和供应商。

[NOTE]
====
您还可以通过选择 Shelf 下拉列表旁边的 SFP 图标 image:../media/sam1130-ss-hardware-sfp-icon.gif[""] 来查看此状态。

====
|===
. 单击 *Close*。
