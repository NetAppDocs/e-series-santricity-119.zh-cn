[[what-is-shelf-loss-protection-and-drawer-loss-protection]]
== 什么是货架丢失保护和抽屉丢失保护？

磁盘架丢失保护和抽屉丢失保护是池和卷组的属性，允许您在发生单个磁盘架或抽屉故障时保持数据访问。



[[shelf-loss-protection]]
=== 磁盘架丢失保护

盘架是包含驱动器或驱动器和控制器的盘柜。盘架丢失保护可保证在单个驱动器盘架发生完全通信中断时对池或卷组中卷上的数据的可访问性。完全失去通信的一个例子可能是驱动器架断电或两个 I/O 模块 (IOM) 出现故障。

[NOTE]
====
如果驱动器已在池或卷组中出现故障，则无法保证提供盘架丢失保护。在这种情况下，失去对驱动器盘架的访问权限，从而导致池或卷组中的另一个驱动器导致数据丢失。

====
货架丢失保护的标准取决于保护方法，如下表所述：

[cols="1a,1a,1a"]
|===
| 级别 | 货架丢失保护标准 | 所需的最少磁盘架数量 


 a| 
池
 a| 
池必须包含至少五个盘架上的驱动器，并且每个盘架上的驱动器数量必须相等。盘架丢失保护不适用于大容量盘架；如果您的系统包含大容量盘架，请参阅抽屉丢失保护。
 a| 
5



 a| 
RAID 6
 a| 
此卷组在一个盘架中包含的驱动器不超过两个。
 a| 
3



 a| 
RAID 3 或 RAID 5
 a| 
卷组中的每个驱动器都位于单独的托架中。
 a| 
3



 a| 
RAID 1
 a| 
RAID 1 对中的每个驱动器必须位于单独的机架中。
 a| 
2



 a| 
RAID 0
 a| 
无法实现 Shelf Loss Protection。
 a| 
不适用

|===


[[drawer-loss-protection]]
=== 抽屉丢失保护

抽屉是货架的一个隔间，您可以拉出它来访问驱动器。只有大容量的货架才有抽屉。抽屉丢失保护可确保在单个抽屉完全失去通信的情况下，可以访问池或卷组中的卷上的数据。完全失去通信的一个例子可能是抽屉断电或抽屉内部组件故障。

[NOTE]
====
如果驱动器已在池或卷组中出现故障，则无法保证提供抽屉丢失保护。在这种情况下，失去对抽屉（以及池或卷组中的另一个驱动器）的访问权限会导致数据丢失。

====
抽屉损失保护的标准取决于保护方法，如下表所述：

[cols="1a,1a,1a"]
|===
| 级别 | 抽屉损失保护标准 | 所需的最少抽屉数量 


 a| 
池
 a| 
池候选项必须包括来自所有抽屉的驱动器，并且每个抽屉中必须有数量相等的驱动器。

池必须包括至少五个抽屉中的驱动器，并且每个抽屉中的驱动器数量必须相等。

当池中包含 15、20、25、30、35、40、45、50、55 或 60 个驱动器时，60 驱动器磁盘架可以实现抽屉丢失保护。初始创建后，可以将 5 的倍数增量添加到池中。
 a| 
5



 a| 
RAID 6
 a| 
此卷组在一个抽屉中包含的驱动器不超过两个。
 a| 
3



 a| 
RAID 3 或 RAID 5
 a| 
卷组中的每个驱动器都位于单独的抽屉中。
 a| 
3



 a| 
RAID 1
 a| 
镜像对中的每个驱动器必须位于单独的抽屉中。
 a| 
2



 a| 
RAID 0
 a| 
无法实现抽屉丢失保护。
 a| 
不适用

|===


[[what-are-battery-learn-cycles]]
== 什么是电池学习周期？

学习周期是用于校准智能电池仪表的自动周期。

学习周期包括以下几个阶段：

* 受控电池放电
* 休息期间
* 收费


将电池放电至预定阈值。在此阶段，电池仪表被校准。

学习周期需要以下参数：

* 充满电的电池
* 无电池过热


双工控制器系统的学习周期同时发生。对于具有来自多个电池或电池组的备用电源的控制器，学习周期按顺序进行。

学习周期计划在一周中的同一时间和同一天定期自动启动。周期间隔以周为单位描述。

[NOTE]
====
一个学习周期可能需要几个小时才能完成。
