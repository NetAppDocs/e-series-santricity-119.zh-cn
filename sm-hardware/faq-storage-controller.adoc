== 什么是自动协商？

自动协商是网络接口与另一个网络接口自动协调其自身连接参数（速度和双工）的能力。

自动协商通常是配置管理端口的首选设置；但是，如果协商失败，不匹配的网络接口设置可能会严重影响网络性能。如果这种情况不可接受，则应手动将网络接口设置设置为正确的配置。自动协商由控制器的以太网管理端口执行。iSCSI 主机总线适配器不执行自动协商。

[NOTE]
====
如果自动协商失败，控制器将尝试在 10BASE-T 半双工模式下建立连接，这是最低的公分母。

====


== 什么是 IPv6 无状态地址自动配置？

使用无状态自动配置，主机不会从服务器获取地址和其他配置信息。

IPv6 中的无状态自动配置具有链路本地地址、多播和邻居发现 (ND) 协议。IPv6 可以从底层数据链路层地址生成地址的接口 ID。

无状态自动配置和有状态自动配置相辅相成。例如，主机可以使用无状态自动配置来配置自己的地址，但使用有状态自动配置来获取其他信息。有状态自动配置允许主机从服务器获取地址和其他配置信息。互联网协议第 6 版（IPv6）还定义了一种方法，通过该方法，可以一次对网络上的所有 IP 地址进行重新编号。IPv6 定义了一种方法，让网络上的设备自动配置其 IP 地址和其他参数，而无需服务器。

设备在使用无状态自动配置时执行以下步骤：

. *生成链路本地地址* -- 设备生成一个链路本地地址，该地址有 10 位，后跟 54 个零，后跟 64 位接口 ID。
. *测试链路本地地址的唯一性* -- 节点进行测试，以确保其生成的链路本地地址尚未在本地网络上使用。节点使用 ND 协议发送邻居请求消息。作为响应，本地网络侦听邻居通告消息，这表明另一个设备已经在使用链路本地地址。如果是这样，则必须生成新的链路本地地址或自动配置失败，并且必须使用其他方法。
. *分配链路本地地址* -- 如果设备通过唯一性测试，则设备会将链路本地地址分配给其 IP 接口。链路本地地址可用于本地网络上的通信，但不能通过 Internet 进行通信。
. *联系路由器* -- 节点尝试联系本地路由器，了解有关继续配置的详细信息。此联系是通过侦听路由器定期发送的路由器通告消息，或通过发送特定的路由器请求消息向路由器询问有关下一步操作的信息来执行的。
. *为节点提供方向* -- 路由器为节点提供有关如何进行自动配置的方向。或者，路由器告诉主机如何确定全局 Internet 地址。
. *配置全局地址* -- 主机使用其全局唯一的 Internet 地址配置自己。此地址通常由路由器提供给主机的网络前缀形成。




== 我应该选择哪一个— DHCP 或手动配置？

网络配置的默认方法是 Dynamic Host Configuration Protocol (DHCP)。除非您的网络没有 DHCP 服务器，否则始终使用此选项。



== 什么是 DHCP 服务器？

动态主机配置协议 (DHCP) 是一种自动分配互联网协议 (IP) 地址的协议。

必须为连接到 TCP/IP 网络的每个设备分配唯一的 IP 地址。这些设备包括存储阵列中的控制器。

如果没有 DHCP，网络管理员将手动输入这些 IP 地址。使用 DHCP，当客户端需要启动 TCP/IP 操作时，客户端会广播对地址信息的请求。DHCP 服务器接收请求，在称为租用期的指定时间内分配新地址，并将该地址发送到客户端。使用 DHCP，设备每次连接到网络时都可以使用不同的 IP 地址。在某些系统中，即使设备仍处于连接状态，设备的 IP 地址也可能发生变化。



== 如何配置我的 DHCP 服务器？

必须将动态主机配置协议 (DHCP) 服务器配置为对存储阵列中的控制器使用静态 Internet 协议 (IP) 地址。

DHCP 服务器分配的 IP 地址通常是动态的，并且可以更改，因为它们有一个到期的租用期。某些设备（例如服务器和路由器）需要使用静态地址。存储阵列中的控制器还需要静态 IP 地址。

有关如何分配静态地址的信息，请参见 DHCP 服务器的文档。



== 为什么需要更改控制器网络配置？

使用带外管理时，必须为每个控制器设置网络配置（其 Internet Protocol (IP) 地址、子网掩码（子网掩码）和网关）。

您可以使用动态主机配置协议 (DHCP) 服务器设置网络配置。如果您未使用 DHCP 服务器，则必须手动输入网络配置。



== 从何处获取网络配置？

您可以从网络管理员处获取 Internet Protocol (IP) 地址、子网掩码 (subnet mask) 和网关信息。

在控制器上配置端口时需要此信息。



== 什么是 ICMP PING 响应？

互联网控制消息协议 (ICMP) 是 TCP/IP 套件的协议之一。

 `ICMP echo request` 和 (`ICMP echo reply` 消息通常称为  `ping` 消息。 `Ping` 是系统管理员用于手动测试网络设备之间的连接以及测试网络延迟和数据包丢失的故障排除工具。 `ping` 命令向网络上的设备发送  `ICMP echo request`，设备立即响应 (`ICMP echo reply`。有时，公司的网络安全策略要求在所有设备上禁用  `ping` (`ICMP echo reply`，以使未经授权的人员更难发现它们。



== 何时应刷新端口配置？

在修改或升级服务器时刷新 DHCP 服务器，并且与要使用的当前存储阵列和存储阵列相关的 DHCP 信息已更改。

具体来说，当您知道 DHCP 服务器将分配不同的地址时，请从 DHCP 服务器刷新端口配置或 iSNS 服务器。

[NOTE]
====
刷新端口配置会对该端口上的所有 iSCSI 连接造成破坏。

====


== 配置管理端口后我该怎么做？

如果更改了存储阵列的 IP 地址，则可能需要在 SANtricity Unified Manager 中更新全局阵列视图。

要在 Unified Manager 中更新全局阵列视图，请打开界面并转到菜单：Manage[Discover]。

如果仍在使用 SANtricity Storage Manager，请转到企业管理窗口 (EMW)，在此必须删除并重新添加新 IP 地址。



== 为什么存储系统处于非优化模式？

处于非最佳模式的存储系统是由于系统配置状态无效所致。尽管存在此状态，但完全支持对现有卷的正常 I/O 访问；但是，SANtricity System Manager 将禁止某些操作。

由于以下原因之一，存储系统可能会转换为无效系统配置：

* 控制器不合规，可能是因为它的子型号 ID (SMID) 代码不正确，或者它已超过高级功能的限制。
* 正在执行内部服务操作，例如驱动器固件下载。
* 控制器超过奇偶校验错误阈值并进入锁定。
* 发生一般锁定情况。
