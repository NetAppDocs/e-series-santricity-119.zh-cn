= 在 SANtricity System Manager 中使控制器脱机
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果系统指示您执行此操作，则可以将控制器置于离线状态。

.开始之前
* 存储阵列必须有两个控制器。未脱机的控制器必须处于联机状态（处于最佳状态）。
* 确保没有正在使用的卷，或者在使用这些卷的所有主机上都安装了多路径驱动程序。


.关于此任务
++ ++

[CAUTION]
====
除非 Recovery Guru 或技术支持人员指示，否则请勿将控制器置于离线状态。

====
.步骤
. 选择 *Hardware*。
. 如果图形显示驱动器，请单击 *Controllers & Components* 选项卡。
+
图形会更改为显示控制器而不是驱动器。

. 单击要置于脱机状态的控制器。
+
此时将显示控制器的上下文菜单。

. 选择 *Place offline*，并确认要执行此操作。


.结果
System Manager 可能需要几分钟才能将控制器的状态更新为脱机。在更新状态之前，请勿开始任何其他操作。
