= 了解 SANtricity System Manager 中的驱动器状态
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
SANtricity System Manager 报告驱动器的各种状态。



== 辅助功能状态

[cols="25h,~"]
|===
| 状态 | 定义 


 a| 
已绕过
 a| 
驱动器实际存在，但控制器无法在任何端口上与其通信。



 a| 
不兼容
 a| 
存在以下条件之一：

* 该驱动器未经认证，无法在存储阵列中使用。
* 此驱动器具有不同的扇区大小。
* 驱动器包含来自较旧或较新固件版本的无法使用的配置数据。




 a| 
已删除
 a| 
驱动器已从存储阵列中被不当移除。



 a| 
现有
 a| 
控制器可以在两个端口上与驱动器通信。



 a| 
无响应
 a| 
驱动器未响应命令。

|===


== 角色状态

[cols="25h,~"]
|===
| 状态 | 定义 


 a| 
已分配
 a| 
该驱动器是池或卷组的成员。



 a| 
使用中的热备盘
 a| 
此驱动器当前正被用作出现故障的驱动器的替代品。热备盘仅用于卷组，而不用于池。



 a| 
备用热备盘
 a| 
驱动器已准备好用作发生故障的驱动器的替代品。热备盘仅用于卷组，而不用于池。



 a| 
未分配
 a| 
驱动器不是池或卷组的成员。

|===


== 可用性状态

[cols="25h,~"]
|===
| 状态 | 定义 


 a| 
失败
 a| 
驱动器无法工作。驱动器上的数据不可用。



 a| 
即将发生的故障
 a| 
已检测到驱动器可能很快出现故障。驱动器上的数据仍然可用。



 a| 
脱机
 a| 
驱动器通常无法用于存储数据，因为它是正在导出的卷组的一部分或正在进行固件升级。



 a| 
最佳
 a| 
驱动器运行正常。

|===
