= 了解 SANtricity 软件中使用的硬件术语
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
以下硬件术语适用于存储阵列。

.一般硬件术语：
[%collapsible]
====
[cols="25h,~"]
|===
| 组件 | 说明 


 a| 
托架
 a| 
托架是架子上安装驱动器或其他组件的插槽。



 a| 
控制器
 a| 
控制器由主板、固件和软件组成。它控制驱动器并实现 System Manager 功能。



 a| 
控制器架
 a| 
控制器架包含一组驱动器和一个或多个控制器罐。控制器罐装有控制器、主机接口卡 (HIC) 和电池。



 a| 
驱动器
 a| 
驱动器是提供数据物理存储介质的电磁机械设备或固态存储设备。



 a| 
驱动器架
 a| 
驱动器架也称为扩展架，包含一组驱动器和两个输入/输出模块 (IOM)。IOM 包含将驱动器架连接到控制器架或其他驱动器架的 SAS 端口。



 a| 
IOM（ESM）
 a| 
IOM 是一个输入/输出模块，包括用于将驱动器架连接到控制器架的 SAS 端口。在以前的控制器模型中，IOM 被称为环境服务模块（ESM）。



 a| 
电源/风扇盒
 a| 
电源/风扇罐是滑入架子的组件。它包括一个电源和一个集成风扇。



 a| 
SFP
 a| 
SFP 是一种小型可插拔 (SFP) 收发器。



 a| 
磁盘架
 a| 
搁板是安装在机柜或机架上的外壳。它包含存储阵列的硬件组件。有两种类型的搁板：控制器搁板和驱动器搁板。控制器搁板包括控制器和驱动器。驱动器搁板包括输入/输出模块 (IOM) 和驱动器。



 a| 
存储阵列
 a| 
存储阵列包括盘架、控制器、驱动器、软件和固件。

|===
====
.控制器条款：
[%collapsible]
====
[cols="25h,~"]
|===
| 组件 | 说明 


 a| 
控制器
 a| 
控制器由主板、固件和软件组成。它控制驱动器并实现 System Manager 功能。



 a| 
控制器架
 a| 
控制器架包含一组驱动器和一个或多个控制器罐。控制器罐装有控制器、主机接口卡 (HIC) 和电池。



 a| 
DHCP
 a| 
动态主机配置协议 (DHCP) 是在 Internet Protocol (IP) 网络上用于动态分发网络配置参数（例如 IP 地址）的协议。



 a| 
DNS
 a| 
域名系统 (DNS) 是连接到互联网或专用网络的设备的命名系统。DNS 服务器维护域名目录并将其转换为互联网协议 (IP) 地址。



 a| 
双工配置
 a| 
双工是存储阵列中的双控制器模块配置。双工系统在控制器、逻辑卷路径和磁盘路径方面是完全冗余的。如果一个控制器发生故障，另一个控制器会接管其 I/O 以保持可用性。双工系统还具有冗余风扇和电源。



 a| 
全双工 / 半双工连接
 a| 
全双工和半双工是指连接模式。在全双工模式下，两个设备可以同时在两个方向上进行通信。在半双工模式下，设备一次可以在一个方向上通信（一个设备发送消息，而另一个设备接收消息）。



 a| 
HIC
 a| 
主机接口卡（HIC）可以可选地安装在控制器罐内。内置在控制器中的主机端口称为基板主机端口。内置在 HIC 中的主机端口称为 HIC 端口。



 a| 
ICMP PING 响应
 a| 
互联网控制消息协议 (ICMP) 是联网计算机的操作系统用于发送消息的协议。ICMP 消息确定主机是否可达以及往返该主机传输数据包需要多长时间。



 a| 
MAC 地址
 a| 
以太网使用媒体访问控制标识符（MAC 地址）来区分连接同一物理传输网络接口上两个端口的单独逻辑通道。



 a| 
管理客户端
 a| 
管理客户端是安装浏览器以访问 System Manager 的计算机。



 a| 
MTU
 a| 
最大传输单元 (MTU) 是可以在网络中发送的最大大小的数据包或帧。



 a| 
NTP
 a| 
网络时间协议 (NTP) 是一种用于数据网络中计算机系统之间时钟同步的网络协议。



 a| 
单工配置
 a| 
Simplex 是存储阵列中的单控制器模块配置。单工系统不提供控制器或磁盘路径冗余，但具有冗余风扇和电源。



 a| 
VLAN
 a| 
虚拟局域网（VLAN）是一种逻辑网络，其行为就像与同一设备（交换机、路由器等）支持的其他网络在物理上分离一样。

.驱动器术语：
[%collapsible]
====
[cols="25h,~"]
|===
| 组件 | 说明 


 a| 
DA
 a| 
数据保障 (DA) 是一项检查和纠正数据通过控制器传输到驱动器时可能发生的错误的功能。数据保障可以在池或卷组级别启用，主机使用支持 DA 的 I/O 接口，如 Fibre Channel。



 a| 
驱动器安全功能
 a| 
驱动器安全是一种存储阵列功能，可通过全磁盘加密 (FDE) 驱动器或联邦信息处理标准 (FIPS) 驱动器提供额外的安全层。当这些驱动器与驱动器安全功能一起使用时，它们需要安全密钥才能访问其数据。当驱动器从阵列中物理卸下时，它们必须安装在另一个阵列中才能运行，此时，它们将处于安全锁定状态，直到提供正确的安全密钥。



 a| 
驱动器架
 a| 
驱动器架也称为扩展架，包含一组驱动器和两个输入/输出模块 (IOM)。IOM 包含将驱动器架连接到控制器架或其他驱动器架的 SAS 端口。



 a| 
DULBE
 a| 
Deallocated or Unwritten Logical Block Error (DULBE) 是 NVMe 驱动器上的一个选项，允许 EF300 或 EF600 存储阵列支持资源调配的卷。



 a| 
FDE 驱动器
 a| 
全磁盘加密 (FDE) 驱动器在硬件级别对磁盘驱动器执行加密。硬盘驱动器包含一个 ASIC 芯片，该芯片在写入过程中对数据进行加密，然后在读取过程中对数据进行解密。



 a| 
FIPS 驱动器
 a| 
FIPS 驱动器使用联邦信息处理标准 (FIPS) 140-2 level 2。它们本质上是 FDE 驱动器，符合美国政府确保强大加密算法和方法的标准。FIPS 驱动器具有比 FDE 驱动器更高的安全标准。



 a| 
HDD
 a| 
硬盘驱动器 (HDD) 是使用具有磁性涂层的旋转金属盘片的数据存储设备。



 a| 
热备盘驱动器
 a| 
热备盘在 RAID 1、RAID 5 或 RAID 6 卷组中充当备用驱动器。它们是功能齐全的驱动器，不包含任何数据。如果卷组中的驱动器出现故障，控制器会自动将故障驱动器的数据重建到热备盘。



 a| 
NVMe
 a| 
Non-Volatile Memory Express (NVMe) 是专为基于闪存的存储设备（如 SSD 驱动器）设计的接口。与以前的逻辑设备接口相比，NVMe 减少了 I/O 开销，并包括性能改进。



 a| 
SAS
 a| 
串行连接 SCSI (SAS) 是一种点对点串行协议，它将控制器直接链接到磁盘驱动器。



 a| 
支持安全的驱动器
 a| 
支持安全的驱动器可以是全磁盘加密 (FDE) 驱动器，也可以是联邦信息处理标准 (FIPS) 驱动器，它们在写入期间加密数据，在读取期间解密数据。这些驱动器被认为是安全_有能力_的，因为它们可以使用 Drive Security 功能用于额外的安全性。如果为与这些驱动器一起使用的卷组和池启用了 Drive Security 功能，则驱动器将变得安全_已启用_。



 a| 
启用安全功能的驱动器
 a| 
启用安全的驱动器与 Drive Security 功能一起使用。当您启用 Drive Security 功能，然后将 Drive Security 应用于支持安全的驱动器上的池或卷组时，驱动器将变为启用安全。只能通过配置了正确安全密钥的控制器进行读写访问。这种额外的安全性可以防止对从存储阵列中物理移除的驱动器上的数据进行未经授权的访问。



 a| 
SSD
 a| 
固态硬盘（SSD）是使用固态内存（闪存）永久存储数据的数据存储设备。SSD 模拟传统硬盘驱动器，并提供与硬盘驱动器相同的接口。

.iSCSI 术语：
[%collapsible]
====
[cols="25h,~"]
|===
| 术语 | 说明 


 a| 
CHAP
 a| 
质询握手身份验证协议 (CHAP) 方法在初始链接期间验证目标和启动程序的身份。身份验证基于名为 CHAP __secret__ 的共享安全密钥。



 a| 
控制器
 a| 
控制器由主板、固件和软件组成。它控制驱动器并实现 System Manager 功能。



 a| 
DHCP
 a| 
动态主机配置协议 (DHCP) 是在 Internet Protocol (IP) 网络上用于动态分发网络配置参数（例如 IP 地址）的协议。



 a| 
IB
 a| 
InfiniBand (IB) 是高性能服务器和存储系统之间数据传输的通信标准。



 a| 
ICMP PING 响应
 a| 
互联网控制消息协议 (ICMP) 是联网计算机的操作系统用于发送消息的协议。ICMP 消息确定主机是否可达以及往返该主机传输数据包需要多长时间。



 a| 
IQN
 a| 
iSCSI 限定名称 (IQN) 标识符是 iSCSI 启动程序或 iSCSI 目标的唯一名称。



 a| 
iSER
 a| 
用于 RDMA 的 iSCSI 扩展（iSER）是一种协议，它扩展了 iSCSI 协议以便通过 RDMA 传输（例如 InfiniBand 或以太网）进行操作。



 a| 
iSNS
 a| 
Internet Storage Name Service (iSNS) 是一种协议，允许在 TCP/IP 网络上自动发现、管理和配置 iSCSI 和 Fibre Channel 设备。



 a| 
MAC 地址
 a| 
以太网使用媒体访问控制标识符（MAC 地址）来区分连接同一物理传输网络接口上两个端口的单独逻辑通道。



 a| 
管理客户端
 a| 
管理客户端是安装浏览器以访问 System Manager 的计算机。



 a| 
MTU
 a| 
最大传输单元 (MTU) 是可以在网络中发送的最大大小的数据包或帧。



 a| 
RDMA
 a| 
远程直接内存访问 (RDMA) 是一种技术，允许网络计算机在不涉及任何一台计算机的操作系统的情况下交换主内存中的数据。



 a| 
未命名发现会话
 a| 
启用未命名发现会话的选项后，iSCSI 启动程序无需指定目标 IQN 即可检索控制器的信息。

.NVMe 术语：
[%collapsible]
====
[cols="25h,~"]
|===
| 术语 | 说明 


 a| 
InfiniBand
 a| 
InfiniBand (IB) 是高性能服务器和存储系统之间数据传输的通信标准。



 a| 
命名空间
 a| 
命名空间是为块访问而格式化的 NVM 存储。它类似于 SCSI 中的逻辑单元，它与存储阵列中的卷相关。



 a| 
命名空间 ID
 a| 
命名空间 ID 是 NVMe 控制器的命名空间唯一标识符，可以设置为 1 到 255 之间的值。它类似于 SCSI 中的逻辑单元号 (LUN)。



 a| 
NQN
 a| 
NVMe 限定名称 (NQN) 用于标识远程存储目标（存储阵列）。



 a| 
NVM
 a| 
非易失性内存 (NVM) 是许多类型的存储设备中使用的持久性内存。



 a| 
NVMe
 a| 
Non-Volatile Memory Express (NVMe) 是专为基于闪存的存储设备（如 SSD 驱动器）设计的接口。与以前的逻辑设备接口相比，NVMe 减少了 I/O 开销，并包括性能改进。



 a| 
NVMe-oF
 a| 
Non-Volatile Memory Express over Fabrics (NVMe-oF) 是一种规范，使 NVMe 命令和数据能够在主机和存储之间通过网络传输。



 a| 
NVMe 控制器
 a| 
在主机连接过程中创建 NVMe 控制器。它提供了主机和存储阵列中的命名空间之间的访问路径。



 a| 
NVMe 队列
 a| 
队列用于通过 NVMe 接口传递命令和消息。



 a| 
NVMe 子系统
 a| 
具有 NVMe 主机连接的存储阵列。



 a| 
RDMA
 a| 
远程直接内存访问 (RDMA) 通过在网络接口卡 (NIC) 硬件中实现传输协议，实现更直接的数据进出服务器。



 a| 
RoCE
 a| 
RDMA over Converged Ethernet (RoCE) 是一种网络协议，允许通过以太网进行远程直接内存访问 (RDMA)。



 a| 
SSD
 a| 
固态硬盘（SSD）是使用固态内存（闪存）永久存储数据的数据存储设备。SSD 模拟传统硬盘驱动器，并提供与硬盘驱动器相同的接口。
