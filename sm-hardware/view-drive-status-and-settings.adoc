= 在 SANtricity System Manager 中查看驱动器状态和设置
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以查看驱动器的状态和设置，例如媒体类型、接口类型和容量。

.步骤
. 选择 *Hardware*。
. 如果图形显示控制器，请单击 *Drives* 选项卡。
+
图形更改为显示驱动器而不是控制器。

. 选择要查看其状态和设置的驱动器。
+
驱动器的上下文菜单打开。

. 选择 *View settings*。
+
此时将打开驱动器设置对话框。

. 要查看所有设置，请单击对话框右上角的 *Show more settings*。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 设置 | 说明 


 a| 
状态
 a| 
显示 Optimal、Offline、Non-critical fault 和 Failed。Optimal 状态指示所需的工作条件。



 a| 
模式
 a| 
显示已分配、未分配、热备盘待机或正在使用的热备盘。



 a| 
位置
 a| 
显示驱动器所在的货架和托架编号。



 a| 
分配给/可以保护/保护
 a| 
如果驱动器分配给池、卷组或 SSD 缓存，此字段将显示"分配给"。值可以是池名称、卷组名称或 SSD 缓存名称。如果驱动器已分配给热备盘，且其模式为待机，则此字段显示"可以保护"。如果热备盘可以保护一个或多个卷组，则会显示卷组名称。如果无法保护卷组，则显示 0 个卷组。

如果驱动器已分配给热备盘，且其模式为"正在使用中"，则此字段将显示"保护"。该值是受影响的卷组的名称。

如果驱动器未分配，则不会显示此字段。



 a| 
介质类型
 a| 
显示驱动器使用的记录媒体类型，可以是硬盘驱动器 (HDD) 或固态硬盘 (SSD)。



 a| 
使用的续航时间百分比（仅当 SSD 驱动器存在时显示）
 a| 
到目前为止写入驱动器的数据量，除以总理论写入限制。



 a| 
接口类型
 a| 
显示驱动器使用的接口类型，例如 SAS。



 a| 
驱动器路径冗余
 a| 
显示驱动器和控制器之间的连接是否冗余（是）或不冗余（否）。



 a| 
容量 (GiB)
 a| 
显示驱动器的可用容量（配置的总容量）。



 a| 
速度 (RPM)
 a| 
以 RPM 为单位显示速度（对于 SSD 不显示）。



 a| 
当前数据速率
 a| 
显示驱动器和存储阵列之间的数据传输速率。



 a| 
逻辑扇区大小（字节）
 a| 
显示驱动器使用的逻辑扇区大小。



 a| 
物理扇区大小 (字节)
 a| 
显示驱动器使用的物理扇区大小。通常，硬盘驱动器的物理扇区大小为 4096 字节。



 a| 
驱动器固件版本
 a| 
显示驱动器固件的修订级别。



 a| 
全球标识符
 a| 
显示驱动器的唯一十六进制标识符。



 a| 
产品 ID
 a| 
显示由制造商分配的产品标识符。



 a| 
序列号
 a| 
显示驱动器的序列号。



 a| 
制造商
 a| 
显示驱动器的供应商。



 a| 
制造日期
 a| 
显示驱动器的构建日期。


NOTE: 不适用于 NVMe 驱动器。



 a| 
支持安全功能
 a| 
显示驱动器是否具有安全功能（是）或不具有（否）。支持安全的驱动器可以是全磁盘加密 (FDE) 驱动器或联邦信息处理标准 (FIPS) 驱动器（级别 140-2 或 140-3），它们在写入期间加密数据，在读取期间解密数据。这些驱动器被认为是安全_有能力_的，因为它们可以使用 Drive Security 功能用于额外的安全性。如果为与这些驱动器一起使用的卷组和池启用了 Drive Security 功能，则驱动器将变得安全_已启用_。



 a| 
已启用安全保护
 a| 
显示驱动器是否已安全启用（是）或未启用（否）。启用安全的驱动器与 Drive Security 功能一起使用。当您启用 Drive Security 功能，然后将 Drive Security 应用于具有安全_功能_的驱动器上的池或卷组时，驱动器将变为安全_启用_状态。只能通过配置了正确安全密钥的控制器进行读写访问。这种额外的安全性可防止对从存储阵列中物理移除的驱动器上的数据进行未经授权的访问。



 a| 
可读/写访问
 a| 
显示驱动器是否可读/写访问（是）或不可访问（否）。



 a| 
驱动器安全密钥标识符
 a| 
显示启用安全功能的驱动器的安全密钥。Drive Security 是一种存储阵列功能，可通过全磁盘加密 (FDE) 驱动器或联邦信息处理标准 (FIPS) 驱动器提供额外的安全层。当这些驱动器与 Drive Security 功能一起使用时，它们需要安全密钥才能访问其数据。当驱动器从阵列中物理卸下时，它们必须安装在另一个阵列中才能运行，此时，它们将处于 Security Locked 状态，直到提供正确的安全密钥。



 a| 
具备数据保障 (DA) 能力
 a| 
显示数据保障 (DA) 功能是否已启用（是）或未启用（否）。数据保障 (DA) 是一项检查和纠正数据通过控制器传输到驱动器时可能发生的错误的功能。数据保障可以在池或卷组级别启用，主机使用支持 DA 的 I/O 接口，如 Fibre Channel。



 a| 
DULBE 功能
 a| 
指示是否启用已取消分配或未写入逻辑块错误 (DULBE) 选项（是）或未启用（否）。DULBE 是 NVMe 驱动器上的一个选项，允许 EF300 或 EF600 存储阵列支持资源调配的卷。

|===
====
. 单击 *Close*。
