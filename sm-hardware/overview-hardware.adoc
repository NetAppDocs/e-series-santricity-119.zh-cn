= 在 SANtricity System Manager 中查看和管理硬件组件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在 Hardware 页面上检查组件状态，并执行与这些组件相关的一些功能。



[[which-components-can-i-manage]]
== 我可以管理哪些组件？

您可以检查组件状态并执行与这些组件相关的一些功能：

* **机架** -- _机架_是包含存储阵列硬件（控制器、电源/风扇模块和驱动器）的组件。机架有三种尺寸，最多可容纳 12、24 或 60 个驱动器。
* **控制器** -- _控制器_是实现存储阵列和管理功能的组合硬件和固件。它包括缓存、驱动器支持和用于主机连接的端口。
* **驱动器** -- _驱动器_可以是硬盘驱动器 (HDD) 或固态驱动器 (SSD)。根据托架的大小，托架上最多可安装 12 个、24 个或 60 个驱动器。


了解详情：

* link:hardware-page-overview.html["硬件页面"]
* link:hardware-terminology.html["硬件术语"]




[[how-do-i-view-hardware-components]]
== 如何查看硬件组件？

转到硬件页面，其中提供了存储阵列物理组件的图形描述。您可以通过选择架子视图右上角的 *驱动器* 或 *控制器* 选项卡，在阵列架子的前视图和后视图之间切换。

了解详情：

* link:view-shelf-component-status-and-settings.html["查看货架组件状态和设置"]
* link:view-controller-settings.html["查看控制器设置"]
* link:view-drive-status-and-settings.html["查看驱动器状态和设置"]
