= SANtricity System Manager 硬件页面和组件
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
硬件页面提供存储阵列的物理组件的图形描述。在这里，您可以检查组件状态并执行与这些组件相关的一些功能。



[[shelves]]
== 磁盘架

机架是包含存储阵列硬件的组件（控制器、电源/风扇罐和驱动器）。有两种类型的机架：

* *控制器架* -- 包含驱动器、电源/风扇罐和控制器。
* *驱动器架*（或*扩展架*）-- 包含驱动器、电源/风扇罐和两个输入/输出模块 (IOM)。IOM 也称为环境服务模块 (ESM)，包括将驱动器架连接到控制器架的 SAS 端口。


货架有三种尺寸，最多可容纳 12、24 或 60 个驱动器。每个货架都包含一个 ID 号，该 ID 号由控制器固件分配。ID 显示在货架视图的左上角。

硬件页面上的货架视图显示正面或背面的组件。您可以通过从货架视图右上角选择 *驱动器* 或 *控制器* 选项卡在两个视图之间切换。您也可以从页面底部选择 *显示所有正面* 或 *显示所有背面*。正面和背面视图显示以下内容：

* *前部组件* -- 驱动器和空驱动器托架。
* *背面组件* -- 控制器和电源/风扇罐（用于控制器架）或 IOM 和电源/风扇罐（用于驱动器架）。


您可以执行以下与货架相关的功能：

* 打开货架的定位灯，以便在机柜或机架中找到货架的物理位置。
* 更改货架视图左上角显示的 ID 号。
* 查看盘架设置，例如安装的驱动器类型和序列号。
* 上下移动货架视图，以匹配存储阵列中的物理布局。




[[controllers]]
== 控制器

控制器是实现存储阵列和管理功能的组合硬件和固件。它包括缓存内存、驱动器支持和主机接口支持。

您可以执行以下与控制器相关的功能：

* 配置管理端口的 IP 地址和速度。
* 配置 iSCSI 主机连接（如果有 iSCSI 主机）。
* 配置网络时间协议 (NTP) 服务器和域名系统 (DNS) 服务器。
* 查看控制器状态和设置。
* 允许局域网外的用户启动 SSH 会话并更改控制器上的设置。
* 将控制器置于离线、联机或服务模式。




[[drives]]
== 驱动器

存储阵列可以包括硬盘驱动器 (HDD) 或固态驱动器 (SSD)。根据托架的大小，托架上最多可以安装 12 个、24 个或 60 个驱动器。

您可以执行以下与驱动器相关的功能：

* 打开驱动器的定位灯，以便在盘架中找到驱动器的物理位置。
* 查看驱动器状态和设置。
* 重新分配驱动器（逻辑上将故障驱动器替换为未分配的驱动器），并在必要时手动重建驱动器。
* 手动使驱动器发生故障，以便更换。（使驱动器发生故障可让您在更换驱动器之前复制驱动器的内容。）
* 分配或取消分配热备用磁盘。
* 擦除驱动器。
