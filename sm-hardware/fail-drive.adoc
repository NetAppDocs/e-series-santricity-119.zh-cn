= 在 SANtricity System Manager 中手动使驱动器故障
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果有指示，您可以手动使驱动器出现故障。

.关于此任务
System Manager 监视存储阵列中的驱动器。当检测到驱动器产生大量错误时，Recovery Guru 会通知您即将发生的驱动器故障。如果发生这种情况，并且您有可用的替换驱动器，则可能需要使该驱动器出现故障，以便采取先发制人的操作。如果没有可用的替换驱动器，则可以等待该驱动器自行发生故障。

[CAUTION]
====
*可能丢失数据访问权限* -- 此操作可能会导致数据丢失或数据冗余丢失。仅在技术支持或 Recovery Guru 的指示下执行此操作。

====
.步骤
. 选择 *Hardware*。
. 如果图形显示控制器，请单击 *Drives* 选项卡。
+
图形更改为显示驱动器而不是控制器。

. 单击要使其失效的驱动器。
+
此时将显示驱动器的上下文菜单。

. 选择 *Fail*。
. 保持 *Copy contents of drive before failing* 复选框处于选中状态。
+
仅为分配的驱动器和非 RAID 0 卷组显示复制选项。

+
在驱动器出现故障之前，请确保复制驱动器的内容。根据您的配置，如果不首先复制驱动器的内容，则可能会丢失关联的池或卷组上的所有数据或数据冗余。

+
复制选项允许比重建更快的驱动器恢复，并减少在复制操作期间如果另一个驱动器发生故障时卷发生故障的可能性。

. 确认要使驱动器出现故障。
+
驱动器出现故障后，请至少等待 60 秒，然后再将其移除。
