= 在 SANtricity System Manager 中打开磁盘架定位灯
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
要查找 Hardware 页面上显示的磁盘架的物理位置，您可以打开磁盘架的定位灯。

.步骤
. 选择 *Hardware*。
. 选择 Controller Shelf 或 Drive Shelf 的下拉列表，然后选择 *Turn on locator light*。
+
货架的定位灯打开。

. 物理定位货架后，返回对话框并选择 *Turn off*。
