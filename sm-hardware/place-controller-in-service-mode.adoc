= 在 SANtricity System Manager 中将控制器置于服务模式
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果系统指示您执行此操作，则可以将控制器置于服务模式。

.开始之前
* 存储阵列必须有两个控制器。未处于维修模式的控制器必须处于联机状态（处于最佳状态）。
* 确保没有正在使用的卷，或者在使用这些卷的所有主机上都安装了多路径驱动程序。


[NOTE]
====
将控制器置于服务模式可能会显著降低性能。除非技术支持人员指示，否则请勿将控制器置于服务模式。

====
.步骤
. 选择 *Hardware*。
. 如果图形显示驱动器，请单击 *Controllers & Components* 选项卡。
+
图形会更改为显示控制器而不是驱动器。

. 单击要置于服务模式的控制器。
+
此时将显示控制器的上下文菜单。

. 选择 *Place in service mode*，并确认要执行此操作。
