= 更改 SANtricity System Manager 中磁盘架的查看顺序
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以更改 Hardware 页面上显示的磁盘架顺序，以匹配机柜中磁盘架的物理顺序。

.步骤
. 选择 *Hardware*。
. 从货架视图的右上角，选择向上或向下箭头以重新排列 Hardware 页面上显示的货架顺序。
