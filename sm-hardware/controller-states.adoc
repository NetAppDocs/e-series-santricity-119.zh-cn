= 了解 SANtricity System Manager 中的控制器状态
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以将控制器置于三种不同的状态：在线、离线和服务模式。



[[online-state]]
== 在线状态

在线状态是控制器的正常工作状态。这意味着控制器运行正常，可用于 I/O 操作。

将控制器置于联机状态时，其状态设置为最佳。



[[offline-state]]
== 离线状态

当存储阵列中有两个控制器时，离线状态通常用于准备要更换的控制器。控制器可以通过两种方式进入离线状态：发出显式命令或控制器失败。控制器只能通过发出另一个显式命令或替换出现故障的控制器来退出离线状态。仅当存储阵列中有两个控制器时，才能将控制器置于离线状态。

当控制器处于离线状态时，满足以下条件：

* 控制器不可用于 I/O。
* 您无法通过该控制器管理存储阵列。
* 该控制器当前拥有的任何卷都将移动到另一个控制器。
* 已禁用缓存镜像，所有卷都已更改为通过缓存模式写入。




[[service-mode]]
== 服务模式

服务模式通常仅由技术支持人员用于将所有存储阵列卷移动到一个控制器，以便可以诊断另一个控制器。控制器必须手动置于服务模式，且必须在服务操作完成后手动恢复联机。

当控制器处于服务模式时，满足以下条件：

* 控制器不可用于 I/O。
* 技术支持人员可以通过串行端口或网络连接访问控制器，以分析潜在问题。
* 该控制器当前拥有的任何卷都将移动到另一个控制器。
* 已禁用缓存镜像，所有卷都已更改为通过缓存模式写入。
