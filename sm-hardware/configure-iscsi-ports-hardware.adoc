= 在 SANtricity System Manager 中配置 iSCSI 端口
:allow-uri-read: 
:icons: font
:imagesdir: ../media/


[role="lead"]
如果您的控制器包含 iSCSI 主机连接，则可以从"硬件"页面配置 iSCSI 端口设置。

.开始之前
* 您的控制器必须包含 iSCSI 端口；否则，iSCSI 设置不可用。
* 您必须知道网络速度（端口和主机之间的数据传输速率）。


[NOTE]
====
仅当您的存储阵列支持 iSCSI 时，才会显示 iSCSI 设置和功能。

====
.步骤
. 选择 *Hardware*。
. 如果图形显示驱动器，请单击 *Controllers & Components* 选项卡。
+
图形会更改为显示控制器而不是驱动器。

. 单击具有要配置的 iSCSI 端口的控制器。
+
此时将显示控制器的上下文菜单。

. 选择 *Configure iSCSI ports*。
+
[NOTE]
====
仅当 System Manager 检测到控制器上的 iSCSI 端口时，才会显示 *Configure iSCSI ports* 选项。

====
+
此时将打开配置 iSCSI 端口对话框。

. 在下拉列表中，选择要配置的端口，然后单击 *Next*。
. 选择配置端口设置，然后单击 *Next*。
+
要查看所有端口设置，请单击对话框右侧的 *Show more port settings* 链接。

+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 端口设置 | 说明 


 a| 
配置的以太网端口速度（仅适用于某些类型的 Host Interface Card）
 a| 
选择与端口上 SFP 的速度能力相匹配的速度。



 a| 
前向纠错 (FEC) 模式（仅适用于某些类型的主机接口卡）
 a| 
如果需要，请为指定的主机端口选择一种 FEC 模式。


NOTE: Reed Solomon 模式不支持 25 Gbps 端口速度。



 a| 
启用 IPv4 / 启用 IPv6
 a| 
选择一个或两个选项以启用对 IPv4 和 IPv6 网络的支持。


NOTE: 如果要禁用端口访问，请取消选中两个复选框。



 a| 
TCP 侦听端口（点击 *显示更多端口设置* 即可使用。）
 a| 
如有必要，请输入新的端口号。

侦听端口是控制器用于侦听来自主机 iSCSI 启动器的 iSCSI 登录的 TCP 端口号。默认侦听端口为 3260。您必须输入 3260 或介于 49152 和 65535 之间的值。



 a| 
MTU 大小（可通过单击*显示更多端口设置*获得。）
 a| 
如有必要，请输入最大传输单元 (MTU) 的新大小（以字节为单位）。

默认最大传输单元 (MTU) 大小为每帧 1500 字节。必须输入介于 1500 和 9000 之间的值。



 a| 
启用 ICMP PING 响应
 a| 
选择此选项以启用互联网控制消息协议 (ICMP)。联网计算机的操作系统使用此协议发送消息。这些 ICMP 消息确定主机是否可达以及往返该主机传输数据包所需的时间。

|===
====
+
如果您选择了*启用 IPv4*，点击*下一步*后将打开一个对话框，用于选择 IPv4 设置。如果您选择了*启用 IPv6*，点击*下一步*后将打开一个对话框，用于选择 IPv6 设置。如果您选择了这两个选项，则首先打开 IPv4 设置的对话框，然后单击*下一步*后，将打开 IPv6 设置的对话框。

. 自动或手动配置 IPv4 和/或 IPv6 设置。要查看所有端口设置，请单击对话框右侧的 *显示更多设置* 链接。
+
.字段详细信息
[%collapsible]
====
[cols="25h,~"]
|===
| 端口设置 | 说明 


 a| 
自动获取配置
 a| 
选择此选项可自动获取配置。



 a| 
手动指定静态配置
 a| 
选择此选项，然后在字段中输入静态地址。（如果需要，您可以将地址剪切并粘贴到字段中。）对于 IPv4，包括网络子网掩码和网关。对于 IPv6，包括可路由 IP 地址和路由器 IP 地址。



 a| 
启用 VLAN 支持（通过单击*显示更多设置*可用。）
 a| 
选择此选项以启用 VLAN 并输入其 ID。VLAN 是一种逻辑网络，其行为就像与相同交换机、相同路由器或两者都支持的其他物理和虚拟局域网 (LAN) 在物理上分离一样。



 a| 
启用以太网优先级（通过单击 *Show more settings* 可用。）
 a| 
选择此选项可启用确定访问网络的优先级的参数。使用滑块选择 1（最低）和 7（最高）之间的优先级。

在以太网等共享局域网 (LAN) 环境中，许多站点可能会争夺对网络的访问权限。访问采用先到先得的方式。两个站点可能会同时尝试访问网络，这会导致两个站点后退并等待重试。对于交换式以太网，此过程被最小化，其中只有一个站点连接到交换机端口。

|===
====
. 单击 *Finish*。
