= 在 SANtricity Unified Manager 中更改存储阵列密码
:allow-uri-read: 
:experimental: 
:icons: font
:imagesdir: ../media/


[role="lead"]
您可以在 SANtricity Unified Manager 中更新用于查看和访问存储阵列的密码。

.开始之前
* 您必须使用包含 Storage admin 权限的用户配置文件登录。
* 您必须知道存储阵列的当前密码，该密码在 System Manager 中设置。


.关于此任务
在此任务中，输入存储阵列的当前密码，以便在 Unified Manager 中进行访问。如果在 System Manager 中更改了阵列密码，并且现在还必须在 Unified Manager 中更改，则可能需要执行此操作。

.步骤
. 从 Manage 页面中，选择一个或多个存储阵列。
. 选择菜单：Uncommon Tasks[Provide Storage Array Passwords]。
. 输入每个存储阵列的密码，然后单击 *Save*。
